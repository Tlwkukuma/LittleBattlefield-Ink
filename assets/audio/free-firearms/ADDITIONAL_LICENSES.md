# Additional free combat audio sources

All sources selected for this replacement are **CC0 1.0 Universal**:
https://creativecommons.org/publicdomain/zero/1.0/

1. **Impact Sounds (1.0)** — Kenney (www.kenney.nl), 2019.
   Original: https://kenney.nl/assets/impact-sounds
   The downloaded archive's License.txt also explicitly declares CC0.
   Uses: physical material impacts, body-hit substitutes, mechanical details,
   case / grenade contacts and debris.
2. **Swishes Sound Pack** — artisticdude, 2011.
   Original: https://opengameart.org/content/swishes-sound-pack
   Uses: object swishes as melee swings and throw sounds.
3. **Muffled Distant Explosion** — NenadSimic, 2014.
   Original: https://opengameart.org/content/muffled-distant-explosion
   The author describes a low-pitched log-drum hit with delayed reverberation.
   Uses: low body / tail in designed heavy-weapon and explosion substitutes.
   This is not an actual explosive field recording.
4. **Rocket launch** — qubodup, 2010.
   Original: https://opengameart.org/content/rocket-launch
   The author describes an Audacity noise-based design inspired by a launch.
   Uses: cropped gas / whoosh layer in designed launcher substitutes.
   This is not an actual RPG firing recording.

Derivative processing: channel selection, silence trimming, resampling to
48 kHz mono PCM16, limited duration, EQ/envelopes, headroom and fades; some
heavy weapon / explosion / suppressor substitutes mix these CC0 sources with
the CC0 firearm library credited in LICENSE.md. No legacy game audio is an
input. Runtime gunshot playback speed remains 1.0.

Archive hashes, original URLs, member paths, derivative parents and output
hashes are recorded in data/free-weapon-audio.json and the preparation cache.
No attribution is required by CC0; these credits are retained voluntarily.
