# 载具驾驶与地面适应（2026-09-28）

## 本轮依据

用户反馈载具操控生硬、无法适应不同地面，并选择优先整体改善转向和起停。本轮继续使用原生 Godot 联合演武场、已有 Tab 车辆选择和地形区入口。以下参数是本项目调校，未将其表述为《逃离鸭科夫》的原作驾驶参数。

旧实现把车轮采样点高度绝对值超过 0.04 m 的地面判为不可通行，车身始终绘制在 y=0。轮式车辆静止时仍能转动车身，撞障碍时直接反向速度。本轮替换了这些处理。

## 操作与调校

- W/S 前进、倒车；A/D 转向；空格制动；F 上下车；G 轮盘、数字键或滚轮切车载武器。固定武器继续使用原操作员及后坐、装填表现。
- 输入经过短暂平滑；松油门逐步减速；反向输入先制动，停稳后倒车。制动力约 0.17 秒建立，低速收停，坡上停车保持位置。
- 吉普、侦察车按轴距和车速计算转弯；静止时前轮可以转向，车身不原地旋转。高速减少转向幅度，松软地面降低横向抓地，并保留有限侧滑。
- 装甲运输车、步战车、轻坦、中坦、重坦按最新 v.29 赛车式方向输入处理，保留较小转弯半径与履带损伤响应；静止不原地转向。
- 碰撞分步计算；按用户后续要求，接触障碍后采用短促回弹、沿边滑动与转向脱离，细节见下方「障碍边缘接触」。

## 地面与外观同步

- `vehicle_grounding.gd` 从 `terrain_surface.gd` 的真实三角网格读取轮式四点 / 履带六点接地高度，拟合车身高度、俯仰和侧倾，支持负海拔。
- 雪地、沙地按原地形软硬程度改变抓地、最高速度和滑行阻力；履带在松软地面损失较少。硬路、草地、土路与山坡也有独立参数。
- 前轮显示转角和轮胎转动；轮式车辆加入有限轮位上下补偿；车身有轻微起停俯仰和转弯侧倾。履带保持连续带体，负重轮按两侧实际转速旋转，没有实现逐节履带形变或刚体翻滚。
- 车辙贴合实际地面，区分轮胎连续印与履带横纹；雪粉 / 扬沙从行进接触区产生。印迹最多 320 处、保留 55 秒、网格最多每秒更新 10 次，粒子沿用现有预算。
- 过陡纵坡、侧坡、沟崖、底盘穿地及深水仍阻挡车辆。壕沟应沿端部缓坡进出，不允许从垂直沟壁直接驶过。

## 共用空间数据

`vehicle_dimensions.gd` 提供倾斜后的车体、舱体和炮塔体积；移动碰撞、人物承托、射线、手雷反弹和爆炸距离使用对应形状。碰撞继续读取存活墙格、家具独立部件和树石凸体，保留真实破口与岩拱空隙。

`vehicle_weapon_rig.gd` 使用同一车身高度和基向量，炮塔沿支撑面转动，实际枪口、后坐和抛壳节点随车。坡上瞄准先投影到炮塔转动平面。下车读取脚下地形高度；载具殉爆和烟雾使用车辆所在高度。移动阴影也贴合地面。

## 倒木越障与连续履带支撑（2026-09-28）

用户继续指出「倒木与断枝」不应一概挡住履带车。标准倒木的实际主干最高约 0.642 m，突出断枝约 0.907 m；不再根据整体高度否决整根主干。

- `vehicle_offroad.gd` 按倒木各独立凸体的真实高度与车型能力判断承托资格。轮履滚动包络、底盘碰撞、影子与地面反馈共用这些表面。立着的树干不会成为可翻越地面。
- 履带前、中、后三组接地点之间补充四组接触查询，避免细长主干落在采样空隙内时被误判为托底；增加的接触只在附近存在可翻越障碍时计算。履带仍为刚性连续环，没有逐节形变。
- 倒木所有部件保留真实底盘体积碰撞。超过本车型高度上限的断枝不提供承托，能否通过仍取决于剩余离地间隙；不能凭空穿过突出断枝。销毁倒木后立即停止承托。
- 五类履带车能通过本次主干截面；轮式侦察车的 0.60 m 上限不足，吉普则在中段可能因轴距、底盘间隙托底。不要把“低障碍参考上限”当作任意形状都能通过的保证。

必要数学检查：七车型共 1,127 个主干静态截面，五类履带均可通行，轮式限制符合上述结果；七个入口均可放置。另检查运输车靠右两条断枝截面，共 322 个位置，仍存在真实断枝阻挡。倒木移除后承托释放，其他直立树不提供支撑；原 2,303 项岩石、1,462 项地形与枪口检查继续通过。实际驾驶与颠簸观感由用户在同一演武场试玩。

## 障碍边缘接触（v2026.09.28.9）

用户明确要求所有障碍边缘接触都应有处理，至少提供反弹，避免速度直接清零造成卡死感。本轮替换驾驶中的接触响应，所有实体仍读取原碰撞数据。

- `vehicle_collision.gd` 在需要时返回真实接触法线、最小水平分离距离及接触位置。覆盖存活墙格、家具独立部件、树石凸体、其他车辆和场地边界；墙洞、岩拱、叶冠与可越障主干的原规则保留。
- `vehicle_contact_response.gd` 对受阻的移动子步细分定位，先走完可通行部分，再沿接触面滑动并给予向外短促回弹。正撞主要后退，斜擦保留约 94% 的切向速度；转向角碰撞限制继续挤入的一侧，允许往脱离方向转动。
- 回弹速度保留到下一帧，避免被本帧平均位移覆盖。撞击后约 0.18 秒暂时卸掉指向障碍的油门；转向、反向离开和空格刹车继续有效。回弹有 0.35 秒冷却，并区分新撞击与持续顶住，减少重复弹跳。
- 不可通行的坡坎、深水边缘等支撑失败也有退让响应；回弹和滑动的剩余位移仍经过原地面与实体检查，夹角内最多处理三次接触，不能通过反弹穿墙。

## 撞击人物与碾压（v2026.09.28.17）

用户进一步指出人不能像固定障碍物一样挡停整车。此规则替代上一轮的人物硬碰撞响应，分段车体与双向几何仍沿用。

- `vehicle_runover.gd` 在实际接触后处理推挤、伤害和人体冲量，几何查询 / 二分扫掠本身不扣血。正常接触优先推开人物，车辆只损失约 3.75%–12% 的速度；人物死亡后不再挡车。只有人被实体夹住且仍存活时才限制剩余位移，保留很小的缓冲和倒车脱离。
- 按接触点的相对法向速度计算伤害，包含车身转动，倒车同样有效。低于 0.8 m/s 的普通自由接触以推挤为主；更快的正撞按速度平方增加，斜擦降低。七车型游戏重量系数为 1 / 1.25 / 1.8 / 2 / 2.15 / 2.7 / 3.2，吉普 2.5 m/s 正撞约 34.7 点、重坦约 111 点；高速正撞可致命。这是本项目游戏参数，非真实事故模型或鸭科夫原作参数。
- 卧倒人物与真实轮履部件接触时增加碾压伤害；人物被墙 / 其他实体夹住且车辆仍向内移动或持续给油时产生挤压伤害。静止、无推进的接触不扣血。每对人车至少间隔 0.55 秒结算，避免同帧子步与细分车体重复伤害；现有演武场玩家无敌设置继续生效。

## 碎石区接地计算优化（v2026.09.28.20）

用户在旧 v2026.09.28.13 窗口的松散碎石簇上报告严重卡顿，截图约 3 FPS、物理耗时约 59.6 ms。该处对应 `(46,14)` 的 `rock.scree`，含九个独立石块。旧实现每个轮履 / 底盘采样点遍历全部朝上三角面，同一物理步首尾重复求接地；零位移仍执行完整接地与碰撞搜索，不可通行姿态还会反复二分。

- `vehicle_collision.gd` 复用车体朝向下的自然凸体投影，单块最多缓存三个朝向；底盘间隙裁切只建立一次，按当前姿态转换。自然支撑和碰撞缓存跟随物体变换 / 网格重建失效，树石实体、车体尺寸、越障上限与碾压规则保留。
