# 短光迹与分口径弹壳

2026-09-28：用户要求采用鸭科夫的子弹方案，并明确选择“短促亮弹芯＋很短的光迹”；随后要求弹壳变小，按不同枪械的弹药大小区分。

## 参考核实

本机《逃离鸭科夫》2.3.30 的 `resources.assets` 已重新只读检查，记录见 [渲染器绑定](duckov-ammo-renderer-observations.json)，复查工具为 `tools/inspect_duckov_ammo_renderers.py`。普通 `BulletNormal` / `BulletSMG` 使用暖色发光 TrailRenderer，序列化保留时间约 0.04 / 0.06 秒。弹壳独立使用不发光网格粒子；特殊弹 Capsule 和海贝 Shell 网格不能代表普通枪弹与弹壳。

本轮还只读查看 `Projectile` 的程序集调用：包含运动、SphereCastAll、命中排序、受击记录、DamageReceiver.Hurt 和对象池 Release；Init 清理既往命中和轨迹。这说明参考游戏将飞行检测与可见轨迹独立组织，不能据此声称测得每把枪的实际速度、弹壳世界尺寸或默认视觉强度。未复制原作素材，未修改原作文件。

## 本项目变化

- 普通枪弹显示淡暖色亮芯与快速收细的短光迹。手枪 / 冲锋枪更短，步枪居中，狙击更醒目；霰弹每颗是很短的小亮点，O12 独头弹更粗短。火箭、榴弹、迫击炮和主炮弹继续使用原三维模型。
- 在已确认的前后物理位置间插值，适配首关 30 Hz 与演武场 60 Hz；不向尚未碰撞检测的位置外推。光迹尾部不会超过枪口，正对镜头时收为短椭圆，不无限拉长。
- 命中或射程结束后，只在真实终点保留最后一小段，显示一帧后在约 0.026～0.036 秒内淡出。这样在两个绘制帧之间生成并命中的近距离弹仍能看见。没有额外伤害、继续飞出墙外或完整路径残留。
- 普通弹通过一个 MultiMesh 批次绘制，每颗两个三角形，无独立节点、描边层或灯光；最多 2048 个显示项、256 条短暂终点记录。优先显示玩家的在途子弹，超出预算只省略外观，不减少实际弹丸或命中。仍有逐弹更新及透明混合开销；这不是 50 vs 50 性能实测结论。
- 弹壳基础大小按口径及壳长分别定义。9 mm、.45、PDW、5.56、短 / 长 7.62、马格南、反器材、霰弹壳不再靠同一巨大屏幕宽度补偿；同一弹药跨枪械使用相同尺寸。目录以简化弹药标签为准，型号可细分壳长，不改原游戏弹药设定。
- 手持弹壳近景尺寸缩小，M416 在常用缩放下约为旧版一半。使用共同倍率保证比例，远景最多放大到基础尺寸 1.6 倍。车载 7.62 和重机枪共用对应手持档；其他炮壳基础尺寸缩小到此前 80%，最多再放大 1.1 倍。
- 红色散弹壳与绿色独头弹壳保持相同体积；不能根据每发散弹的颗粒数量生成多枚壳。铜色壳体、暗空口、重力、弹跳、支撑破坏后下落、枪型抛壳时序及弹匣掉落沿用原系统。

上述颜色、尺寸、持续时间和容量是本项目的表现参数；没有改弹速、伤害、碰撞半径、弹丸数、散布或后坐。飞行亮芯是可读性效果，不拿光迹长度作为空弹壳的尺寸依据。

## 特殊飞行弹体细化（v2026.09.29.7）

用户截图中的 40 mm 榴弹使用旧的两段八边圆锥，统一黄铜色；远景最短显示长度又被固定拉到约 23 像素，导致短榴弹看起来像临时黄色箭头。本轮保留普通机枪 / 步枪等既有短光迹，重做特殊弹体的外形和缩放。

- 40 mm 车载与手持发射榴弹：圆钝金属引信、短粗橄榄色弹体、暗接缝和铜色环带、收口底部。飞行物是弹头，空弹壳仍走原抛壳系统。
- 炮弹：锥弧鼻部、金属引信、橄榄色主体和铜色弹带，取消整枚淡黄亮块。
- 迫击炮弹：卵形主体、收细尾管和四片尾翼。火箭：独立战斗部轮廓、收颈、发动机段、四片尾翼和缩短的尾焰；原先四个重叠横板改为四个径向尾翼。
- 特殊弹体按原长宽比统一缩放，约 5.5–6.5 像素直径为可读性目标，倍率限制为 1.15–2.15。取消沿视线方向无限补长；不改变武器的弹速、伤害、物理碰撞半径和弹丸数量。
- 特殊弹体位置同样在已完成碰撞检测的前后物理点之间插值，不向前外推；显示尾部仍受离开枪口距离限制。
- 所有零件在首次构建时合成一个带顶点色的缓存三角面，后续弹丸复用；常规演武场也使用此合并结果，战役继续接入原几何图集。关闭飞行小弹体阴影，不新增灯光、长拖尾或粒子发射源。模型为 12 边分段轮廓，仍有逐弹节点更新成本。

编译与原场景启动检查通过。未自动射击或用独立预览 / 截图代替验收；通过现有 Tab 选择运兵车榴弹、步战车自动榴弹、坦克主炮 / 迫击炮及手持 RPG 试玩。

速度直接用于实际弹丸推进，迫击炮用于原弧线时长（.85–4 秒范围）；显示沿已验证的物理位置插值，无独立假速度。真实连续射线扫掠、伤害、爆炸半径、散布和抛壳不随视觉口径放大：`collision_radius` 保存原碰撞半径，枪口遮挡与飞行读取该值。

普通光迹仍为原单个有界 MultiMesh，不新增材质批次、灯光或长拖尾。特殊弹体复用原缓存和战役几何图集。只做编译与原场景启动检查，未自动射击或压力测试；用户通过原 Tab 配装 / 车辆面板试玩后继续调校速度与辨识度。
