# 首关壕沟掩护修正

2026-09-28，根据用户“沟内人物容易被平地敌人击中”的反馈制作。

原深沟为 1.3 米，站姿通行体高 1.95 米，AI 采用胸部与头部可见射线，实际命中使用原骨架胶囊；这几个高度并不相同。旧木护壁高 1.1 米、底高 -1.3 米，顶端低于自然地面 0.2 米，只是沟内护壁。沟底宽、边坡向外展开，平地射手仍能斜向击中露头的人；原实现没有给沟内人物附加无敌或减伤。

本轮调整为同一套真实地形与通行几何：

| 部位 | 首关参数与用途 |
| --- | --- |
| 主沟 | 深 1.6 米；沟底设计净宽仍 2.4 米，保留原折线与两处步行坡口 |
| 迎敌侧胸墙 | 原地面以上 0.6 米；相对沟底总高 2.2 米，主要挡住来自东侧道路/农院方向的平射 |
| 背侧土堆 | 原地面以上 0.3 米，比正面低，保留方向差异 |
| 土堆横断面 | 沟坡外再起土：内坡水平展开 0.65 米、顶宽 0.8 米、外坡展开 1.25 米；出口附近渐低并让开整个坡道 |
| 射击踏步 | 沟底以上 0.9 米，脚下绝对高 -0.7 米；长 4 米、宽 0.9 米，双端五级进入，每级 0.18 米 |
| 木护壁 | 随沟底降到 -1.6 米、高 1.4 米，顶端维持 -0.2 米，仍可被枪弹/爆炸打坏 |

土堆不是贴图或额外透明碰撞盒。它并入 `terrain_surface.gd` 的三角网格，显示、人物高度、子弹、手雷和视线共用实际表面；道路保平约束仍优先。土堆轮廓/颜色区别于沟底，土堆不挤入沟底净宽。

进入深沟用于移动和躲避，站上踏步可把枪口抬过胸墙，也会把头部暴露给对方；踏步上蹲下可重新遮蔽。近距离、高处俯射以及坡口、纵向来火仍可能命中，壕沟没有额外减伤。原有木/石墙仍保留真实破口；土壤保持本项目静态高度地形，本轮未增加爆炸挖土。

## 复用参数

`landform.trench-network` 新增 `parapet_height_m`、`parados_height_m`，默认均为 0，所以既有普通沟与梯子演示不自动长出土堆。`parapet_side` 为 +1 或 -1，表示沿点列方向与“控制点到采样点”叉积的正/负侧；首关从南向北走向时，+1 为东侧。

横断面使用 `berm_inner_run_m`、`berm_crest_width_m`、`berm_outer_run_m`。坡口按原 `ramps` 留口，两个末端自然收低。重复沟网使用最大土堆高度，不叠加土堆；任一沟的完整沟底都优先于相邻土堆，避免交叉处被填高。最终形状仍受 0.5 米地形网格采样影响。

## 验证与验收

- `qa/trench_cover_contract.gd`：49 项遮挡/几何检查通过，包括平地射线、真实子弹命中类别、AI 视线、旋转土堆、两个坡道，以及 M416、AKM、AWM 的原骨架头部与实际枪口。
- 专用平地夹具中，来自正面 12 / 20 / 30 米、三个沟内位置和三个身体采样高度，共 27 条固定射线：旧版全部无遮挡，新版全部被实体土壤挡住。这是固定几何对照，不是战斗命中率统计。
- 首关布局 385 项、AI/车辆导航几何 248 项、通用果园资产 266 项、石墙破坏 5 项回归通过。原门洞、道路整车扫掠、两条出口与现有路线保持可用。

通过 `START_LEVEL_01.bat` 或同一联合演武场的“第一关”进入。由用户比较沟底行进、上台站射、蹲下遮蔽及敌方近距离俯射；没有自动操控游戏或截图验收。
