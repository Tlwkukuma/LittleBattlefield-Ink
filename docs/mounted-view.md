# 载具与固定武器视野 · v2026.09.29.15

用户要求炮台、机枪、载具看见更大范围。操作期间提升原正交相机 size，不改变俯视角度或模型尺寸。

| 操作对象 | 相机 size 目标（常规演武场步兵为 20） |
| --- | ---: |
| 武装吉普 | 30 |
| 侦察装甲车 | 34 |
| 装甲运兵车 | 32 |
| 步兵战车 / 轻型坦克 | 36 |
| 中型坦克 | 40 |
| 重型坦克 | 42 |
| 固定重机枪 | 32 |
| 固定野战炮 | 38 |

尺寸为相机正交跨度参数，不等同于 AI 视距 / 武器射程。目标取该档与当前场景步兵视野 ×1.30 中较大者，以适应首关等已有较宽镜头的场景。

- 上下车 / 接管或离开固定武器平滑过渡；步兵原 zoom 保留，下车恢复所属场景原视野。
- 同一车体切换主炮、同轴机枪、榴弹或迫击炮不改变视野，避免切枪时反复缩放。
- F1 用户主动动作近景、编辑器视野仍由原入口控制；扩大默认操作视野不覆盖这些明确查看方式。
- 准心固定鼠标、驾驶姿态插值、独立垂直跟随、开镜逻辑继续沿用。只有同一相机 size 改变，不新增相机或特效容量。
- 范围变大可能让更多已有场景物体进入画面；原剔除和更新预算保留，不宣称额外可见物没有 GPU 成本。

必要编译 / 启动检查；实际驾驶、远距离射击和可读性由用户在原联合演武场 Tab → 车辆 / 固定武器 → 立即试驾 / 操作验收。
