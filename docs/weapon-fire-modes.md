# 射击模式与空仓自动装填

2026-09-26。按用户要求采用 PUBG 端游式单发、固定发数连发、全自动的扳机规则。仍在 `res://proving_ground.tscn` 联合演武场，`START_FIRE_MODES.bat` 默认装备 M16A4；Tab 可换全部 84 项装备。

## 操作

- **B** 循环当前武器支持的射击模式，底部 HUD 和武器库都显示当前模式；武器库也有切换按钮。只有一种模式的武器会说明其固定模式。
- 单发 / 半自动：每次按下打一发，按住不重复。栓动、泵动、杠杆枪仍受原本枪型动作和射速限制。
- 二 / 三连发：一次点击启动一组，每一发按枪械射速分别消耗弹药、生成实体弹丸、产生后坐和抛壳；普通松开鼠标会完成这一组，按住不会自动开始下一组。连发中额外点击不堆积下一组。
- 全自动：按住持续射击，松开停止。MG3 用 B 切换 660 / 990 RPM 两档全自动。
- 弹匣最后一发打完立即开始装填，有备用弹药才装填。R 仍可提前装填；备用不足时只装入实际剩余数量。保留原装填时长、掉落弹匣、留膛壳在开膛 / 换弹时排出的表现。
- 半自动 / 连发在装填完成后必须重新点击，旧连发不会跨到下一弹匣；全自动保持按住则继续射击。备用弹药耗尽时 HUD 显示提示，不循环空装填。
- 换枪记住该武器所选模式。切模式、换枪、上下车、打开菜单、失去窗口焦点、翻墙 / 爬梯或倒地会清除未完成连发；被取消后需松开扳机再开火。切模式不能跳过已有射击冷却。
- 车载主副武器按最新规则使用 G 轮盘、数字键 / 滚轮切换，E 交互，F 上下车 / 离开固定武器。车载机枪持续按住射击，单发炮、迫击炮按次发射，自动装填共用弹药逻辑。

## 参考证据与边界

- [PUBG 官方 22.2 公告](https://pubg.com/en/news/4555)：说明 M16A4 / Mk47 无全自动，并列出 FAMAS 的单发、连发、全自动模式。
- [PUBG 官方 18.2 公告](https://pubg.com/en/news/1741)：O12 明确为单发、三连发、全自动。
- [PUBG 官方 12.2 公告](https://pubg.com/en/news/1740)：K2 支持单发、连发、全自动。
- [PUBG 官方 8.2 公告](https://pubg.com/zh-cn/news/4744?category=patch_notes)：MG3 的 660 / 990 RPM 两档全自动。
- [PUBG 官方 19.1 公告](https://www.pubg.com/en-asia/news/1364)：MP9 单发 / 全自动。
- [PUBG 官方控制选项公告](https://pubg.com/en/news/1728) 的自动装填选项在空仓尝试开火时触发。本项目按用户明确要求，采用**打完最后一发立即自动装填**，不要求再点一次。

上述公告明确核实了关键例外，并非全部 84 把枪的当前版本逐项实机验证。其余模式按端游枪型规则组织，扩展装备的映射如上明确列出；实际操作感觉留给用户验收。

## 实现与检查

- 独立扳机状态保存 `fire_mode`、`fire_pending`、连续射击时钟和取消后的松手门控，不复用原后坐力的 `burst` 计数。
- 持续射击保留至多一个物理帧的时间余量，避免例如 800 RPM 在 60 Hz 下因每次向整帧取整而变成 720 RPM；停火不积累余量，也不在一帧补发大量积压弹丸。
- 玩家、靶兵和车载开火仍共用原来的 `fire()`、`shot` / `reload_start` 事件，连发中的每一发独立经过枪口、后坐、碰撞和抛壳管线。靶兵反击启用时按短射击窗口使用相同模式；默认关闭的反击不变。
- `qa/fire_control_check.gd` 995 / 995 通过：模式覆盖、30 / 60 / 120 Hz 射速算术、点击 / 按住、连发中断、切模式冷却、装填后扳机规则、弹药守恒和无备用弹药等。只运行纯字典和时钟计算，没有加载游戏场景或调用世界开火 / 自动操作输入。
- `proving_ground.gd` 编译检查通过。启动同一联合演武场交付用户；未自动射击、行走或截图测试，不把启动帧率作为 50 vs 50 性能结论。

## 车载机枪误判为半自动（v2026.09.29.4）

根因：导入目录中的 15 项车载武器和 2 项固定武器没有随身武器 `id`，也没有 `automatic` 字段。原 `modes()` 未命中随身武器模式表后按缺省 false 回退为单发，导致 HUD 显示半自动、按住扳机只打一发。

现在目录加载时为全部 17 项装备绑定独立的车型 / 武器槽键，由 `MOUNTED_MODES` 明确配置，开火、默认模式、B 键和 HUD 共用。新增未配置的车载槽位会在载入时报错，避免静默遗漏；没有修改导入 JSON 或创建另一套开火计时。

- 固定全自动：六种车型的重机枪 / 同轴机枪、固定重机枪；侦察车 20 mm 与步战车 25 mm 机关炮；步战车 40 mm 自动榴弹发射器。按住发射、松开停止，弹匣耗尽后依原时长装填，持续按住可在装填完成后继续。
- 固定单发：运兵车普通 40 mm 榴弹发射器、45 / 75 / 88 mm 炮、81 mm 迫击炮、近距霰弹炮、野战炮。按次发射。
- 各武器原射速、伤害、容量、备用弹量和装填时间保留；切枪、上下车、菜单与失焦的松手门控仍有效。机枪只有全自动一种模式，不会被 B 切成半自动。

本轮只做必要编译和场景启动检查，未新增 / 运行自动射击测试；持续开火与换武器手感由用户在原联合演武场验收。
