# 载具耐久与状态显示（v2026.09.29.27）

## 成熟项目参考与本项目取舍

- [《坦克世界》1.26 官方更新说明](https://worldoftanks.eu/en/content/docs/release_notes/release-notes-1-26/) 明确涉及伤害面板中的车辆部件示意、被毁油箱红色状态及悬挂损坏图标。借鉴车体与部件分开、通过图标与颜色表达受损的方式。
- [《战争雷霆》官方地面伤害模型开发日志](https://warthunder.com/en/news/384--en) 说明装甲、关键部件与履带损伤有不同作用。该资料是 2013 年设计说明，不作为当前版本全部参数的依据；该作也不是靠本项目这种统一车体 HP 决定摧毁。
- 本项目按用户要求保留两类可读数值：“装甲”显示现有车体总生命值，归零摧毁；“履带 / 轮胎”显示现有行走系统生命值，影响速度与转向。装甲条不是额外吸收层，装甲方向系数仍单独参与伤害计算。
- 所有下列 HP 都是本项目调校，不宣称复制竞品数值。不给敌人增加透视血条，不引入新的修理道具或自动修复机制。

## HUD 与机动状态

左下人物生命条上方显示当前车型与两行耐久，每行包括独立图标、当前值 / 最大值、进度条及状态词。装甲采用盾牌图标，轮胎 / 履带各有图标。颜色正常为浅绿、受损为琥珀、严重受损为红色，辅以文字，避免只靠颜色判断。

行走系统状态与 `vehicle_dynamics.gd` 共用 `mobility()`：

| 剩余比例 | 速度系数 | 转向系数 | 显示 |
|---|---:|---:|---|
| ≥68% | 1.00 | 1.00 | 完好 / 轻损 |
| 35%–68% | 0.72 | 0.74 | 受损 · 机动下降 |
| >2%–35% | 0.48 | 0.48 | 严重受损 · 机动下降 |
| ≤2% | 0.28 | 0.24 | 重损 · 仅可缓行 |

沿用现有受击方向与伤害强度触发行走系统伤害的机制，不在本轮扩展为独立左右履带或四只轮胎；HUD 诚实显示同一个总池，不能伪装独立部位数值。原有最低缓行能力保留，避免把 0 HP 描述为完全无法移动。固定机枪 / 炮位仍只显示炮位耐久。

## 性能与交付

`vehicle_status_hud.gd` 追加到原 HUD 的图形 / 字体缓存批次，没有新增每车 UI 节点、世界血条、相机、射线或每帧车辆扫描。缓存签名纳入当前车辆 ID、类型与两类血量，上下车、切车、受损和重置均能正确刷新。

必要编译、导出与启动检查完成后，仍通过 `res://proving_ground.tscn` 联合演武场的 Tab「车辆 / 固定武器」→「立即试驾 / 操作」交付，血量平衡与视觉体验由用户亲自试玩。
