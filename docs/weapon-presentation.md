# 枪械外观、实体弹丸与掉落件

后续弹药迭代已补充普通弹真实渲染器绑定、短亮弹体、弹壳停稳和材质声音，最新尺寸与行为以 [弹丸与弹壳体验](ammo-experience.md) 为准。下文记录第一轮实现。

2026-09-26：按用户要求，以 PUBG 的枪型结构与本机《逃离鸭科夫》的俯视弹药可读性为参考，调整枪长、枪宽、分区配色、弹丸、弹壳及掉落弹匣。保留原武器目录、伤害、弹丸数、射速、弹匣容量、散射和原骨架。

## 参考依据与边界

- 实际查看 [PUBG 官方步枪展示](https://pubg.com/en/game-info/weapons/ar) 和 [霰弹枪展示](https://pubg.com/en/game-info/weapons/sg)。可见 M416 的深色机匣、SCAR-L 的沙色外壳、S1897 的木托泵柄、S686 的长双管、DBS 的紧凑枪身，以及 O12 的弹匣供弹轮廓。官方说明明确区分霰弹散布。本项目用原有轮廓和自己编写的几何细节实现这些辨识点。
- 用已安装 UnityPy 对 `F:/steam/steamapps/common/Escape from Duckov/Duckov_Data/resources.assets` 做只读检查。核实存在独立的枪械、Bullet、Shell、ShotgunShell、ShellEmitter，以及步枪、冲锋枪、霰弹、狙击弹相关对象；`Bullet` 材质为暖色并设置发光，`Shell` 材质设置为不发光。观察记录见 [元数据](duckov-weapon-observations.json)，复查脚本为 `tools/inspect_duckov_weapon_reference.py`。
- 本机网格局部包围盒显示短枪、长狙、长双管在建模层面有不同尺寸，但这些不是最终持枪世界尺寸。未从截断的 MonoBehaviour 字段推断弹速、散射、射击节奏，也未宣称实测过原作。
- 未导入或复制两款游戏的网格、贴图、动画或声音。下面的尺寸、颜色、像素下限均为本项目的设计值。

## 枪型

- 沿用原 84 项装备；给可用枪型补齐长度表，并按手枪、紧凑冲锋枪、普通步枪、狙击枪、双管/DBS、机枪分别设定宽度。例：Micro UZI 0.43、Vector 0.55、M416 0.88、S1897 1.11、AWM 1.32、Lynx 1.48，均为模型绘制长度。
- 深灰钢件、黑色握把、暖棕木托、沙色 SCAR/Vector 和橄榄色 AWM/AUG 分区绘制，不再统一涂成浅灰紫色。
- 补充枪口深色孔、口缘、抛壳窗、枪机柄、机匣销、选择杆、握把/套筒细槽、导轨、护木通风槽、制退器开孔、消音器分段和木托接缝。
- S1897/Nova/XM1014 区分枪管与下方弹管，泵动型号有环纹泵柄；S686 为上下双管，Sawed-Off 为短并列双管，DBS 为并列双管和下方弹管。双管射击轮换实际枪口节点。S12K 与 O12 保留盒式弹匣、弹鼓区别。
- 固定细节在创建时合并并按武器缓存；本轮资源检查中单枪固定几何最多 3628 个三角形、最多两个表面。该数字不等于同屏性能测试。

## 弹丸与弹壳

实体弹丸始终从当前枪口发出，沿每步经过路径做三维碰撞，保留高度瞄准、穿透、伤害衰减、爆炸与破坏。表现大小独立于命中半径、伤害和速度。

| 弹类 | 飞行外观 | 抛壳外观 |
| --- | --- | --- |
| 手枪 / 冲锋枪 | 短圆头、浅铜色 | 短直壁黄铜壳 |
| PDW | 细长尖头、浅金色 | 小型缩颈壳 |
| 5.56 / 7.62 | 长尖头，铜金 / 暖铜；7.62 更粗大 | 不同长宽比的缩颈黄铜壳 |
| 马格南 / 反器材 | 更长、更粗，浅金 / 灰铜和亮端部 | 大型长壳 |
| 霰弹 | 一组独立短小灰银弹丸，淡色高光，无长条金色弹体 | 红色塑料管、黄铜底缘和深色开口 |
| O12 独头弹 | 单颗粗短钝头弹，分段环槽 | 绿色塑料管、黄铜底缘 |

- 普通枪弹与对应弹壳继续共用可读尺寸基准；霰弹丸明确与整枚霰弹壳分开，独头弹也使用自己的短粗比例。
- 以 900 高视口计算，普通弹丸宽度下限约 3.8～5.8 像素，霰弹丸 2.8 像素、长度约宽度的 1.18 倍。近景按基础世界尺寸显示。缩放时整体等比例增大弹壳，避免短壳被拉成长壳。
- 飞行弹体有克制的亮色与发光，落地壳不发光。每颗普通弹丸为一个共享网格节点；没有重加拖尾或单独灯光。霰弹枪口火光更短、更宽。

## 抛壳和弹匣

- 每发一枚枪弹/霰弹药筒，只产生一枚弹壳，与霰弹丸数无关。
- 自动枪即时抛壳；泵动、拉栓和杠杆枪延后到动作阶段。DBS 每两发排出两壳，只有一发时留待装填排出。折管双管和左轮保留已发射空壳，在装填时排出。
- 泵动、管式供弹枪装填时不再次抛出已经排掉的空壳。
- 弹匣从当前枪身 `MagazineSocket` 的位置与朝向脱落；装填取消、切枪或死亡时取消尚未发生的弹匣掉落。弯弹匣、直弹匣、短弹匣、弹鼓、机枪弹箱、P90 顶置弹匣和螺旋弹筒按枪型生成。枪上的新增弹匣体积和掉落件使用同一缓存几何与配色。
- 保留旋转、重力、弹跳、落地声和地面/支撑物高度处理。弹壳最多 160 枚、弹匣最多 32 个，最长 24 秒，另受总粒子 360 项预算约束；不是永久留存或完整刚体墙面碰撞。
