# 载具与固定武器弹壳

2026-09-28 补充：按用户要求缩小弹壳，车载 7.62 和重机枪分别与人物长 7.62、反器材壳共用尺寸及放大上限；其他炮壳基础尺寸为此前的 80%，远景放大最多 1.1 倍。口径映射、封闭舱内收壳和野战炮实际退壳时序继续保留，见 [最新弹药实现](bullet-flight.md)。

用户要求载具弹壳与人物枪械区分。实现按武器口径和机构分档，同口径保留相近比例，而不是给所有车载武器统一放大人物弹壳。

`scripts/mounted_cases.gd` 显式映射七类载具的十五个武器模式及两件固定武器。只控制退壳表现，不调整弹丸、伤害、射速、散布或弹药数量，也不通过没有武器 ID 的 `bullet` 默认值猜测弹壳。

| 类型 | 形态与表现 | 使用位置 |
| --- | --- | --- |
| 7.62 同轴机枪 | 与人物 7.62 弹壳相同的基础直径和长度，细瓶颈 | 侦察车、轻／中／重坦同轴机枪；在舱内收壳 |
| 重机枪 | 加长壳体、宽底缘、抽壳槽、收口和烧黑空壳口；较克制的上抛与翻滚 | 吉普、运兵车顶机枪、固定重机枪；从真实机匣侧口排出 |
| 20 / 25 mm 机关炮 | 独立尺寸、较宽肩部、金属底缘和灰绿色壳体 | 侦察车、步战车；在封闭炮塔内收壳 |
| 40 mm 榴弹 | 短粗杯形、厚底缘和明显空口 | 运兵车外露发射器排出，步战车在舱内收壳 |
| 45 / 75 / 88 mm 主炮 | 各自尺寸，宽底缘、渐缩大壳体，区别于步枪瓶颈 | 轻／中／重坦；在舱内收壳。重坦霰弹炮共用 88 mm 壳体档，不按散弹丸数重复退壳 |
| 野战炮 | 单独的大炮壳档，不虚构原资料没有提供的口径；较低转速、较小落地反弹、较低落地音调 | 实际装填进度 22% 时后膛已经打开，由后膛向后退壳，然后才进入送弹动作 |
| 迫击炮 | 无独立抛出的弹壳 | 不生成空壳特效 |

重机枪长壳按本项目 12.7 表现档制作，未在原数据标注口径的吉普和固定重机枪也使用这一美术档。所有模型尺寸和抛壳速度均为游戏表现参数，不宣称为现实武器实测数据。

大壳体保持相同重力，采用较低抛出速度、翻转速度和反弹系数表达重量。排壳继承车辆运动速度；延迟排壳读取实际机匣或后膛节点。远景放大有上限，防止屏幕最小像素尺寸抹平不同口径的区别或把壳体放大到盖住炮塔。

野战炮无弹可装时保留待退壳状态，开始实际装填并到达开膛阶段后再退出；修复／补给会清理待退壳事件。外露武器每次发射仅排一枚壳，封闭炮塔继续采用舱内收壳。

## 检查与验收

完成 17 种武器模式映射、9 种非空壳体资源及近远景尺寸上限的资源／数学检查，演武场资源加载通过。未自动开火或截图验收。

仍在 `res://proving_ground.tscn`：Tab 选择吉普、装甲运兵车、固定重机枪或野战炮，左键开火，G 轮盘、数字键或滚轮切换车载武器，F1 近看。野战炮开火后等待装填阶段，观察向后退壳；F 离开操作位。实际画面和手感由用户试玩评价。
