# 载具损毁表现（v2026.09.28.28）

沿用原联合演武场与原车型。这是本项目的表现调校，不是鸭科夫原作参数。

## 表现

- 移动车辆车体耐久低于 35% 时，发动机区域开始间歇冒烟；蓝红涂装上出现不规则焦斑，钢件、玻璃与漆面分别变色。
- 摧毁瞬间分为短白黄闪光、数团橙色爆燃、贴地扩散尘雾及少量旋转金属碎片。吉普最轻、重坦最强；固定武器使用缩小的瞬时损毁效果，不持续产生车辆发动机火焰。
- 发动机残火前 4 秒较明显，第 4–8 秒逐渐熄灭；余烟前 9 秒较密，之后降低生成频率，第 24 秒停止，最后一批自然消散。
- 残骸保留原车型轮廓，显示破损机盖、焦黑斑块、下垂炮管和断履带。炮管约 1.8 秒内回落稳定；炮塔倾斜统一进入 `vehicle_dimensions.gd`，显示、射线、承托与碰撞同步，损毁 / 修复都会使几何缓存失效。
- 保留原殉爆伤害与残骸阻挡；特效不新增伤害。标记车辆殉爆事件，避免再叠加一次通用爆炸粒子。碎片是短时外观效果，飞散后消失，不增加可碰撞碎片或逐骨刚体。
- 原补给 / 修复会清除燃烧与余烟，并恢复模型及碰撞姿态。F5 重建仍保留本次启动身份。

## 性能预算

`vehicle_destruction_fx.gd` 与 `vehicle_destruction.gdshader` 使用两个启动时分配的 MultiMesh 批次：

| 项目 | 上限 / 策略 |
| --- | --- |
| 烟火 / 尘雾实例 | 192 |
| 金属碎片实例 | 64 |
| 动态绘制批次 | 2，无额外描边 pass |
| 单渲染帧新实例 | 48，超过即省略 |
| 持续燃烧 / 受损冒烟源 | 8，优先保留靠近玩家的车辆 |
| 生成范围 | 玩家周围 55 m，范围外停止生成 |
| 发射与过期清理 | 10 Hz，有界数组 |
| 运动 | GPU 解析位移 / 旋转 / 衰减，CPU 不逐粒子积分 |
| 透明与光影 | 深度测试＋网点消退，不用透明烟层排序、动态光源或粒子投影 |
| 空闲 | 无源无粒子后关闭处理 |

炮管稳定后缓存姿态，不继续更新武器后坐 / 瞄准；已毁车辆跳过车轮悬挂采样。损坏机盖在启动时建好并合并到原磨损层，损毁瞬间不重建整车网格。性能监控日志 `batches.vehicle_destruction` 包含实例、批次、发射源、上传次数与 CPU 记账耗时。

## 必要检查与边界

5,504 项独立资源 / 数学检查通过：七车型两阵营的原模型与残骸状态、炮塔显示与碰撞一致、缓存损毁 / 修复失效、密集实例池索引、单帧生成上限、计时跨 64 秒周期、全部效果过期、修复清理。30 秒孤立特效记账中峰值 80 个实例，CPU 更新 P50 1 μs、P95 62 μs、最大 218 μs；这是本机无战斗输入的单模块记录，**不代表整场帧率或 GPU 耗时**。

编译和实际启动日志另行检查。画面强度、遮挡范围及多车同时摧毁时的手感，由用户在原演武场内用 RPG / 车载炮亲自验收，不自动驾驶、开火或另建预览场景。
