# 快捷装备轮盘

2026-09-28 实现。入口仍为 `res://proving_ground.tscn`，可使用 `START_EQUIPMENT_WHEEL.bat`。

## 参考与适配

用户最新要求以《赛博朋克 2077》的快捷装备结构为主要参考，替代四个固定武器类别。采用三个自由装备槽与独立快捷物品区，鼠标方向选择、松开确认；原 2.5D 视角与线稿风格保留。

- [CDPR 官方 1.3 更新](https://www.cyberpunk.net/en/news/39092/patch-1-3-list-of-changes) 确认原作武器轮盘及拳头条目的存在。
- 三个已装备武器、独立快捷消耗品与收枪的界面组织对照 [Gamepressure 装备页](https://www.gamepressure.com/cyberpunk-2077/equipment/zbc789) 和 [武器切换说明](https://twinfinite.net/guides/cyberpunk-2077-change-weapons-how/)。后两项是第三方操作资料，不能当成原作源代码或当前所有版本的逐项承诺。
- [CDPR 官方 2.0 更新](https://www.cyberpunk.net/en/news/49060/update-2-0) 说明原作医疗和手雷改为可恢复的充能。本项目仍保留有限弹药和有限医疗数量，避免改变已有战场补给目标。
- G 为用户指定键；RPG 与手雷共享战术区也沿用用户要求。原作义体、拳击和恢复充能不在本轮复制范围，轮盘提供独立收枪动作。时间速度、治疗量及换枪秒数均为本项目调参。

## 实际操作

| 输入 | 功能 |
| --- | --- |
| 按住 G | 步兵打开六区域轮盘；车辆 / 固定武器按实际武器数显示同款轮盘。战场降至 20% 时间速度 |
| 松开 G | 确认高亮装备；中央死区松开则取消 |
| 鼠标滚轮 | 战斗时向下切下一个武器、向上切上一个，跳过空槽；开镜时同样换武器，不再调倍率。轮盘内：战术 / 医疗区域浏览物品；车载轮盘浏览武器，松开 G 才确认 |
| 右键 / Esc | 取消选择，不保存尚未确认的战术 / 医疗浏览结果 |
| 1 / 2 / 3 | 步兵对应三个自由武器位；上车后按 HUD 数字直接选择该车的武器 |
| 4 | 取出当前战术装备，包括手雷、烟雾弹、RPG 等 |
| 5 | 使用当前医疗用品；满血或没有数量时不消耗 |
| Tab | 附近有可达掉落背包时打开拾取面板；否则保留原武器库和车辆入口。选择目标武器位后点武器即可配装，也可以卸下此槽 |

六区域按顺时针依次为：武器 1、武器 2、战术、收枪、医疗、武器 3。战术区不能凭空选择未携带装备。演武场默认配装 M416 / AWM / 军刀，携带手雷、烟雾弹、RPG 供轮盘测试；其他战术装备通过原 Tab 武器库加入。正式关卡只读取原角色 loadout，不额外发放演武场武器。

正式关卡的 Tab 随身装备面板可将该士兵已有枪械 / 近战分配到三个武器位；接管队友继承其选择、剩余弹药与医疗数量。F 仍上下车，Q 不再换武器。上车后 G / 数字 / 滚轮只操作该车的武器，下车恢复个人槽位。车上不存在的数字槽无操作，不会取出随身武器或使用医疗。

## 状态与表现

- 数字键、轮盘和滚轮共用 `proving_world.equip_slot`；`quick_equipment.entries` 提供相同顺序给选择器和 HUD。保持弹匣、备用弹药、射击模式及尚未结束的射击间隔。车辆各武器的独立装填进度也保留；切换不补弹、不清冷却。重复分配同一件武器交换位置，不复制装备。
- 换枪带有取枪过渡，枪械 / 近战 / 发射器有不同取用时长；期间禁止攻击。轮盘浏览只预览，确认才切换。
- 打开轮盘取消待发连射、近战和未出手投掷；关闭后需松开旧扳机才能重新开火，恢复原鼠标瞄准位置。菜单、角色更换、上下车、死亡、失焦、销毁均撤销轮盘并恢复时间速度。按 G 后更换载具 / 角色不能把旧轮盘选择提交给新对象。
- 收枪隐藏当前武器并切回用户原始 `Armature|idle / walk / run / jump` 动画，保留自然垂手、手腕与走跑摆臂，停用持枪 IK 和瞄准扭腰；1–4 可重新取用，原武器与弹药保留。收枪 / 取枪不重置当前步伐相位，卧倒和翻越仍保留必要的空手支撑。迫击炮收起后解除架设蹲姿。
- 绷带 1.8 秒恢复 40 HP，急救包 3 秒恢复 100 HP，默认数量 3 / 1；完成治疗才扣数量，受伤、切枪、离地或攀爬会取消治疗。演武场原补给按钮恢复数量。满血不治疗；演武场默认无敌可通过原 Tab 开关关闭后由用户体验受伤治疗。
- HUD 仅新增小型 1–5 装备图标与 G 标记，医疗进度是图标周围细环；没有新增切换成功、就绪等提示浮框。
- 绘制采用单个 2D Control 与复用图集图标，无额外世界相机。未声称已通过 50 vs 50 性能实测。

本轮实现快捷配装与轮盘，不是完整背包容量 / 负重 / 地面拾取系统。此前 `backpack-design-proposal.md` 的两个枪械挂点与四分类提案已被用户后续要求取代。

### 收枪后仍保持持枪姿势的修正

用户实测指出隐藏武器后仍呈端枪姿态。原实现继续采样 `Rifle_*`（上身为固定开火姿态），再用固定手腕目标压低双手，因此仍留下握枪手腕并覆盖原摆臂。现已切回原始空手动画，并去掉站立 / 蹲伏走跑时多余的手臂 IK；未改动原骨骼、蒙皮或源动画文件。

`qa/holster_pose_check.gd` 的 69 项资源与骨骼数学检查通过，覆盖手枪、步枪、迫击炮收枪后的原始上身 / 腿脚曲线、双手位置、取放武器步伐连续性及空手跳跃 / 卧倒。待机时双手分别低于肩部约 0.44 m。仅验证数据和骨骼采样，实际画面仍由用户测试。
