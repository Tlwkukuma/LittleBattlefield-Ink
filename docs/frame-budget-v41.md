# v2026.09.28.41：替换高成本表现

用户在 v40 实战仍只有约 39–42 FPS，帧间隔 P95 / P99 30.6 / 33.8 ms，要求稳定 60 FPS 且帧耗时低于 15 ms。用户随后明确允许先删减某些效果，再用性价比更高的实现替换。本文件记录本次修改和检查，**不新增用户已暂缓的全局性能制作规范**。

## 实战依据

原始日志 `qa/performance-v2026.09.28.40-20260928-175027-612.log`；最差三个活动窗口另存于 `qa/performance/v40-worst-live.json`。

- 拥挤窗口实际约 44.8 FPS，P95 / P99 30.542 / 32.859 ms。
- GPU 中位约 7.77 ms，物理更新中位约 7.44 ms；角色、特效、批次提交同时占用 CPU。最慢一帧包含两次物理更新，合计约 20.55 ms。
- Draw Call 当时已在 42 左右，不能用继续减少少量提交次数代替降低几何、动画树、逐粒更新的成本。

## 表现取舍

1. **角色单遍墨线。** 取消角色和掉落头盔的整套外扩描边通道；保留原身体、头盔网格、原 GLB 骨架、蒙皮、纹理里的五官和衣缝，以及主材质中的法线轮廓墨线。取消主材质额外四次纹理梯度采样。外轮廓不再外扩 1.1 像素，视觉差异由用户检查。
2. **职业挂件减面。** 小背包、标记、带扣的倒角盒细分从每边 4 段降为 2 段，圆柱 16 边改 8 边；职业种类、阵营色、挂点、整体尺寸保留。共享角色几何由 39,160 减至 19,288 个三角形；掉盔几何由 7,200 减至 3,024。原身体和原头盔本体不减面。
3. **小弹壳使用专门的低面表现。** 六边截面、保留底缘、肩部、深色空口及口径长宽比，72 个三角形、单遍顶点色。省去亚像素抽壳槽和额外描边。原详细弹壳资源仍可用于独立资源用途；运行特效使用轻量网格。
4. **烟尘 / 火光 / 火花使用 GPU 平面卡片。** 原逐粒 Node3D、旋转、缩放、实例提交替换为一个最多 192 张卡片的批次。CPU 只在生成时写位置、速度、尺寸、寿命、颜色，GPU 计算运动和消退。一次画面更新最多一次数据上传。长寿命烟雾独占 48 槽，短促枪口特效不能顶掉它。装饰烟雾由球体改为带不规则边缘的平面团块。
5. **取消远处多余装饰。** NPC 普通开火保留原枪口焰、真实弹丸与命中效果，省去额外的枪口烟粒 / 小火星。玩家与车载武器保留这些反馈。NPC 抛壳只在距玩家 14 m 内每三发取一次样本，并在飞行壳较多时停止增加；玩家 / 车载武器仍依原枪型时机抛壳。弹药、射速、弹道、伤害完全不靠这些装饰计数。

## 同轮 CPU 修改

- NPC 画面插值直接加在合批实例的世界平移上，避免每帧移动源骨架根节点使所有子挂点失效。身体、头盔、挂件、枪械、枪口焰、阴影使用同一平移数据；原动作取样和物理位置继续保留。
- 人体命中胶囊记录取样时的物理原点；射线只对候选人物做一次相对原点转换，代替每画面帧重写全部肢体端点。感知头部 / 胸部也随当前物理位置移动。胶囊形状、真实射线和部位命中仍保留。
- HUD 按标签保留字形实例。数字变化只上传所属标签，未变化时不扫描 / 重建所有文字几何；菜单继续使用原控件。

人数仍为 30 对 30，Laya 关闭，物理 60 Hz、画面上限 75 FPS。真实地形、墙体破坏、实弹碰撞、原骨架与动作、分辨率不变。上限设置本身不等于性能达标。

## 检查及限制

遵循项目约定，没有自动输入、推进战斗、调用 world.step 或用截图代替用户验收。以下全部为编译、数学或冻结资源检查：

- `v41_effects_contract.gd`：4,976 项通过。包括 1,200 组平移后的胶囊射线 / 头胸位置、全目录低面弹壳尺寸、无第二蒙皮通道、300 次短促特效不新增 CPU 粒子节点、固定槽上限及寿命回收。射线浮点最大已观察差约 0.0000255 m，检查容差 0.0001 m。
- `v41_resource_contract.gd`：实际 OpenGL 下 3,692 项通过。对照原层级平移，验证身体 / 武器 / 挂件 / 枪口焰 / 阴影变换；HUD 字形顶点和 UV 回读；未变化时不上传，计数器变化不重建全部字形。
- `projectile_unit_index_contract.gd`：68,429 项通过，551 次实际几何人物命中，仿真时间和射击数均为 0。补齐测试参考代码的带类型循环替换，确保参考路径确实扫描全部单位。
- `gpu_render_contract.gd`：实际 RTX 3060 / OpenGL。基础冻结首关 26 Draw Call、1,200,584 图元；v40 相同基础检查为 27、2,622,152 图元，图元减少约 54.2%。显示尸体 / 掉盔 / 弹壳 / 弹匣 / 血迹 / 枪口焰 / GPU 平面特效 / 载具烟火 / 遮挡提示并扩大视野，最高 46 Draw Call；广视野约 2,453,836 图元。全武器目录资源替换为 45。无脚本 / 着色器错误，仿真时间 / 射击数为 0。

关键日志：`qa/performance/v41-effects-final.log`、`v41-resource-light.log`、`v41-projectiles.log`、`v41-gpu-light-final.log`。

**用户已亲自试玩并反馈“60”。** 随后读取同一窗口实战日志，近期 5 秒窗口的 P95 约 18–24 ms、P99 约 21–27 ms，Draw Call 曾达到 53。特效 CPU 多数约 0.8–1.1 ms、GPU 中位约 4–5 ms，性能改善但仍未满足 P95 / P99 ≤15 ms 与全程 Draw Call <50。原始活动记录另存 `qa/performance/v41-first-live.json`，继续由 v42 处理剩余尖峰。不能把用户看到的 60 FPS 当作全帧达标。
