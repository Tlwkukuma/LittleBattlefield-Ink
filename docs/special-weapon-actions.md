# 近战与炮筒动作

2026-09-26。入口保持 `res://proving_ground.tscn`，`START_SPECIAL_WEAPONS.bat` 默认消防斧、近景、靶兵前方。Tab 切军刀、消防斧、武士刀、RPG、反坦克发射器、榴弹发射器及便携迫击炮；左键攻击，R 装填，F1 远近。

## 问题与来源

原角色路径只有手雷的独立分支，近战仍套用步枪双手握持和瞄准；伤害在点击时立即产生，缺少动作命中窗口。火箭筒虽有偏移参数，整体仍是步枪握持 / 换弹手势。

保留用户原 41 根骨骼、蒙皮、走跑和跳跃。原文件 `Armature|slash` 为 1～159 帧；资源采样确认 25～57 帧含主要挥击。当前取这个区间的上身旋转作基础，再按各武器调整双臂、腕部与握点，不播放原片段的长铺垫、根位移和蹲跳，不改腿部曲线。

鸭科夫本机程序集只读元数据另核实 `ItemAgent_MeleeWeapon` 有 `DealDamageTime`、`AttackSpeed`、`AttackRange` 和 `CheckAndDealDamage`。本轮没有实测原作，也没有从这些符号推断具体时长或伤害数值。以下节奏及姿态为本项目设计，不声称复刻原作动画。

## 实现

- 军刀：右手短距离刺击，左手独立防护。
- 消防斧：双手握柄、上举、向前下劈、回收；保留较慢的原攻击间隔。
- 武士刀：双手握柄、身体随刀横斩，再回收；不再用左手托住刀刃。
- 近战以 `melee_action.gd` 共用的动作阶段驱动显示与命中。原伤害、范围、射速目录保留，每次攻击只对同一目标结算一次；增加挥击和接触音，继续使用原方向受击、血飞溅与死亡反馈。
- 命中检测考虑高度和实体遮挡；墙体接触读取原可破坏单元。菜单、失焦、切武器、上车、翻越、死亡等取消未完成攻击，避免稍后补伤害。
- RPG / 反坦克发射器：右肩承托，右手握把、左手托管；轻微发射冲量，枪口和尾焰仍取实际节点。装填时左手从身侧取弹，分别向前装弹 / 后部装填位置移动。
- 榴弹发射器：胸前短粗枪管、木色握把与前托，独立低位持握和装填手势。
- 便携迫击炮：静止时降低身体、底座落地，移动时平滑收起；卧倒时放低炮管。落地状态不随装填把整个底座晃进地面。
- 七类武器补上对应几何：刀刃、护手、斧头与长柄；炮口、尾口、肩垫、握把和瞄具。装填中显示独立弹体，固定部分继续合批缓存。

`special_weapon_motion.gd` 保持腕部可达限制，不能靠拉长手臂来连接握把。原 2.5D 相机、鼠标准心、枪械射击模式、弹壳和弹匣掉落保留。

当前近战采用有时序的扇形范围与三维遮挡检测，并非逐三角形的刀刃碰撞。炮筒装填是本项目手势与弹体显示，尚非完整可拆炮闩机构；没有声称使用两款参考游戏的模型、动作或音频。
