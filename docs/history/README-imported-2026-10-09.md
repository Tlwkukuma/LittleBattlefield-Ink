# 小小战地 · Godot 墨线街区

Godot 4.6.3 原生可玩样板。人物是实际的 3D 蒙皮网格；固定 45° 正交相机和地面战斗形成 2.5D 观感。色板、细线与排线参考碧海狂涛，陆战资产为本项目生成。

**当前默认入口为联合演武场**：84 项原版武器装备、7 种载具、2 种固定武器；Shift 快跑、空格跳跃/翻越、C 蹲伏、Z 卧倒、F1 动作近景、Tab 武器库、F8 场景工坊。支持局部墙体破坏、支撑崩塌、弹壳、倒地掉枪和可进入房屋。完整操作、数据继承范围与本轮测试见 [演武场与编辑器说明](../proving-ground.md)。

## 启动与操作

**当前人物已替换为用户提供的 Tripo 模型**：本机 Blender 中增加独立头盔、背包与持枪动作；演武场支持头部命中后头盔飞出并落地。文件、操作及最新测试见 [Tripo 人物说明](../tripo-character.md)。下方旧墨线人物性能数据为历史版本。

| 文件 | 用途 |
| --- | --- |
| `OPEN_BLENDER_CHARACTER.bat` | 在本机 Blender 打开可编辑小兵模型、装备与持枪动作 |
| `START_CHARACTER.bat` | 新人物近景；右键举枪，H 演示头盔脱落，F5 恢复 |
| `START_50_VS_50.bat` | 50 蓝方对 50 红方，含玩家，阵亡两秒后复活 |
| `START_GAME.bat` / `START_RANGE.bat` | 联合演武场：全部武器、载具、姿态、场景破坏 |
| `START_MOVEMENT.bat` | 直接来到训练墙前，体验快跑、跳跃和翻越 |
| `START_EDITOR.bat` | 场景工坊，载入原版地图并叠加三维属性 |
| `START_SKIRMISH.bat` | 原八人最小循环：射击、破墙、清敌、占点、重开 |
| `VIEW_CHARACTER.bat` | 人物近景，A/D 转身、空格迈步、R 试换弹 |
| `VIEW_ROOMS.bat` | 无敌军的室内漫游，WASD 从门洞进出 |

脚本使用本机已有 Godot，可用 `GODOT_EXE` 指定其他 Godot 4.6 可执行文件，也可导入 `project.godot`。无需额外素材下载。

旧八人/百人场景操作：WASD 移动，鼠标瞄准，左键射击，R 换弹，滚轮缩放。F1 人物检查，F2 切换八人/百人战场，F3 屋顶显示，F4 进入/退出室内漫游，F5 重开，M 静音，Esc 暂停。失去窗口焦点自动暂停。演武场的操作见上方新说明。

百人模式是持续交战测试，保留 100 个实际角色槽位。界面显示双方实际存活人数；AI 主要寻敌、横移射击和寻路，还不是完整小队战术 AI。

## 动作与室内

`scripts/soldier_motion.gd` 分离位移步态、腰部转向、上身瞄准、后坐力、换弹和手臂 IK。步态随实际移动距离推进，启动/停止有加减速，腿部 IK 与踝部补偿控制落脚，上身独立瞄准。换弹包含支撑手离枪、腰部取弹匣、送至弹匣口、返回握持。

这是参考公开射击游戏架构的原创程序动作，未导入商业游戏动作文件，尚未达到动作捕捉质量。演武场已增加蹲伏、卧倒、匍匐、独立颈部、落脚固定、快跑、跳跃和翻越。支持障碍顶面落地与走下后下落；暂无手指动画、悬崖攀爬和连续斜坡地形落脚。

当前 Tripo 角色保留原 FBX 的 **41 根骨骼、原蒙皮权重和 20 段动画**；走路、跑步和待机使用原动作，持枪只叠加上半身姿态，保留原脚踝与脚趾动画。身体保持原来的 9688 个三角面，头盔与背包独立附着。远处 AI 骨骼交错按 30 Hz 更新，位置每帧更新。旧 15 骨骼绑定及程序军装作为历史备份保留，当前入口不再使用。

三栋房屋有 1.6 米南北门洞、隔墙通道、木地板、床、桌面电台和物资架。`scripts/house_layout.gd` 共享墙体和主要家具的渲染/碰撞布局；隐藏视效不取消墙体挡弹。窗户暂不可穿越。

F3 循环：**自动切顶（推荐）** → **常驻无顶** → **屋顶淡化**。自动模式在入室或遮挡玩家时渐隐屋顶及上半墙，保留低墙轮廓；退出恢复。淡化模式保留约 12% 抖动透明轮廓，采用像素丢弃避免半透明排序问题。暂无楼层、楼梯、室内视野迷雾或可开合门扇。

## 性能与验证

本机 i5-12400F / RTX 3060，1440×900，Godot Compatibility，2× MSAA，关闭 VSync。预热 3 秒，采样约 15 秒真实窗口渲染：

| 场景 | 平均 FPS | P95 帧耗时 | 实际存活人数 | 平均绘制调用 |
| --- | ---: | ---: | ---: | ---: |
| 50 vs 50，两秒复活 | 126.5 | 11.39 ms | 68–85，平均 76.7 | 1079 |
| 压力测试，即刻复活 | 105.8 | 15.57 ms | 全程 100 | 1120 |

这是本机当前地图的短时结果，不代表低配硬件或更大场景。严格模式 P99 为 19.20 ms，不能称为全程锁定 60 FPS。普通模式与全员存活模式分开报告，避免死亡等待降低负载造成误导。

详细来源和数据见 [实现与性能报告](../animation-rooms-performance.md)。原始采样在 `qa/crowd100-benchmark.json`、`qa/strict100-benchmark.json`；本地生成的采样和截图不纳入 Git。
