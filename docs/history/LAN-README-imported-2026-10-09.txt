小小战地 · Windows 局域网加入包

1. 将整个 ZIP 解压到一个文件夹。不要只运行 ZIP 内的单个文件。
2. 房主首次在此文件夹运行游戏时，双击「允许局域网联机.cmd」，在 Windows 管理员提示中允许。此工具仅放行同文件夹游戏的 UDP 27829 / 27830，来源限私有局域网。换文件夹后重新运行。随后在游戏首页进入「战役」，再点右上角「战役菜单」→「加入队友战役」→「开放当前战役给队友」。
3. 队友双击「加入小小战地.cmd」，点「浏览局域网房间」，在游戏中选择房间并加入。也可填写房主显示的 IPv4 地址，点「立即加入」；手动地址会记住。
4. 房主继续原战役，队友接管一名存活蓝军。最多五名队友。不同版本按已确认的协议兼容；实时同步优化双方至少 v53。本包版本见 VERSION.txt 和游戏窗口标题。

v53 修复队友被误按 AI 半频更新的问题，并加入本地移动 / 瞄准呈现、30 Hz 实时状态和可靠快照排队限制。实际伤害、命中、弹药与破坏仍由房主决定。若仍有卡顿，在队友窗口打开 Debug，查看“局域网：输入回声、自身更新、当前断档”，可用于区分网络等待与画面帧率。

v54 加入使用游戏内 IPv4 通道，处理透明 UDP 链路改写回复端口造成的 ENet 丢弃；不需要关闭 VPN 或安装额外转发程序。先确认游戏端口可达，再离线准备关卡，最后建立正式战役连接；无回复时 8 秒超时并明确提示，失败返回菜单也不再反复重建关卡。连接阶段记录在 %APPDATA%/Godot/app_userdata/小小战地 · 墨线街区/lan-connection.log。

游戏端口为 UDP 27829，房间搜索使用 UDP 27830。若搜索不到房间，先检查双方处在同一可互通的局域网、房主是否已开放战役，以及 Windows 防火墙是否允许这两个 UDP 端口。跨网段可使用手动 IP 加入。
v56 左上角常驻 FPS / Ping。Ping 是 ENet 可靠包真实往返统计；房主显示队友中的最大值，未连接显示 --。同步断档超过 250 ms 会显示“同步等待”，因此 FPS 高但数据迟到也能看出来。IPv4 收发不再额外等待一帧，同一帧积压的自身状态只校正最新一份；已准备的第一关重连不再重建。双方建议使用同一 v56 包，仍兼容 v53–v55 同步协议。连接日志每 5 秒记录网络等待和处理成本。
可直接双击 LittleBattlefield.exe 打开普通首页；无需安装 Godot。
v58 修复联机子弹断续：普通子弹独立每秒 30 次更新，短距离命中、在完整快照之间消失的子弹也会发送真实终点；接收后按连续时间显示、重复终点不重放。自己开枪的确认特效也不会被背景战斗配额挤掉。房主和队友都必须换成 v58，才能使用完整的弹体连续性修复；连接旧房主仍兼容，但不能补回旧房主没有发送的短命弹数据。
v57 包含上述 FPS / Ping 和同步优化，并修复远端车辆车体固定朝向滑动：真实车体姿态、前轮转角一起同步。队友 v57 连接旧房主也能恢复车体方向；双方 v57 才能使用完整实时姿态与前轮转角。建议两台均使用本包。
