# 壕沟表面平滑 · v2026.09.29.39

用户截图中的土坡三角色块来自地形每个三角面独立取色、使用面法线。壕沟及相邻草土边缘现在使用共用格点颜色与已有平滑法线，消除同一点在相邻三角面上出现不同颜色 / 明暗的拼接。保留地形明暗、沟底颜色和土堆起伏；雪地沿用平滑法线并共享顶点颜色，山体仍保留原分面。

只改启动时的网格颜色与法线烘焙；原三角形顶点、数量、地形材质 shader、绘制表面数、真实高度、坡度、梯子、挡弹和通行保持。没有新增每帧计算、采样纹理或第二层覆盖网格。颜色和标志数组仅网格生成时临时使用。此轮解决三角面色差与硬色块边沿，未增加几何细分，原坡面轮廓分辨率仍受现有格网限制。

检查：`trench_surface_contract.gd` 验证 6,000 个三角面数量不变、936 个壕沟共用格点的颜色 / 法线一致、显示顶点仍等于物理高度；`terrain_relief_contract.gd` 回归真实沟深、地形与梯子。壕沟掩护检查只对可游玩格网比较物理高度，排除其他任务新增、附加在网格末尾的边界外背景山环。
