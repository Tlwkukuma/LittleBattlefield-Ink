# 机枪瞄准与支撑稳定（v2026.09.29.26）

## 本轮修正

- 固定重机枪原先只有水平转动，未按鼠标目标高度调整俯仰，却继续叠加枪口上扬。新增围绕 1.16 m 枢轴的俯仰节点，范围 -35° 至 60°；枪体、实际枪口、握点、抛壳口、装填接触和机匣命中包围同步。弹道直接读取物理枪口方向，后坐只计算一次。
- 处理缓存优先使用 `mounted_fire_key`，避免同名车载武器共享错误的手持参数。固定和车载机枪原先持续射击可爬升至通用 0.26 rad 上限，现改用独立参数并在连射时持续回稳。
- 枪座状态同步乘员瞄准及车辆速度；右键稳定和行驶散布正常参与计算。

| 项目 | 固定机枪 | 车载机枪 |
|---|---:|---:|
| 单发基准俯仰冲量 | 0.085° | 0.12° |
| 最大累积上扬 | 0.75° | 1.0° |
| 连射回稳系数 | 4.0/s | 3.2/s |
| 腰射散布半角 | 0.003 rad | 0.004 rad |
| 聚焦散布半角 | 0.0018 rad | 0.0025 rad |

这些是本项目游戏参数，不是真枪测量数据。自动炮、主炮、迫击炮保持各自后坐。机枪仍有短促机件震动：车载 8–12 mm、固定重机枪 12 mm；固定机枪操作员受力幅度降为原来的 45%。

## 支架卧倒

采用原武器 `mechanics.model.bipod` 标记及现有 heavy 枪族模型规则，与可见支架一致。必须实际卧倒过渡完成、在地面、速度低于 0.12 m/s，且未翻越、攀爬或乘坐，才在约 0.29 秒内逐渐建立支撑。

- 完全支撑后的角冲量为站姿基准的 18%；此前普通卧姿为 56%（瞄准另乘 0.9）。
- 完全支撑后额外散布乘 0.60，单发散布增长乘 0.35；连射回稳 2.4/s，累积上扬限 0.030 rad。
- 枪身和肩部视觉受力同步减弱；爬行、起身或离地立即撤销支撑收益，再次停稳才重新建立。
- 准心仍固定鼠标位置，不追踪人体，不吸附头胸；保留真实地形与掩体挡弹、车辆枪架原机械俯仰范围。

## 性能与验收

复用原处理缓存、物理枪口与骨骼更新；每座固定机枪仅增加一个变换节点，不增加逐发节点、射线或特效容量。机匣包围根据当前俯仰更新，无全场扫描。

沿用 `res://proving_ground.tscn` 联合演武场及 Tab「车辆 / 固定武器」→「立即试驾 / 操作」。可对比固定机枪、吉普机枪、坦克同轴机枪长点射，以及 M249 / MG3 站立、卧倒停稳、爬行时的差别。仅做编译、导出、启动检查；命中率和实际手感由用户试玩确认。
