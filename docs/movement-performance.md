## 验收目标和当前证据

用户在 v2026.09.28.10 反馈最低 38 FPS，旧用户交战日志也出现 36–55 FPS。这是未达标结果，不能用暂停 60 FPS 覆盖。目标仍为首关移动、转向、交火 Draw Call < 50，稳定 60 FPS，并尽量保留原画面。

新实现的真实 RTX 3060 OpenGL 资源检查中：初始战斗画面 24 次；冻结原场景叠加下列资源，镜头 size 22 时 39 次，size 44 / 96 时 48 次。读数来自 `Performance.RENDER_TOTAL_DRAW_CALLS_IN_FRAME`，包含当时可见的 3D 和 HUD，没有扣减、伪造面板数字。

- 原 60 人、18 具原骨骼尸体、12 个头盔、全部 60 枪口焰。
- 120 枚六种原口径弹壳、6 个弹匣、30 个带原描边的伤害数字。
- 血花和地面血迹、原玩家遮挡轮廓及脚底标记、飞行子弹、掉落背包。
- 载具烟火及碎片两个批次、普通爆炸球体与碎片。

脚本 `qa/gpu_render_contract.gd` 只实例化原 `proving_ground.tscn` 并检查显示资源，`world.time=0`、`shots=0`，没有调用世界步进或模拟玩家输入。**以上证明该资源组合低于 50；不是完整对局的最高 Draw Call，也不是稳定 60 FPS 证明。** Tab 配装和其他交互菜单仍用原生控件，菜单 Draw Call 不在这组战斗画面测量内。换装新枪、狙击/投掷界面、破坏重建等实际组合仍需用户试玩日志验证。

最终移动帧率尚未验证。上一验收窗口 v27 / PID 7932 一直 `active_play=false`、移动样本为 0；其暂停 60 FPS 不算通过。运行日志增加移动帧间隔 P95/P99/最大值、交战逐帧 Draw Call 最大值和各阶段耗时，用来定位用户实测长帧。

## 实现

- 玩家、弹丸和载具保留 60 Hz；59 名 NPC 按奇偶 ID 分配到相邻物理步，累计原 30 Hz 时长，原兵力不减少。AI 感知、掩护/路径与脱困共享预算并继续上次搜索；受阻恢复不因微小位移反复清空搜索。单位空间网格与小范围实体索引减少全量扫描，窄相碰撞和实际地形结果保留。
- 玩家骨骼每帧更新；NPC 原动画在屏内 24 Hz、屏外 6 Hz，以真实模拟时间插值显示。姿势有共享预算，原胶囊、手部和枪口计算保留；原动画 seek / advance 避免重复求值。
- `crowd_batches.gd` 复用原身体蒙皮、UV、头盔、五职业挂件和红蓝颜色。一个共享网格、原着色/描边两个通道，影子另一个批次。屏外实例从提交列表移除，留足屏幕外边缘余量；回来后恢复同一模型，不用低模替换。合并挂件会增加模板内顶点数，未选中的职业三角形被折叠，不能把 Draw Call 降幅等同于 GPU 时间降幅。
- 枪械/载具刚性部件和整件树岩共用矩阵纹理与原材质组；静态物件存活可见性变化只更新矩阵，不重烘整个树林。真实局部墙破坏仍使用原网格，四分区只重建受影响区。同步墙体重建仍是待实测长帧风险。
- 弹壳和弹匣把原始网格顶点/法线/颜色放入共享图集，各自一批；Compatibility 的半精度实例数据用拆分整数坐标避免精度丢失。落地后停止运动和重复上传，地面破坏/载具支撑变化时唤醒，数量上限和原口径比例保留。
- 枪口焰、伤害数字、普通 FX 共享批次；18 具尸体预热复用，原骨架姿势不替换。启动预热零面积实例，减少首次射击/换弹编译抖动。
- 战斗 HUD 保留原控件的布局/输入/文本，用共享形状网格与原字体位图图集绘制；伤害描边沿用原字体。返回菜单恢复原生绘制。普通字体纹理在当前 OpenGL 下比 MSDF 字体更适合这组批次，未降低窗口分辨率或 3D 渲染比例。
