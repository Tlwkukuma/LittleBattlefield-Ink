# 死亡背包与附近拾取

用户要求将地面掉枪统一改为背包，并参考 PUBG 靠近后按 Tab 拾取。入口仍为 `res://proving_ground.tscn` 联合演武场。

## 参考与本项目选择

- [PUBG 官方支持](https://support.pubg.com/hc/en-us/articles/115004201094-How-do-I-drop-items) 确认 Tab / I 打开库存及地面武器转移。
- [PUBG 官方 42.2 更新](https://www.pubg.com/en/news/10459) 的基础训练包含死亡盒拾取与装备附件。这里只参考死亡容器和库存交互，不声称取得其资源或复制其全部背包规则。
- 本项目按用户要求使用布制背包外形。物品数据与尸体、模型分离，尸体清理 / 复活不补满包内物品。

## 操作

- 地面背包内保存死亡角色携带的枪械、近战、战术装备、实际余弹与医疗数量；不生成完整掉枪模型。
- 同层约 2.2 m 范围内、无实体遮挡时显示简短 `Tab 背包`。Tab 打开两栏面板，左栏是附近背包，右栏是随身装备。
- 点击逐项「拾取」或「全部拾取」；物品原子转移，清空后背包消失。取到新枪不会强制换掉手上的武器，有空槽时放入空槽；右栏可选择 1–3 槽后「装备」。战术武器沿用独立选择区。
- 同款武器记录携带数量，弹药合并进该型号的备用弹药，避免生成多个武器模型。现有快捷槽仍按武器型号管理，同型号不会复制到多个快捷槽。本轮未加入重量、格子容量、附件拆装或拖拽丢弃规则。
- Tab / Esc 关闭；没有可达背包时，Tab 仍打开原武器 / 车辆面板。拾取面板也保留一个进入原面板的按钮。
- 拾取面板不暂停战场，阻断移动、瞄准、开火、换武器和交互输入；关闭后旧鼠标扳机不能误射。超距、死亡、换角色、上车、失焦、重置均关闭或使转移失效。每次转移重新检查距离、高差及遮挡。
- 正式关卡拾取同步添加实际装备所有权，后续 G、数字键、滚轮、配装和角色接管均读取相同库存。

## 性能与边界

- 一个共享 492 三角形、单表面背包网格；一个 `MultiMeshInstance3D` 绘制所有地面背包。不创建逐包刚体、碰撞形状、灯光、动画或逐武器节点。
- 最多保留 128 个地面背包；达到上限时优先清理最旧的远处背包，全部位于近处时清理最旧项。没有额外按时间过期逻辑。场景重置同时清除数据和批次。
- 静止状态不每帧检查地面。只有拓扑变化时，每 0.1 秒最多处理 4 个背包的承托检查；楼板破坏后包移到剩余真实表面，支持负海拔。
- 附近提示 10 Hz，最多对两个距离候选检测遮挡；打开面板后 0.15 秒复核可达性。物品列表只有库存内容变化才重建，武器图标复用图集。
- 尸体、血迹、弹壳、弹匣及帽子脱落保留。本轮减掉的是地面枪械实例，并未声称完成 50 vs 50 帧率实测。

## 检查

`qa/loot_bags_check.gd`：36 项库存、距离 / 楼层 / 遮挡、正式关卡所有权、重复点击、重复死亡、复活隔离、背包数量、承托、共享网格、致命伤害接入和原生界面资源检查通过。未自动操控游戏或做截图验收；用户在同一演武场射击目标后靠近背包亲自测试。
