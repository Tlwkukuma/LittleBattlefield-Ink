# 同视角圆镜与按住右键扩大视野

用户于 2026-09-28 明确：**常规视野固定；右键扩大可见战场范围，狙击也先扩大视野。** 此前把“放大”实现为拉近目标、缩小可见范围，与这次要求相反，现已修正。同一个 2.5D 正交主相机增大 size，保持俯角、朝向、目标高度拾取及鼠标坐标规则，圆镜继续跟随鼠标。

## 操作

- 狙击枪：按住右键先扩大范围，视野过渡完成约 72% 后才开始淡入圆镜；AWM 默认可见宽高为常规的 2 倍，DMR 1.5 倍。松开恢复当前场景固定的常规视野。
- 按武器配置使用 1.25 / 1.5 / 2 / 2.5 倍**视野范围**；按用户后续统一切换要求，开镜滚轮改为换武器。例如基础 size=20，AWM 为 40，2.5 倍为 50；数字表示可见范围，不是目标放大倍率。屏幕直接显示“视野范围”。
- 普通步枪、霰弹枪和机枪：右键扩大到 1.25 倍范围；手枪、冲锋枪 1.15 倍；发射器 1.18 倍。这些枪不加圆镜。
- 战斗滚轮（含开镜）统一切换武器，不改变视野；F1 仍是演武场手动近景检查开关。编辑器仍可滚轮缩放，退出编辑时恢复进入前的战斗视野，避免编辑缩放带入试玩。
- 近战、投掷、迫击炮和载具不启用这次的举枪缩放。
- V 保留为可选的狙击开关。按住右键会改回持续按住模式，随后松开右键退出。
- 装填、切枪、翻越、乘车、菜单、暂停或死亡会中断瞄准；右键仍按住时，须松开重按。圆镜、分划和文字不接收鼠标事件。

## 画面与手感

1. **镜内仍是当前战场。** 主相机拉远，单层不采样屏幕纹理的 UI shader 负责镜外压暗和边缘柔化，不添加额外世界相机或镜内第二遍场景渲染。镜外压暗由 0.84 降为 0.56，扩大后的外围战场仍可辨认。
2. **缩放围绕目标。** 按下右键时，冻结当时鼠标投影锚点。缩放过程中该射线上的不同高度/深度保持原屏幕位置；鼠标继续移动不反过来牵动相机。角色移动的镜头跟随仍保留。
3. **圆镜准确跟随鼠标。** 圆心不向屏幕中央吸附，不人为夹住圆心后让目标滑出镜内；靠近屏幕边缘时圆镜边缘会自然被屏幕裁切。圆镜半径约视口短边的 32%，限制在 110～420 像素。
4. **准星和圆镜始终跟随同一个鼠标位置。** 按用户最新要求，取消预测落点牵动准心、橙色遮挡提示和额外落点标记。准心表达操作意图，散布只影响线条间隙，目标远近和镜头倍率不改变其尺寸。子弹仍按真实枪口、后坐、散射和碰撞计算；屏幕准心不承诺子弹必然到达该位置。保留确认命中的短暂 X。
5. **退出迅速恢复。** 进入和退出分别采用 14 / 18 的指数收敛系数，无等待长按成立的额外延迟；右键保持按下期间持续瞄准，松开即开始退出。不会覆盖原基础缩放设置。

以上倍率、遮罩尺寸与动画速度为本项目调校值，不是照搬原作参数。[PUBG 官方操作说明](https://support.pubg.com/hc/en-us/articles/360002074913-What-are-the-basic-game-commands) 将按住瞄准和点击 ADS 分开；这里只参考持续输入与明确退出的交互组织，按用户要求采用固定 2.5D 和跟随鼠标圆镜，不切第一人称。

## 实现与验证

- `scripts/scope_view.gd`：右键/V 状态、主相机缩放、平面镜框与分划。
- `shaders/scope_mask.gdshader`：圆形透明窗口、镜外压暗、柔边；使用 [Godot CanvasItem shader](https://docs.godotengine.org/en/stable/tutorials/shaders/shader_reference/canvas_item_shader.html)。
- `scripts/weapon_reticle.gd`：每帧采样绝对鼠标位置，普通准心和圆镜共用该样本。圆镜开启时关闭重复的普通 HUD 准心；保留细十字和中心点，见 [简洁准心](reticle-design.md)。
- 构建 2026.09.28.5 将左上角聚焦文字迁入统一 [战斗提示](combat-hud.md)：准心旁显示进入 / 就绪 / 回稳，右下角显示聚焦和当前视野范围；圆镜本身只绘制遮罩与分划。
- `qa/precision_camera_check.gd`：72 / 72 通过，涵盖多分辨率与深度的投影锚点、扩大过程无拉近帧、变范围、移动跟随、快速重开、按住/释放/中断/UI 防透传、圆镜延后淡入、普通枪无圆镜及退出恢复固定视野。
- 演武场启动检查通过。没有自动操控游戏、开火或截图验收，实际瞄准观感由用户测试。

运行 `START_SCOPE.bat`，在同一个联合演武场默认装备 AWM。Tab 切 M416 对比普通枪右键扩大视野；左键开火、右键按住、滚轮切武器（同时退出当前开镜）、R 装填。窗口标题为“小小战地 · 右键扩大视野”。
