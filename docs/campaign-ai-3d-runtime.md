## 当前运行行为

| 层 | 实现 |
| --- | --- |
| 补兵 | 保持每 0.5 秒每队最多 5 人、30 人上限和有限预备兵。每三名成功增援共享批次锚点与路线；出生检查实体净空、敌距保护和当前可达的 CaptureZone 入口。失败不扣兵力。 |
| 身份与编组 | 原网络单位 ID 不变，另加 `spawn_epoch` 和增援批次。默认三人组保留存活成员与任务，附近同批、可通行成员才加入。玩家、远程人类与乘员预约排除；同任务、同路、同计划的附近残队每次最多合并一对。 |
| 合法攻守目标 | 使用当前占领多边形、高度与站立净空中的连通网格点，分散终点。图修订时分片更新连通分量，暂时保留有效旧命令，不用每个出生候选重新 A*。 |
| 掩护交接 | `idle → deploy → bound → handoff → idle`。有目视报告和实际开火、弹药/装填/姿态可用，才允许同伴移动到已检查并预留的短段终点。暴露段最多 3 m，有掩体候选最多 5 m。所有移动者实到 0.5 m 邻域且接地、新支持者射界可用后交接。 |
| 失败回退 | 部署最多 3 秒，移动最多 5 秒。失去支持、装填、伤亡、严重来火、站位冲突或超时释放协同承诺，回到原局部掩体/寻路恢复；一人残队不反复尝试双角色循环。 |
| 效果证据 | 实际开枪只算火力活动。只有当前生命代次的射手与目视报告中的目标代次匹配、命中事件新鲜且属于相关威胁，才标记 `observed-hit`。不把枪响等同成功压制，不读敌方隐藏压力决定成功。 |
| 姿态与射界 | 真实头部、枪口、材料能力共同评价站/蹲/卧。实体中伸出的枪口不得支持开火；友军挡线时暂停。姿态至少保持 0.8 秒，紧急压力例外；卧移按 0.62 m/s 基准缩放，坡度和实体净空仍检查。可见脚架只有实际卧倒、停稳才提供稳定。 |
| 近弹压力 | 对实际飞行且露出实体的子弹段，使用现有人体空间索引与缓存胸部点检查近弹。每目标/射手生命代次至少间隔 0.12 秒，最多 16 条压力时钟。不再在开火前扫描所有敌人、对隐藏身体施加近弹压力。 |
| 材料穿透 | 独立于旧人体穿透次数。枪弹读取已编译材料预算，以实际实体入/出口、厚度及射角消耗剩余预算，逐层衰减伤害；最多 4 层。穿透后查询只到该实体出口，再重新检查同建筑后续部件、其他物件和人物，不瞬移子弹、不忽略整栋房屋。 |
| 局域网 | 房主决定战术与物理。原快照字段增加生命代次及弹体穿透状态，沿用 v53/v54 的独立输入/运动通道与分包；不让客户端另行指挥。 |

材料禁破、局部墙格伤害和支撑坍塌保持原来源。地形、车辆不获得隐式材料穿透；枪管真实受阻的近距离接触预算为零。树干/自然凸体使用实体出口，家具/住宅使用各部件出口，金属围栏仍只查询穿过的墙格杆件，不全量遍历焊接网丝。

## 三套首关计划

- **T01 西门推进 · 双翼支援**：主路与两翼约 50/25/25；主组通过原西门，两翼在现有路线形成射角。有近期关联命中或到位等待结束后接续攻点，不永久停留。外圈部署时间有 32 秒回退，到岗位后等待最多 8 秒。
- **T02 东墙破障 · 主路牵制**：主路继续推进，仅一个具备现有手雷的组接近当前东墙合法位置。指定一名投掷者，验证真实弹道和友军/自身爆炸安全距离；轨迹只读扫掠按现有预算分次完成。实际破口足够站立人物通过后向内侧进入，至少一名成员实际接地到位才派一个接续组。最多两组承担破口角色；接续等待最多 12 秒，首次破障尝试整体最多 24 秒。弹药耗尽时等待已投手雷的引信窗口，再按真实结果通行或改走西门，不生成免费炸药。
- **T03 壕沟接近 · 林翼迂回**：主组强制经过当前西侧壕沟/林地的既有路点，不因据点直线近而跳过；两翼仍支持和接续。沟深、坡口、挡弹和姿态继续按真实地形处理。

红军大部分小队保持区内守备，两翼各至多一个组。附近墙体破裂只能先产生局部关注；每物理帧最多一个结构观察，占用原至多四个视觉候选中的一个名额。观察有视角与实体遮挡检查，站立通道成立后才生成目视报告。只调最近守备组转向和移到占领区内邻位，其余职责保持；听到破墙不等于已确认通道。

原吉普通过主路真实驾驶/避让/倒车，按附近主组的进度分段前出或停靠支援；与步兵失联时有界等待。两座固定机枪保留原位置、朝向和机械射角，不能追踪转角外目标。中立归属、真实乘员、有限弹药、上下车继续复用原机制。

地图仍为布局第 7 版，原斜路、原吉普/两座机枪、连续 2.2 m 南墙、唯一预置西门与占领多边形均保留。蓝军完全占领 B 仍立即胜利，不暗加长时间占领后守备。

## 调度与诊断

两队命令错开更新，每队约 0.65 秒。个人思考仍为约 0.30–0.52 秒，NPC 仍按原交错物理调度。命令、图连通修订、姿态、破障预览共用原 1000/2000 μs 决策预算；保留每帧至多两次寻路、一次掩体搜索及原恢复配额。姿态评价最多约 450 μs，破障轨迹每次最多 12 段/约 350 μs，候选超预算保留到后续决策。

这是实现工作边界，不是新增全局性能规范，也不保证所有原子查询绝对不越界。没有增加常驻模型/相机/特效批次。常规 HUD 保持简洁，Debug 概览打开才构造战术与阶段计数文字。
