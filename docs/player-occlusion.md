# 主角遮挡提示 · v2026.09.28.24

高住宅把屋后的主角完全盖住时，现在出现随原动作移动的淡蓝剪影和脚下细环。只对本地玩家绘制，不显示被墙挡住的敌人、家具或其他楼层。没有改变室内判定、屋顶显示、准心、弹道、碰撞或墙体破坏。外梯、平台和阳台仍算室外；剪影不是可射击或穿墙通行的提示。

## 实现与性能边界

- `player_occlusion.gd` 在房屋可见性更新之后，按真实相机投影检测主角胸、头、脚附近三个点。每 0.1 秒至多一次、每次至多三条已有空间索引射线，命中即停；长帧不补跑积压查询。使用实际骨架缓存和渲染插值偏移，不增加动画采样或 IK。死亡、封闭载具、场景编辑和离屏立即停用。
- 显示采用两份只共享网格 / Skin / 原 Skeleton3D 的 MeshInstance：身体与可摘头盔，共 10,744 三角形；脚下环固定 64 三角形。没有第二份骨架、动画播放器、世界相机或渲染世界的 Viewport。主角在首关仍参加原人群批次，提示节点使用自己的绘制层。
- 启用时额外三个网格节点、五个表面绘制（原身体 / 头盔含多个表面，启动日志已核对）；关闭后全部隐藏，不提交额外可见几何。淡入 120 ms，清晰状态保持 180 ms 后淡出 220 ms，降低门沿附近的反复开关。每帧深度比较只给实际被遮挡的主角片元上色，已经露出的身体不覆盖蓝色。
- 深度采样复用当前世界的深度，启用时仍有透明混合、蒙皮顶点变换及可能的全尺寸深度解析/复制成本，不能说 GPU 成本为零。Shader 按 [Godot 4.6 深度文档](https://docs.godotengine.org/en/4.6/tutorials/shaders/advanced_postprocessing.html#depth-texture) 处理 Compatibility 的 NDC，再换回视空间米数比较；不依赖硬编码正/反向 Z。
- 脚下环复用原角色阴影的真实承托高度，不额外查地面，不锁在 y=0。角色与枪械原来的视觉材质保持独立；不扫描所有敌人或逐帧修改整栋房屋材质。
- `--performance-log` 在既有日志中增加 `last_frame.player_occlusion_ms`。`--startup-watch` 记录本次是否激活、可见表面数和查询计数。
