# 地图原点阴影闪烁修复（v2026.09.29.5）

用户在第一关道路交汇处看到固定灰影闪烁。静态资源检查复现了载具阴影的网格与变换不同步：

- `vehicle_style.gd` 创建局部 PlaneMesh；首关/演武场2的 `rigid_batches.gd` 在初始化时缓存它并关闭原节点渲染。
- `vehicle_ground_effects.gd` 随后生成真实地形承托的世界坐标网格，并将节点变换设为单位变换。
- 合批只同步变换，没有更换缓存网格，导致旧平面出现在地图原点 y=0，与地形共面。
- 首关修复前实际打印：缓存包围盒中心约 `(0,0,0)`，原节点新网格中心约 `(18.30,0.016,23.35)`。地图原点对应原布局 `(1650,1050)`，位于农场横向土路南侧。

修正：动态贴地阴影标记 `dynamic_geometry`，刚体静态网格合批在注册时排除该类资源，由原节点绘制最新网格。车身、炮塔、轮履仍沿用现有合批；阴影仍仅在车体变换变化时更新。旧实现每车已有独立阴影批次，因此此处是一进一出，不新增阴影渲染通道。

检查：`qa/vehicle_shadow_contract.gd` 修复前首关 3 项失败，修复后首关 8/8、演武场2 20/20；原实例资源回归 364/364。全部检查冻结游戏，世界时间和射击数均为 0。验证网格身份、阴影位置、渲染路径和静止不重建；闪烁消失由用户在实际窗口验收，不以静态检查冒充动态观感或实战性能测量。
