# 爆炸武器特效 · v2026.09.29.20

## 第二轮重做：成熟项目参考与实施

用户指出原爆炸随意、弹坑像纯色椭圆。本轮移除 `proving_fx.decal()` 的压扁球体实现，仍在原联合演武场 / 第一关交付。

### 参考依据

- [War Thunder，Hornet’s Sting 官方开发说明，2025-03-14](https://forum.warthunder.com/t/hornet-s-sting-improvements-and-new-features/220585)：按弹药威力、口径和土壤 / 雪 / 沙地组织向上喷散的泥土、碎石与烟尘。本项目采用分层节奏及地表配色，不复制资产，也不声称获得其源码。
- [War Thunder，Dagor 6.0 官方说明，2020-11-16](https://warthunder.com/en/devblog/current/6946)：命中痕迹区分弹种、口径和表面，包含坑口、崩边与积碳。本项目据此将焦土中心、内壁明暗、翻土缘与外围散土分层。

### 当前实现（覆盖下方第一轮同名描述）

- 起爆：85 ms 暖白爆闪；机关炮 / 榴弹 / 手雷火焰 100–160 ms，主炮 190–300 ms，燃料约 620 ms。随后是短促定向喷土、抛散碎片、延迟上浮烟团与贴地滚尘，不把所有弹种做成同一大火球。
- 动态烟火改为两三角面片的朝向相机体积明暗，GPU 程序噪声侵蚀轮廓、内部滚动和消散。喷土沿发射方向拉长并受重力回落，墙面接触把水平运动偏到外侧。无需外部图片、动态灯、刚体或额外世界相机。
- 地面残留由 `blast_marks.gd` / `blast_mark.gdshader` 管理：不规则坑缘、凹面明暗、焦土中心、细裂隙、碎土颗粒；浅翻土边最高 3.5 cm。按真实地形的原三角形细分贴附，陡壁跳过；不画漂浮的水平椭圆。
- 残留大小区分机关炮（半径上限 0.36 m）、榴弹（0.52 m）、手雷（0.70 m）与主炮口径。烟尘和残留共同读取 `blast_surface.gd` 的雪、沙、红土、硬地配色。
- 仅低于地表上方 0.65 m 的地面爆炸留痕；排除朝向不合适的墙面以及金属 / 木 / 玻璃接触，不在高空、屋顶或装甲下方盖弹坑。持续烟雾弹与载具殉爆仍由原独立系统处理。
- 弹坑为浅表视觉凹痕，未修改真实地形高度、通行、掩体、伤害或弹道；不能把它描述为可驶入的动态深坑。

### 性能界限与验收边界

- 动态效果仍为 2 个 MultiMesh / 480 槽，112 装饰 + 12 爆闪写入预算不增加，保留 32 / 64 m 降级及屏外剔除。新增喷土与烟尘共享原容量。
- 弹坑合并为 1 个绘制对象，最多 64 处，近点重复命中合并，66–90 秒渐隐。每帧至多烘焙一个新足迹，等待队列最多 3 个，整批网格上传最多 10 Hz；旧顶点、颜色和时间数组缓存复用。空闲关闭更新，重置清空。
- 不再每坑一个 Node、不保留原 100 个压扁球体。着色器预热使用零面积几何，不自动触发爆炸或开火。
- 完成必要脚本 / 资源编译、现有入口启动核对；没有自动进行战斗、截图验收或压力测试。新增噪声着色和残留几何仍有 GPU 开销，连续轰炸画面与帧率由用户实际试玩确认。

## 本轮调整

所有武器仍从 `proving_world.blast()` 发出同一爆炸事件；`explosion_fx.gd` 与 `explosion.gdshader` 负责表现。实际伤害、半径、掩体遮挡、墙体破坏与人物冲量不变。事件附带来弹方向，供火箭爆炸塑形。

| 弹种 | 表现 |
| --- | --- |
| 机关炮爆破弹 | 小而短的亮芯、少量烟尘与碎屑，适应连续命中 |
| 手持 / 车载榴弹 | 短促爆闪、紧凑火团、快速扩散土尘 |
| 高爆手雷 | 短火光、放射碎屑与贴地尘团 |
| RPG / 反坦克火箭 | 来弹方向偏置火团，延迟展开烟团 |
| 便携 / 车载迫击炮 | 火焰较短、向上发展的扬土与烟柱 |
| 坦克 / 固定野战炮 | 较厚的火团、烟团与飞散碎屑 |
| 燃料桶连爆 | 较长火焰与更深色烟团 |

爆闪、火团、烟尘按不同时间展开；碎片在 GPU 上旋转并沿抛物线飞散。采用低面数体积轮廓、暖白 / 橙色火焰、灰土色烟尘及纸感抖动消隐。接地爆炸按雪地 / 沙地 / 红土调整扬尘色，分点读取真实地形高度；跨沟边点跳过，空爆不生成贴地尘圈或焦斑。焦斑缩小并去除旧紫色。

烟雾弹继续使用原持续遮蔽效果及独立保留槽位；载具损毁继续使用既有 `vehicle_destruction_fx.gd`，殉爆不会叠加第二套通用特效。

## 性能边界

- 两个共享 MultiMesh：384 个烟火实例 + 96 个碎屑实例，上限 480；无逐粒子 Node、灯光、阴影、刚体或碰撞射线。
- 每渲染帧最多写入 112 个装饰实例 + 12 个爆闪；烟火批次预留 24 个爆闪槽，过载时先削减烟尘 / 碎屑。槽位循环复用，不扩容。
- 32 m 外细节约减半，64 m 外不生成；屏幕外剔除视觉，仅近处保留有界声音。每帧最多三个声音 / 焦斑提示，焦斑复用原 100 个总量上限。
- 运动、膨胀、渐隐在 shader 中计算，CPU 不逐帧上传粒子位置。只更新统一时间，每 0.1 秒清点固定容量；清空后停止处理并隐藏批次。
- 启动时提交零面积实例预热 shader，减少第一次爆炸编译顿挫。重置清除出生时间，避免旧粒子重新出现。
- `proving_fx.batching_stats().explosions` 提供实例数、容量、批次数、上传量、削减数及维护耗时。该计时不代表整体爆炸伤害 / 墙体破坏耗时，也不代表 GPU 帧率。
