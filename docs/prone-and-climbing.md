# 卧倒与按墙高翻越

保留用户原 41 骨骼、蒙皮与走跑动画。原文件没有匍匐和攀墙动作；在这些原骨骼上增加按接触阶段编排的动作，未导入 PUBG 原版动捕，也未替换骨架。

## 卧倒

骨盆降低到地面附近，上背与头部独立抬起。双腿展开，膝部微弯，脚踝转平；静止时肘部向地面支撑，枪身保持向前。移动使用交替收腿及左手前伸回拉，停止或射击时回到双手持枪。卧倒枪口仍使用真实武器节点。头部命中位置与卧倒空间高度同步调整，避免角色头部越过旧的低矮碰撞范围。

## 按墙高选择动作

高度相对于角色脚下地面计算，并读取破坏后实际剩余墙高。墙厚、落点空间和整个路径仍参与碰撞检查。

| 相对墙高 | 动作 | 表现 |
| --- | --- | --- |
| 0.30–0.85 米 | 低墙跨越 | 右手保留枪械、左手短撑，重心侧移、前后腿错开 |
| 0.85–1.35 米 | 中墙撑越 | 收枪、双掌先后撑沿、屈髋提膝、分腿通过 |
| 1.35–2.10 米 | 高墙攀爬 | 双手抓沿、后脚蹬墙、前脚上沿承重、越过后分腿落地 |
| 超过 2.10 米 | 不可攀爬 | 保留障碍阻挡 |

手掌目标来自墙沿世界坐标，脚部抬升随墙高变化，动作时长随高度和厚度增加。高墙的领先腿沿用进入动作前的原步态选择，不固定每次同一条腿。中高墙动作中武器暂时收在身体侧后方，释放双手；落地时逐渐回到持枪。地图编辑或车辆阻挡改变路线时，仍会中止翻越。

### 2026-09-26：深入参考 PUBG 后的动作调整

PUBG 的[官方翻越开发说明](https://store.steampowered.com/news/posts/?appids=578080&enddate=1510588202&feed=steam_community_announcements)区分障碍高度、持枪跨越与双手拉升、助跑和原地起步，并说明会根据现场几何选择动作。[官方 Animation Refresh](https://pubg.com/en/news/1565)强调通过可见的重心转移和动作力度增加重量感。这里借鉴这些组织方式；下面的时序、阈值和骨骼修正均为本项目的调校，不是 PUBG 原始参数。

旧实现用原跳跃片段叠加统一收腿，身体先整体上抬，双手够不到墙沿后松开，随后平移越墙。现在翻越使用原骨架的稳定持枪姿态作为基础，分别编排预压、抓沿、提膝、支撑、越沿、落地缓冲；普通跳跃仍使用原跳跃片段。

- 起步：身体先压低、向支撑侧转移重心；真实接近速度影响动作时长。刚按 Shift 不会凭空获得助跑动量。
- 撑手：世界位置固定的掌部接触点，左右手错开入场；低墙右手保持持枪。手臂够不到时按可达范围释放，不拉长原骨骼。
- 提腿：领先腿先抬、后腿延迟蹬离；高墙有蹬墙脚和上沿脚两个支点。膝盖有明确弯曲方向，大靴子先抬过墙顶再前移，碰撞约束解除时限制横向转移速度，避免脚部突然跳变。
- 身体：骨盆压低和侧倾，上背前折、头部适度反向抬起；先形成支撑姿态，再越过墙沿。
- 落地：下落按高度分配加速下降时间，不再接近地面时悬停减速。领先脚先落、后脚跟上，屈膝吸收冲击后恢复原走跑；落地效果在实际接触阶段触发一次。
- 衔接：进入翻越时从当前原骨骼姿态渐入；退出时在 0.18 秒内衔接原走跑。持续按前进可保留一部分进入动量，不强制每次从完全静止重新起步。

0.5 米厚、原地起步的训练样本约为：0.65 米墙 1.26 秒，1.15 米墙 1.67 秒，1.85 米墙 2.48 秒。高墙包含拉升、越沿、下落和缓冲，助跑时会缩短移动部分；不是同一片段统一加速。

### 墙体穿模修正

保留“模型与碰撞使用同一实际高度”的修正，不使用虚拟抬高碰撞底部来掩盖腿部穿墙。接近墙面时使用普通移动的 0.28 米半径，使已靠墙的角色不必先倒退；完全升过墙顶后，跨墙与落点仍按 0.64 米半径检查。根部高于墙顶 0.16 米才开始水平通过，身体和背包离开另一侧墙面后才下降，并逐段复查实时障碍。

翻越的动作与位移共用同一阶段时间；靠墙阶段减少过早弯腰，并对头盔、胸部、骨盆预留厚度。蹬墙脚的接触目标退到墙面外，膝盖收拢，双手在离开墙沿后收回身侧，武器改为枪口朝上收起。保留原有三种墙高动作和原骨骼，不改变普通走跑动画。

演武场西侧训练区为 0.65 / 1.15 / 1.85 / 2.5 米四道墙。`START_MOVEMENT.bat` 进入第一道墙前；`START_CLIMBING.bat` 直接进入 1.85 米高墙前，越过后继续向上依次经过中墙和低墙。Z 卧倒；先起身，再朝墙按方向键和空格翻越。F1 切换近景。

新增 `qa/climb_contact_check.gd`：只读取资源并计算静态路径和原骨架采样，不调用 `world.step`、不模拟按键、不渲染截图。3 种墙高 × 3 种墙体朝向，加上贴墙起步及高度上限检查，共 100 项通过；覆盖原骨长、撑手位置、脚部支点、靴尖/膝盖/躯干余量、脚部跳变、动作退出和碰撞路径。检查中的完整撑手采样误差最大约 4.1 毫米，脚部支点误差最大约 4.7 厘米。这是骨骼与几何检查，不代表已完成所有服装蒙皮的逐顶点碰撞检查或用户观感验收。

### 破坏缺口与墙沿卡住修正

普通移动、起身、落地及下车位置统一使用 0.28 米身体半径。旧起身检查为 0.29 米，可能把可移动的位置误判为不能起身；旧落地探测只覆盖身体半径的 72%，可能漏掉身体边缘仍接触的墙顶，导致落入墙沿。

墙体按剩余有效格检测圆形身体与矩形格的实际重叠，排除墙角外侧的误阻挡。水平移动每段不超过 0.10 米；降低姿态时碰撞高度跟随姿态过渡，起身则先预留目标高度，避免刚按卧倒就进入尚未能容纳身体的孔洞。

记录最近的无重叠位置。发生异常穿入时，优先沿不加深重叠的路径回退到附近有效位置；无可用记录时，仅在同高度、0.8 米内寻找最近退出位置。恢复路径逐段检查，不允许先深入实体墙再穿到另一侧，也不会直接抬到墙顶。深处或被完全封闭的空间不会强行传送。

上方确有残墙时继续禁止起身，并提示保持当前姿态、用 WASD 移出缺口。按用户偏好，本次只检查脚本加载和演武场启动；破坏后缺口、墙沿下落、趴下与起身的实际操作由用户验收。

### 助跑切入攀爬时的闪移修正（2026-09-26）

用户反馈：助跑后翻墙，角色会先闪到墙的另一边、再回到下方、最后登墙。原走跑片段包含向前的根位移，日常采样会用模型偏移抵消；进入攀爬时只混合了骨骼姿态，却丢失旧姿态对应的位移抵消。不同跑步阶段因而出现不同程度的整个人偏移。原检查从静止姿态进入，未覆盖这个问题。

现在在进入和退出攀爬时同时记录可见骨盆的位置。骨骼过渡后重新抵消源动画位移，保留原姿态的压低、提膝和落地缓冲；角色的世界位置仍只由原翻越路径负责。原骨架、蒙皮、走跑片段和按墙高分档均保留。

另一个跳变来自避墙修正：头盔、上身或骨盆高过墙沿时，向后避让量曾一次归零。现在继续即时保留必要余量，越过墙沿后平滑释放，避免约 22 厘米的中途跳动。

新增 `qa/climb_transition_check.gd`，覆盖 3 种墙高、3 种朝向、走路/快跑及 3 个进入步态阶段，共 54 组静态资源/路径采样。进入连续性、模型与路径的一致性、过程跳变、退出连续性和落地后的走跑恢复，共 324 项通过。修正前进入瞬间最大偏移约 3.43 米，修正后小于 0.001 毫米；同一 120 Hz 路径采样下，修正根位移后剩余的约 21.8 厘米单步突变，经避让平滑释放后降至约 3.1 厘米。后者是采样中的骨盆相对路径运动，不是实际游戏帧率或用户观感测量。

原撑手、脚部支点、骨长和墙体余量检查 100 / 100 通过。检查未模拟按键、运行战斗或渲染截图；通过 `START_CLIMBING.bat` 打开同一联合演武场的高墙前，由用户体验助跑与连续翻越。
