# 加特林外观修正 · 2026-09-29

用户圈出的 Minigun 图标过于像单管枪。实际运行数据的 `shapes` 为 null，旧模型使用简化六管占位形状，又叠加了通用步枪的护木、中心枪管、瞄具与脚架；图标仍是原二维图集。

本次以 [Dillon Aero M134D 官方展示](https://dillonaero.com/m134d-standard-7-62-x-51mm/) 的多管枪组为外形参考，制作适合本项目角色的虚构便携版本。提把、侧挂弹箱及握持比例属于游戏设计，不宣称真实武器规格，也不是 PUBG 原版资源。

- `minigun_visual.gd` 独立建模：六根分离、带真实内壁的枪管，两道开孔束环，圆柱机匣、侧驱动电机、供弹口、橄榄色弹箱、提把与后握把。绕过通用步枪细节，保留原墨线材质。
- 总绘制长度仍为 1.32 m，整个模型等比缩放，避免沿步枪宽度挤扁圆形枪组。原角色骨架、蒙皮和走跑不变，双手 IK 改为真实握把接触；装填接触和弹箱掉落读取同一个侧挂位置。
- 六管合成一个共享转子网格，机匣合成另一个共享网格。单模型共 3204 个三角形、两个三角表面，进入既有枪械实例合批；没有六个独立枪管批次、逐帧重建网格或新增灯光。每个真实射击事件推进六分之一圈，现有枪口求解回调时一根管口对齐发射节点。保留 1200 RPM、18 伤害、200 发弹箱和原音效映射；模型无脚架，因此移除其通用重机枪分支赋予的隐形脚架稳定加成。
- `tools/build_minigun_icon.gd` 从同一原生模型生成透明 SVG，`weapon_icon.gd` 统一提供给 Tab 配装、G 轮盘、战斗 HUD 和拾取面板。原始图集不修改，其余枪仍读取原图标。后续改几何后须重新运行该生成器并导入资产。

检查：`qa/minigun_model_check.gd` 43/43；`qa/weapon_presentation_check.gd` 1410/1410（84 项装备）。检查包括资源复用、开火时枪管孔与枪口节点对齐、静止收转、手部接触、侧箱掉落及原数据不变。没有自动操控游戏或截图验收；同屏帧率与手感仍由用户实际测试。

试玩入口沿用 `res://proving_ground.tscn -- --weapons --weapon=minigun`，直接配备加特林并使用既有 F1 近景模式。Tab、G、数字键与滚轮保持原切换方式。

## 持枪修正

用户实际试玩指出姿态不对。进一步采样发现，旧步枪锚点将枪轴抬至约 1.25 m，左手提把接触点超出骨骼臂长；独立截断手腕 IK 后手掌离把约 0.19 m。仅修改握点不足以解决承重姿态。

新增 `minigun_motion.gd`：常规站姿枪轴约 0.93 m，枪身置于腰腹前方；提把后移至机匣上方，右手握后把，左手从上侧抓提把，两肘下沉。原 `Armature|idle/walk/run` 保留走跑，独立设置手腕方向与轻微上身前倾。枪整体位置通过两个手臂可达范围共同约束，避免只截断一只手的 IK。真实目标高度、后坐弹道和枪口求解继续使用同一枪姿，站立、蹲伏与卧倒均适用。装填右手保持承重，左手拿取并接触侧箱；收枪、医疗与攀爬仍由原有动作分支接管。

`qa/minigun_pose_check.gd` 离线采样 327/327 通过，涵盖三姿态、八方向、近远目标与不同高度、走跑、换弹右手接触及原腿脚变换不变。常规握持的最大接触误差小于 0.001 mm，最大枪口瞄准夹角误差约 0.27°；这些是数学与骨骼检查，不代表用户已认可画面。模型 43 项、原全装备 1410 项检查再次通过。图标随提把位置重新生成。

## 枪口火光位置修正

用户指出开火位置偏移。旧实现只在发射瞬间让一根枪管对齐固定发射节点；枪组继续旋转时，65 ms 的火光仍挂在固定上方位置，且超过原 1200 RPM 的 50 ms 发射间隔。通用步枪的三片侧向星芒进一步掩盖了具体管口。

`minigun_visual.align_flash` 根据真实射击序号选出刚开火的枪管，在转子变换下定位余焰；发射瞬间火光根与物理枪口仍重合，已经飞出的子弹不跟随旋转。枪口节点的尺寸补偿、人物姿态和渲染插值沿用原流程。加特林火光改为两个共享锥体（亮芯与外焰），长度 0.22、基部半径 0.035、持续 26 ms，取消通用侧向星芒，不增加批次或灯光。

资源检查扩展至 153/153：覆盖六个射击相位、枪组转动期间及枪身俯仰后的实际管口跟随，使用运行时同样的挂点父子关系和尺寸补偿；每发起点与物理枪口保持重合。持枪 / 高度瞄准检查 327/327 再次通过。实际画面继续由用户在统一演武场验收。
