# 打击感实施 · v2026.09.29.14

## 本轮实现

- `combat_feedback_profile.gd` 按原武器身份 / mounted_fire_key 缓存声音、强度、肩部承力及炮管回缩参数。手枪、冲锋枪、步枪、7.62 / 12.7 机枪、机关炮、霰弹、狙击、榴弹、火箭、迫击炮及主炮都有对应配置。真实射速、伤害、散布与弹道沿用现有系统。
- `combat_audio.gd` 启动加载 14 个本地 WAV（合计 3,270,984 字节源文件），同一文件被多种音色复用。枪口、人体接触、金属、石、木、土、玻璃、近战及爆炸分别路由；材质变体调节基音，远处经过共享低通总线，3D 声像跟随真实位置。
- 原循环 12 声道替换为固定 24 个 AudioStreamPlayer3D：8 个本地重要事件、12 个附近世界事件、4 个爆炸。抢占按重要性与剩余响度，低优先级细节不能占用本地保留槽。每帧最多启动 8 个本地 + 8 个世界声音，材质接触按部位区域 / 目标限频 65 ms，致命有独立门控；状态表最多 512 项。
- 65 m 外世界声音剔除，近 / 中 / 远三档混音。M 静音立即停止现有声音；维修、接管玩家、场景重建清理旧声音状态，销毁时只删除本实例拥有的两条音频总线。没有新增声音遮蔽射线；当前远景低通是距离效果，不代表墙后声音遮蔽已实施。
- `combat_reaction.gd` 同一受击包络前段继续推进，新的连续命中增加有上限的强度，不反复回到首帧；强命中 / 头部可提升方向与部位。普通 / 头部包络为 .30 / .38 s，前段合并窗口最多 .24 s，保留原骨架、根位移和死亡动画。此实现用自然动画进程合并，不另存逐弹动画队列。
- `source_rig_motion.gd` 将枪身快速冲量与滞后肩部承力分开，按枪族恢复。45 / 75 / 88 mm 炮管回缩分别 .17 / .25 / .32 m（模型空间），恢复 .36 / .48 / .61 s；可见车体叠加小幅承力，炮塔枪口求解与车辆物理接地保持原路径。固定武器继续使用现有炮架、操作员承力及装填动作。
- 材质命中读取实际法线，木屑细长、玻璃薄片、金属短火星、石土碎屑与尘团；粒子强度按弹种变化。每帧最多 10 个接触装饰事件，背景事件最多使用前 6 个名额，40 m 外和屏外剔除。实际命中和伤害不受该预算限制。
- 特殊弹爆炸携带实际命中法线 / 材质；击墙偏向外侧展开，按木 / 金属 / 石改变烟尘色。45 / 75 / 88 mm 区分火团数量、烟团数量与火焰时间；保留原两个爆炸批次和 480 实例上限。未新增碎片物理或真实穿透模拟。
- 命中标记只由本地玩家对敌方的实际正伤害触发，普通 / 致命为 .12 / .18 s，线条粗细和颜色区别；普通与狙击圆镜一致。删除原隐藏伤害 Label3D 的逐命中创建，不加新的战斗文字。
- 主炮与近爆才产生最多 2 px 的短镜头包络，默认再乘 .5；Tab 原面板提供关闭 / 轻微 / 标准。开镜、编辑与菜单期间不使用震动，鼠标投射射线扣除装饰平移；准心固定鼠标，无每发镜头缩放或全局 hit-stop。

## 保留与性能边界

- 原 2048 弹丸显示项、480 爆炸实例、血迹容量与 18 个尸体上限保持不变，无逐弹灯光、新世界相机、全场额外扫描。
- 新增维护主要是事件分发、最多 24 个声音槽检查及小型缓存；声音不在每帧扫描场景。已有 AI 声学感知、伤害与可破坏掩体不依赖可听声音是否播放。
- 原击飞 / 倒地与载具毁坏系统继续使用，并非为普通机枪新增大量刚体尸体。
- 当前只完成必要的脚本编译、资源加载及原场景启动检查；没有自动开火、操控或压力测试。设计目标 CPU P95 ≤.5 ms 尚未通过负载测量，不能声称已经达到。音频统计通过 `fx.batching_stats().audio` 读取。

## 用户试玩

联合演武场原 Tab：M416 / AKM / 12.7 重机枪比较枪声和受击节奏；木、石、金属比较落点；机关炮 / 三型坦克 / 野战炮比较重量；榴弹 / RPG / 迫击炮比较发射与落点爆炸。关注连续命中是否自然、击杀是否明确、枪口与落点声音是否清楚，混战时操作和目标识别是否稳定。
