# 演武场、姿态与场景破坏

## 如何体验

运行 `START_RANGE.bat`（或 `START_GAME.bat`），Godot 的默认主场景也已切到演武场。`START_EDITOR.bat` 直接进入场景工坊。旧八人战场改由 `START_SKIRMISH.bat` 进入，百人战场仍用 `START_50_VS_50.bat`。

`START_MOVEMENT.bat` 直接来到 0.65 米训练墙前，朝墙按 W + 空格翻越；向空旷处移动按空格跳跃。出生点西侧排列 0.65、1.15、1.85、2.5 米四道墙，分别体验跨越、撑越、攀爬和阻挡。F1 或滚轮调整观看距离。动作与资源参考见 [卧倒与攀爬说明](prone-and-climbing.md)。

| 操作 | 按键 |
| --- | --- |
| 行走 / 驾驶 | WASD，载具空格制动 |
| 快跑 | 按住 Shift + WASD；站姿生效，瞄准、射击、换弹时取消 |
| 跳跃 / 翻越 | 空格按下触发一次；朝向近处可翻墙体则翻越，否则跳跃；空中不能二段跳 |
| 瞄准 / 开火 | 鼠标转向，右键精确瞄准，左键开火；半自动需逐次点击 |
| 装填 | R，保留有限备用弹药，空弹匣自动装填 |
| 蹲伏 / 卧倒 | C / Z，再按同键起身；头顶有阻挡时不能起身 |
| 动作近景 | F1，近景中仍可走路、蹲伏、卧倒、射击、换弹 |
| 武器库 | Tab，按名称搜索或按类型筛选，点击立即装备 |
| 交互 / 职业换装 | E 与最近可达装备台交互；Tab 的职业形象可直接换装 |
| 载具 | 靠近按 F 进入，再按 F 离开；也可在武器库选车辆并“立即试驾 / 操作” |
| 车载武器 | Q 循环，界面显示当前武器、车体耐久、履带状态和速度 |
| 屋顶 | F3：入室隐藏 / 常驻无顶 / 入室抖动透明 |
| 重置 / 编辑 | F5 重置当前场景，F8 切换编辑与实地测试 |
| 其他 | 滚轮缩放，M 静音，Esc 暂停；武器库可补给弹药、修复载具 |

默认演武场有六名自动补充的靶兵，前方摆放木栅栏、砖墙、混凝土、沙袋、金属围栏、燃料桶和木箱。西侧停放七种载具，东侧是两种固定武器与可进入的警卫室。默认玩家无敌，武器库可以关闭，也可以打开靶兵反击。

建议先用 M416 对砖墙连续射击观察局部损伤，再换 RPG 连续打同一位置观察缺口。墙材质不同，所需火力不同。一次未炸开不代表没有伤害。

## 从原版继承的内容

`tools/sync_original.mjs` 只读导入 `client/web/Pixi-Battlefield1-Blue` 的最终 JS 导出对象，并记录 12 个源文件的 SHA-256。后续更新原版数据后，可在本项目运行 `node tools/sync_original.mjs` 同步。

| 内容 | 数量及处理 |
| --- | --- |
| 武器装备 | 77 项原版武器 + 7 项装备，共 84 项；保留最终伤害、射速、弹匣、备用弹药、射程、衰减、弹丸速度、散布、弹片数及装填数据 |
| 武器造型 | 74 项有原版矢量轮廓，挤出为有厚度的网格；10 项近战/特种装备另建程序模型；保留原版图标 |
| 载具 | 武装吉普、侦察车、APC、IFV、轻坦、坦克、重坦；各自武器表、装甲朝向、加速、倒车、转向、履带受损系数 |
| 固定武器 | 重机枪、野战炮，保留射界与各自弹药/装填 |
| 地图库 | 52 个预制体、63 个组件、30 张原版场景；保留二维坐标、实例 ID、缩放、旋转和未知字段 |
| 材质破坏参数 | 读取原版 `CampaignRuleKernel.wallConfig` 的单元耐久、爆炸倍率、掩蔽透射，以及相应枪弹材质系数 |

原版停用的烟雾弹在演武场标 `*`，允许测试烟雾视效。它目前不遮蔽 AI 视线。原版枪械档案也包含未实现的特殊模式等元数据，导入数据不等于逐项运行功能都已移植。

## 动作实现

13 根骨骼：骨盆、髋/膝/踝、胸部、双臂和独立颈部。步态按真实位移推进，站立速度 3.4 m/s、蹲伏 1.65 m/s、匍匐 0.62 m/s。切换姿态有过渡，腰部跟随移动方向，上半身跟随瞄准；蹲姿、卧姿改变射击高度、受击高度、散布和通过能力。

演武场及工坊实地测试现支持 Shift 快跑（5.8 m/s）、空格跳跃（初速度 6.4 m/s、重力 18 m/s²，60 Hz 下脚底最高约 1.08 m），支持快跑起跳时保留水平速度。腾空时释放脚掌固定并收腿，落地有缓冲与短暂尘土；影子保留在支撑面，角色、枪口、命中体积和空中死亡跟随真实高度。蹲姿起跳会起身，卧倒需先按 Z 起身；头顶空间不足时受阻。

翻越检查当前未被破坏的墙格：高度差 0.30–1.80 m，厚度不超过 1.40 m，人物接近墙面且方向不能过于平行，墙后需有完整落脚空间。动作分为接近、扶墙收腿、越过、落地，途中不能开火或换弹，原有装填中断后可重新开始；空弹匣会在落地后自动装填。预检整个路径，途中再次检查移动车辆等新障碍。打掉墙顶后按剩余高度判断，彻底破坏的墙不再触发翻越。这是矮墙翻越，不包含高墙攀爬、悬挂或屋顶跑酷；屋顶仍为显示层，未变成可站立楼板。旧八人/百人独立场景保持原操作。

本轮增加脚掌接触阶段的世界坐标固定，腿部双关节 IK 解算落脚；踝部抵消身体倾斜，抬脚阶段再回到摆腿轨迹。增加卧姿抬头、俯身持枪、匍匐屈腿及支撑手变化，并区分手枪并拢握持、投掷、近战挥动与长枪持握。

设计参考了 Epic [Lyra 动画说明](https://dev.epicgames.com/documentation/unreal-engine/animation-in-lyra-sample-game-in-unreal-engine) 的距离匹配、方向适配及上/下身分层原则，以及 Godot [AnimationTree 文档](https://docs.godotengine.org/en/stable/tutorials/animation/animation_tree.html) 的分层与骨骼过滤思路。当前由程序直接写入骨骼姿态，未使用 Lyra 资产，也未接入动作捕捉片段或 AnimationTree 动画资源。

## 弹道、细节和破坏

- 普通枪弹用连续线段查询，避免高速弹穿过薄墙；保留霰弹数量、狙击穿透和距离衰减。瞄准不同姿态的靶兵时调整弹道高度。
- 火箭、榴弹、炮弹碰撞爆炸；手榴弹有抛物线、碰撞反弹、落地和引信；迫击炮有最小射程、弹道弧线与飞行时间。
- 弹壳有抛出、旋转、重力、反弹、落地残留。栓动/泵动/杠杆武器延迟抛壳，DBS 成对泵动；转轮和折开式在装填时排壳。弹匣装填有地面残留。
- 死亡包含受击方向位移、骨骼倒地、血迹与当前武器掉落。残骸持续保留，有上限清理；这是程序倒地，不是全关节刚体布娃娃。
- 墙体沿长度和高度分单元，普通墙约 0.55 × 0.50 m，沙袋高度单元约 0.27 m。子弹破坏局部高度，爆炸依距离和材质损伤多个单元。缺口实际改变射线、人物通过和 AI 导航。
- 每个墙段内部检查四邻接支撑关系。仍与底层相连的门楣保留，失去全部支撑的孤立块掉落。房顶在所属墙体大量损毁后消失。
- 爆炸伤害先采样遮挡，再更新结构；燃料桶只触发一次连锁爆炸。载具受正面/侧面/背面装甲影响，履带损伤降低机动性，损毁载具会爆炸并保留阻挡残骸。
- 弹坑为地面视觉痕迹，碎块为有运动和落地的效果体。地形没有挖深，碎块不参与阻挡，房屋没有多层结构、楼板承重或真实建筑力学求解。

活动效果最多 360 个，倒地角色最多 18 个，地面残留最多 100 个。网格和材质复用，墙体修改按帧合并重建。

## 场景工坊

F8 进入编辑模式。可加载原版 30 张场景或打开 JSON，选择预制体/组件/载具后点击地面放置。按 Esc 回到选择模式，单击选中、拖动移动；中键平移，滚轮缩放。面板支持俯视/立体预览、旋转、缩放、高度、离地距离、耐久倍率、破坏材质、可破坏开关与房顶开关。修改属性后点击“应用到选中物件”。

Q/E 旋转，Delete 删除，Ctrl+D 复制，Ctrl+Z/Y 撤销/重做，Ctrl+S/O 保存/打开。选择“布置靶兵 / 出生点”可以配置测试对象和玩家位置。门组件与同一直线上的墙段相交时会开门洞。

保存仍使用原版 `endless-war-scene-plan` 2.0.0 数据结构，40 原版像素对应 1 米。高度等扩展写在实例/线段的 `godot3d` 内，原始二维字段继续保留。保存文件默认位于 `exports/`，不自动覆盖原版工程。

F8 用当前布局副本生成可玩的场景。实弹造成的破坏不会覆盖编辑稿；返回工坊恢复完整布局。移动、属性修改和批量撤销均作用于原版实例层，不把墙体碎片写成新的地图物件。

当前支持单选编辑和一层平面地图。原版关卡脚本、战役进度、完整载客 AI、全部武器切换模式以及原版逐像素断裂算法尚未移植；本轮完成的是共享原版数据的原生 Godot 演武场与编辑闭环。
