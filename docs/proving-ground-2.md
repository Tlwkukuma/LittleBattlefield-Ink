## 入口与操作

- 双击根目录 `START_RANGE2.bat`：构建并打开 Release。版本来自 `proving_ground.gd`，窗口及顶部保留启动时间，窗口还显示 PID。
- 原联合演武场的 Tab 面板也可进入；样板间 Tab 面板可返回联合演武场。F8 场景列表包含演武场2。
- F2 原地切换荒原墨线 / 原版材质；几何、相机、单位、碰撞和破坏状态不变。F5 复原当前场景，保留材质选择和启动身份。
- F1 查看动作近景；WASD、左键射击、右键聚焦、R 装填、G 轮盘与原操作一致。
- Tab 选择武器、职业与车辆，点击「立即试驾 / 操作」；靠近车辆可按 F 上下车。

## 样板内容

48×40 m 的测试院落：玩家、五职业红方靶兵、两名蓝方样兵；蓝红武装吉普及蓝方重坦；砖墙、混凝土、木墙、沙袋、容器、木箱和油桶；右侧为旱地伞冠树、砂岩、矮岩与阔叶树。停车和射击区地面平整，右侧低沙丘仍使用真实地形高度。靶兵反击默认关闭，由用户在原面板开启；蓝方样兵保持站位，不攻击玩家。

## 风格实现

以无主之地的漫画概念稿方向为参考，保留本项目小兵比例。暖沙土、冷色阴影、蓝红识别色、三段明暗、表面磨损、警戒漆与入口 02 模板字组成样板。

`range2_ink.gdshaderinc` 在原有材质单次绘制内处理颜色、明暗与朝向轮廓。磨损来自共用的 256×256 SVG 纹理，启用 mipmap，按物体表面坐标采样。未增加屏幕复制、全屏边缘检测、额外描边模型、动态灯光或第二台世界相机。角色与挂件、枪械、车辆、墙体、道具和 HUD 复用已有批处理。

全局材质开关只在演武场2启用；返回原演武场或第一关时关闭，原场景保留旧表现。样板采用共享材质和原预制体，不复制另一套战斗系统。

## 已做检查与限制

`qa/style_range_contract.gd` 为冻结场景资源检查：验证预制体注册、原蒙皮、双方阵营、三辆载具、地形与漆面高度、A/B 前后模型及破坏数据不变、返回原演武场、启动身份。全程 `simulation_time=0`、`shots=0`。

RTX 3060 / GL Compatibility / 1440×900 的静态样板检查，新旧材质均为 **30 Draw Call**，约 37.5 万提交图元（包含批处理保留几何）。三组 GPU 中位值为 0.691 / 0.674 / 3.145 ms，存在明显时间波动，因此不能把前两组的差值当作稳定增量保证，更不能把它当成满负载实战帧耗时。第一关原资源回归检查 364 项通过。

画面、驾驶、射击、破坏及持续移动性能由用户亲自验收；尚未宣称实战稳定 60 FPS 或 P99 ≤15 ms。运行窗口默认保留左上性能面板，开启性能日志。最后启动身份保存在 `qa/performance/latest-range2-launch.json`。
