# 载具装甲与行走机构耐久方案

2026-09-29，打击感方案补充。状态：设计设定，待实施；本轮未修改运行数值。范围为七类移动车辆及固定武器的区别处理。

## 1. 源码依据和现状

- 旧 Pixi `src/equipmentProfiles.js:19` 的 `VEHICLE_PROFILES` 定义车体 health、trackHealth、front / side / rear 装甲伤害倍率及 smallArmsMultiplier。下表车体值与方向倍率直接以此为基线。
- `src/game.js:1900` 的装甲扇区为前方 ±60°、后方 ±60°，其余侧面；`damageVehicle()` 另按武器类型乘算。
- 旧版履带受损按侧 / 后 / 前的 .72 / .38 / .18 概率触发，爆炸等损伤履带时取原伤害的 .42，机关炮 .20。`src/specials.js:137` 中履带接近归零仍保留约 28% 移动能力，不能描述成原版完全断履停驶。
- 当前 Godot `proving_world.gd` 已导入车体、履带基础值和方向系数，但方向扇区为 ±45°；仍采用随机履带损伤。反坦克武器另走倍率分支，未统一经过各车型的 armor 表。
- 当前 `vehicle_collision_parts.gd` 只将吉普和侦察车作为轮式；运兵车已有履带形状及 gear 碰撞部件，但导入 trackHealth 为 0，需补齐。

## 2. 两条耐久的定义

1. **装甲血量：** 车体综合生存耐久，归零才触发载具毁坏与原殉爆。吉普显示“车体”。这条就是当前 health，不再额外加一层先扣完再扣车体的护盾。
2. **履带血量：** 行走机构耐久，归零导致失去地面驱动力，但车体和武器仍可能完好；不能自动判定整车爆炸。轮式车辆第二条显示“轮组”，不能虚构履带。

首轮每车使用一条合并行走机构耐久。命中仍可辨别左右部件用于火花 / 断带位置，但不扩展成左右履带独立血条或四轮逐轮操作系统。

## 3. 建议首轮数值

装甲系数表示该方向**承受的伤害比例**，数值越小防御越强；还需乘弹种对车辆的有效系数、距离和遮挡。

| 车型 | 装甲 / 车体 HP | 履带 / 轮组 HP | 正面倍率 | 侧面倍率 | 后方倍率 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 武装吉普 | 720 | 轮组 120（新增） | .92 | 1.00 | 1.08 |
| 轻型侦察装甲车 | 1120 | 轮组 160（新增） | .62 | .76 | .94 |
| 装甲运兵车 | 1840 | 履带 200（补齐） | .48 | .62 | .82 |
| 步兵战车 | 2320 | 履带 235 | .38 | .54 | .78 |
| 轻型坦克 | 1960 | 履带 220 | .43 | .61 | .84 |
| 中型坦克 | 2760 | 履带 300 | .30 | .52 | .84 |
| 重型坦克 | 4560 | 履带 430 | .17 | .34 | .66 |

保留原版“轻坦 / 步战车不是单按名称递增”的基线；两者定位还由主炮、射速、速度和乘员能力共同形成。如用户试玩后希望轻坦更抗打，再单独调整其装甲而非隐性提高所有坦克耐久。

前后扇区拟统一为原版 ±60°，相对于**车体前进方向**，不受炮塔转向影响。命中车首但炮塔朝后，车首仍是正面装甲。若后续引入独立炮塔装甲，再给炮塔单独表；本轮不混算。

举例：一发已通过弹种、距离和遮挡处理的 100 点有效伤害，打中中坦前 / 侧 / 后分别扣 30 / 52 / 84 HP。此例不是某个现有武器的最终伤害，也不能据此直接宣称击毁发数。

## 4. 伤害结算与断履规则

### 车体

拟统一为：基础伤害 × 弹种对车型有效系数 × 命中面装甲系数 × 已有距离 / 遮挡衰减。各项只能算一次。直接命中与弹药配置允许的范围爆炸分别记录，禁止意外重复结算同一直接命中伤害。

- 普通步枪和 7.62 机枪主要威胁吉普、轮胎与外露操作员；建议对中 / 重坦车体不造成有效结构伤害，不能靠大量小口径把正面扫爆。这是相对旧版极小磨血的新增提案。
- 12.7 mm 可压制轻装甲、损伤部分行走机构；20 / 25 mm 是轻装甲克星，攻击坦克时侧后及履带更有价值。
- 主炮与反坦克火箭按显式弹种 ID / mounted_fire_key 分类，不依赖英文显示名称或“单发伤害 ≥90”推断弹种。
- 反坦克弹仍有对装甲的专用有效系数，但统一受车型和命中面约束；不保留绕过车型装甲表的特殊路径。具体弹种倍率实施前与当前武器伤害一起核对，不能只改表后使重坦正面近乎无敌。
- 爆炸方向来自爆心与车体的关系，直接弹来自实际入射与接触位置。遮蔽继续读取真实地形和可破坏物体；迫击炮顶部命中后续可扩展独立顶部档，首轮不冒充已实现顶部装甲。

### 行走机构

- 直接弹命中现有 gear 部件才扣轮组 / 履带；不再采用侧面命中随机扣履带。
- 轮胎允许普通枪弹损伤；钢履带对普通小口径免疫或极低损伤，避免机枪轻易锁死重坦。
- 建议以有效接触原始伤害 × 部件系数起调：20 / 25 mm 机关炮打钢履带 .20，主炮 / 反坦克直击 .42；这些沿用原版尺度，但去掉随机命中概率，仍待实际发数调校。
- 爆炸按爆心到履带部件距离、实际遮挡及衰减扣血；同一爆炸对同一合并履带池只结算一次，不能左右部件各扣一遍。复用原载具爆炸查询，不为全场每个轮子新增射线。
- 击中履带不是穿透车体的证据。直接命中只结算实际接触部件；爆炸可依据真实覆盖同时损伤车体和行走机构。不要无条件按满伤害扣两条血。

## 5. 损伤与操作反馈

| 行走机构剩余 | 履带车表现（拟定） |
| --- | --- |
| >60% | 正常行驶 |
| 30–60% | 加速与最高速度约 85%，起伏和异响轻度增强 |
| 1–30% | 加速与最高速度约 60%，转向响应下降；保持可控 |
| 0 | 断履，地面驱动力为零；现有惯性、坡面滑动和空中下落继续物理解算，武器仍可使用 |

轮组归零采用约 25% 最高速度的跛行与较差转向，不直接毁车。上述比例为新提案，替代原版断履仍可高速挪动的统一倍率；状态转换平滑，不能靠修改速度造成瞬停 / 弹飞。

断履不允许车辆原地旋转，符合此前统一赛车操控规则。维修恢复到 20% 以上再恢复低速驱动，避免 0 / 1 HP 状态频繁跳变；维修资源、耗时复用后续工程维修设计，本轮不擅自增加自动回血。

- 车体受伤：与实际碰撞点一致的火花 / 闷响；重击给一次短车身承力。
- 履带重伤 / 断裂：一次断带声和局部零件位移，移动时才有有界拖擦效果；不因断履而隐藏整个履带或生成持续爆炸。
- 已有车体低血烟火、归零残骸特效继续使用，不新增逐部件刚体。
- 驾驶 HUD 紧凑显示“装甲 / 车体”与“履带 / 轮组”两条；低耐久变色，断履只提示一次。敌方不额外显示精确数值，避免增加战场文字。

## 6. 固定武器与实施次序

固定重机枪本体 HP 520、野战炮 HP 840，沿用源表。两者没有履带条；操作员使用自己的生命值，防盾仅在真实遮挡 / 材质规则支持时保护，不能把整座武器当封闭载具。

实施顺序：先统一耐久 / 扇区配置与 HUD；再补 gear 接触信息及真实履带损伤；最后串联受击、断履、维修与 AI 失去机动后的行为（停驻射击或按原上下车规则弃车，不能继续请求驾驶导致每帧寻路）。

保留 `data/original`，运行配置放独立模块；新增部件耐久通过真实碰撞结果 O(1) 选取，破坏 / 修复使显示与碰撞缓存同步失效。用户仍在原联合演武场按 Tab 选择载具，分别从前、侧、后攻击，以及瞄准履带，确认生存时间和战术差异后再调第二版数值。
