# v2026.09.28.37：移动与战场残留物

2026-09-28，承接用户 v36 的 39 FPS / 44 Draw Call 截图。此文件记录本次实现与验证，不新增全局制作规范。

## 实战依据与范围

`qa/performance-v2026.09.28.36-20260928-151414.log` 中，多人活动期间每次物理更新约 7.5–9.7 ms，单个显示帧经常累计两次物理更新；动态特效约 3–5 ms。枪口求解通常约 0.25 ms，不能把剩余卡顿都归因于精确瞄准。GPU 耗时尚未独立测量，Draw Call 降到 44 不等于整帧符合 16.67 ms。

本次没有降低人数、动画更新率、原骨架细节、头盔精度、弹壳/血迹/焦斑上限，也没有自动运行战斗。

## 实现

- `proving_world.gd`：人物移动先检查整段轴向位移矩形是否仅接触地形。现有身体索引已按 0.6 m 扩展，车辆使用当前姿态对应的保守范围；只要有实体候选就保留原完整查询。空地路径复用地表高度，省掉每个分步重复的墙格与车体查询。地形坡度、海拔、边界、重叠恢复、姿态和脚步规则保留。
- `proving_fx.gd`：承托状态没有变化且上一轮检查已完成时，不再每帧扫描整个残留物列表。墙格拓扑或车辆姿态变化仍触发检查，未完成工作跨帧继续，每帧最多 16 次；已经休眠的弹壳在镜头比例不变时跳过尺寸查表，寿命照常推进。
- `blood_effects.gd`：静止血迹仅在出生、删除、上限淘汰造成列表变化时提交位置/颜色。最后两秒保持原来的逐帧淡出，仍为最多 96 个血迹。
- `proving_fx.gd`：普通爆炸焦斑改用共享 20 段 / 10 环球面网格和原材质。相同材质的 100 个焦斑只占 1 个表面批次；半径、压扁比例、颜色、高度和保留数量不变。升降更新及密集槽位回收保留。
- `terrain_art.gd`：单墙格几何生成直接访问目标行列，避免每格扫描整墙。`retained_wall_surface.gd` 在有效顶点数量相同时复用索引缓冲；颜色/位置照常更新，破口和坍塌仍更新真实几何。
- `runtime_performance.gd`：记录血迹、接触/生成、粒子、尸体各环节的五秒窗口 P50/P95/P99，避免只看某一帧的细分值。新增残留物扫描次数和血迹上传计数供实战分析。

没有交付弹壳旋转积分重写：该尝试可能改变非均匀缩放下的欧拉角连续性，已撤回，保留原运动实现。

## 验证

使用 Godot 4.6.3，冻结首关对象/车辆/地形，交替执行旧源码与新源码。没有 `world.step`、AI 决策、发射武器或输入模拟；时间始终为 0，射击数为 0。旧源码保存在 `qa/performance/secondary-before-source/`。

`qa/secondary_performance_contract.gd`：60,169 项检查，0 失败。包括 1,800 组地形/墙边/车边/地图边缘/腾空/姿态移动结果，逐格墙面几何完全一致，血迹生命周期，焦斑世界坐标几何、槽位回收，以及跨 16 次预算的掉落物承托抬升/失去支撑唤醒。

以下是同进程批次中位耗时，不是每帧耗时，更不是实战 FPS：

| 固定计算批次 | v36 旧实现 | v37 | 变化 |
| --- | ---: | ---: | ---: |
| 1,800 组混合移动计算，含字典复制 | 290.849 ms | 235.843 ms | -18.9% |
| 96 个静止血迹，120 次更新 | 19.379 ms | 2.216 ms | -88.6% |
| 360 个已稳定残留物，240 次承托刷新 | 51.840 ms | 0.309 ms | -99.4% |

原始结果：`qa/performance/secondary-performance.json`，日志 `qa/performance/secondary-contract.log`。数次同进程重复测量中移动约减少 19–20%，墙格仅减少约 2–5%；墙格收益较小，不把它描述为主要帧率改善。

`qa/wall_retained_contract.gd`：另有 1,111 项原入口冻结墙体检查通过，验证 HP、切顶、整墙隐藏/恢复、局部更新及 GPU Mesh RID 保持；没有推进战斗。日志 `qa/performance/secondary-wall-contract.log`。

仍需要用户在 `res://proving_ground.tscn` 第一关实际移动交火后确认 FPS、慢帧和 Draw Call。以上静态检查不能证明稳定 60 FPS 或全程 Draw Call <50。默认验收以 briefing 暂停启动，等待用户主动开始。
