# 载具外观与统一验收

## 入口

继续使用本项目 `res://proving_ground.tscn` 联合演武场。通过已有的 `Tab`「武器 / 载具」面板，在「车辆 / 固定武器」中选车并点击「立即试驾 / 操作」。WASD 驾驶，G / 数字键 / 滚轮切换车载武器，F 离开，F1 切换近景。面板的「补满弹药 / 修复」可恢复受损载具。

画面和手感由用户在这个原生 Godot 场景里亲自验收。载具、枪械、角色、攀爬等修改共用这个入口；不为单项另建独立网页、替代演示场景或截图验收流程。

本页的封闭驾驶舱和体积调整适用于 7 类移动载具。固定重机枪和野战炮使用可见人物操作，共享材质风格但不随车辆整体放大，详见 [固定武器表现](emplacement-presentation.md)。

## 参考与实现

主要参考用户提供的本机《逃离鸭科夫》`F:/steam/steamapps/common/Escape from Duckov`。此前只读检查 `sharedassets34.assets` 内 `SM_Tank_B`、`SM_Tank_T`、`Car_Military` 等分件形态，用于观察大块装甲分面、炮塔层次、舱盖、轮胎和外置装备。分件观察不包含原游戏完整装配、场景或着色器。项目内的几何由代码重新制作；当前着色以用户原人物为直接风格基准。

- `vehicle_style.gd` 集中管理车辆与固定武器的材质、配色及倒角零件。最新配色按下文阵营方案执行：装甲分主色、浅色面板和深色识别区，帆布、轮履、钢件、玻璃保留各自材质色。
- 与原人物共用纸底、墨色、固定光照方向和 3.2 像素间距的阴影排线；载具使用较细的 0.72 像素轮廓。排线按法线和光照方向出现，不再让整个侧面平均变黑。
- 车体装甲增加顶部和底部的小倒角，轻／中坦炮塔采用平滑铸造曲面，轮胎增加圆润胎肩。仍保留各车型的斜装甲、舱盖、炮盾和分体炮塔特征。

- 固定武器同步材质和边缘风格，其握点、操作员站位和后坐／装填动作尺寸保留。

本轮不修改人物模型、骨架或着色器。使用现有合批层级，车体、轮履、炮塔和后坐组件各自更新。

## 炮塔、枪口与抛壳（2026-09-26 后续修正）

用户截图反馈炮塔和弹丸位置需要优化。代码检查发现：偏前的炮塔造型仍绕车身原点旋转；多管武器共用整组 0.20 m 后坐；部分车载抛壳依赖「枪口后方 0.32 m」回退位置。

- `vehicle_dimensions.gd` 提供车型对应的炮塔座偏移。炮塔座跟随车体，水平回转绕自己的座圈，炮塔命中盒采用同一中心。
- `vehicle_weapon_rig.gd` 为主炮、同轴机枪、机关炮、榴弹发射器和迫击炮分别保留俯仰、后坐、枪口、炮尾与抛壳节点。重坦主炮与霰弹炮弹种共用同一炮管。
- 鼠标选点驱动真实炮管俯仰，后坐角作用于模型后由枪口方向直接用于射击和准星，避免重复叠加。主炮采用较大行程，机枪采用短行程；发射瞬间先读取前位枪口，再后坐复进。
- 枪口焰绑定实际发射管，切换武器后不会把上一管尚未结束的火光移动到另一管。炮弹从对应枪口中心生成，可读尺寸的弹体尾部随离膛距离逐步露出，避免首帧向后穿进炮塔。
- 外露的吉普／运兵车车顶机枪从机匣侧面抛壳，延迟抛壳读取真实节点；封闭炮塔的弹壳按舱内收集处理，不从炮管或车顶凭空抛出。固定武器也使用其原有抛壳节点，保留人物动作。
- 长炮管的近处遮挡检测由实际炮尾到枪口执行，准星同步采用该段；保留原伤害、射速、弹药数量和弹道散布。

已完成 7 类车辆、15 种武器模式、不同转向／目标高度／后坐时刻合计 270 组静态变换计算，座圈中心误差为零，枪管轴向与枪口方向向量差小于 0.000001。该计算不代替画面和手感验收。

同一演武场中 Tab 选车后，用 G / 数字键 / 滚轮逐项切换、左键开火，重点观察炮管出口、火光和抛壳口；F1 近看，F 离开操作位。

后续已按用户反馈拆分弹壳规格和排壳动作，覆盖同轴机枪、重机枪、机关炮、榴弹、主炮和野战炮，详见 [载具与固定武器弹壳](mounted-cases.md)。

## 人物与载具比例（2026-09-26）

以用户原人物的尺寸为基准。对原 GLB 的 `Rifle_idle` 首帧做蒙皮矩阵计算，身体底部约 -0.012 m，头盔顶部约 1.925 m，含头盔总高约 **1.94 m**。这是项目内模型尺度，不是现实人体标准。

用户先确认「紧凑载具＋封闭驾驶舱」，在长宽增加约 12% 后再次反馈仍然偏小。本轮在该版基础上再增加约 **20% 长宽**，俯视占地约增加 44%。人物尺寸不变，保留从吉普到重坦的体量递增。上车后乘员在封闭驾驶舱内；吉普继续使用帆布篷、窄不透明车窗和车顶武器座。仍不要求新增驾驶员全身坐姿、方向盘握持或车内乘员动画。最终画面由用户试玩评价。

| 车型 | 车体长 × 宽（m，含轮履） | 车长 / 人高 |

| 武装吉普 | 3.00 × 1.82 | 1.55 |
| 侦察装甲车 | 3.12 × 2.02 | 1.61 |
| 装甲运兵车 | 3.68 × 2.39 | 1.90 |
| 步兵战车 | 3.90 × 2.54 | 2.01 |

上述为车体标称尺寸，不含前伸炮管，高度判断不含天线。重坦由前一版 3.75 × 2.44 m 调整为 4.50 × 2.93 m；吉普由 2.49 × 1.52 m 调整为 3.00 × 1.82 m。高度随纵向长度等比增加，避免轮胎截面变椭圆。固定重机枪和野战炮仍保持原尺寸，使原角色握持、双脚承力和退壳装填位置保持一致。

`scripts/vehicle_dimensions.gd` 集中维护这些尺寸。车体和炮塔各自在自己的朝向下缩放，轮子所在的 Y/Z 平面等比缩放，保持轮胎圆形。人物骨架与原角色比例作为固定参照。

碰撞、射线选点、弹丸命中和车顶承托读取同一组车体／驾驶舱／炮塔尺寸，替换全车统一 1.9 m 高的碰撞盒；下车点按车体边缘和人物半径计算。模型枪口仍由实际节点提供，跟随同一缩放。

沿用同一个演武场验收：Tab 选车试驾后按 F 下车，人物会站到车身旁，可用 F1 近景观察身高、车宽和舱盖的比例，再按 F 上车观察封闭驾驶舱的观感。

用户反馈整体配色单一，要求制作敌我两套涂装。本轮以原人物的蓝 / 红纸感色系为基准：

| 部位 | 我方 | 敌方 |

| 舱盖、上装甲、间隔侧裙 | 浅蓝灰 `#abc2d3` | 浅暖红 `#d5a6a7` |

- 卡其帆布、石墨黑橡胶、冷灰钢件、深青玻璃、黄铜弹链、暖色车灯分别保留自己的颜色。材质不再把所有零件压成同一灰蓝色。
- 保留与人物一致的墨线、纸感排线方向、圆润零件和克制轮廓，不改变人物原材质或骨架。
- `vehicle_livery.gd` 解析场景里的 `team`（`blue` / `red`，兼容数字 0 / 1）并提供涂装。旧场景的 `neutral` 保留独立中立灰绿。运行时车辆数据保存阵营，试驾敌车不会自动改成我方涂装；本轮不新增敌方驾驶 AI 或修改阵营伤害规则。
- 材质角色通过顶点颜色 alpha 的 1–9 / 15 编码穿过合批；这里只是材质标签，所有载具零件仍使用不透明渲染。着色器分别读取车漆、金属、橡胶、玻璃、帆布和标识，避免依赖颜色相似度猜测部件。
- 七类移动载具和两类固定武器均提供蓝 / 红版本。默认演武场为 **14 辆车 + 4 座固定武器**，每种成对摆放；西侧车辆列距 8 m、行距 5.8 m，给增大后的车体、炮管和下车位置留出空间。
- Tab 原有「车辆 / 固定武器」列表显示「我方 · 蓝」/「敌方 · 红」，鼠标悬停显示尺寸；「前往车辆涂装区」把人物带到两列之间。`--vehicles` 仅调整同一演武场的起始观察位置。F8 原有场景工坊增加「载具阵营」，放置、修改、复制及 JSON 保存沿用场景的 `team` 字段。

资源与数学检查：蓝 / 红各 9 种装备的主装甲、浅色面板、钢件、识别色和标识标签均保留到最终网格，蓝 / 红主色材质参数与配置一致。车身网格实测长宽与标称值差异最大约 1.3 cm（侦察车倒角），其余小于 3 mm；停放车体间最小净距约 1.515 m。放大后再次计算 270 组武器变换，炮塔座中心误差为零，枪口方向误差小于 0.000001。以上不代替用户画面与手感验收。

## 履带带体侧面缺失修正（2026-09-28）

用户截图中的负重轮下方缺少连续带体。原带体只有一圈外侧薄面，两个侧面和内侧未封闭，最低面又与地面重合，导致侧视和贴地时不可见。

- `vehicle_track_mesh.gd` 生成外侧、内侧与左右环形侧边组成的闭合履带环，中心保留负重轮开口。单条带体 112 个三角面，沿用既有合批与橡胶材质标签。
- 下缘两侧加入细小履带块端面，提高轮下带体的辨识度。轮径、车体占地和蓝红涂装不变；原断履带的局部脱落表现继续保留。
- 车辆共享接地姿态保留 1.2 cm 接触余量，避免履带最低面与地面重合闪烁；碰撞和真实枪口读取相同高度，没有单独抬高显示模型。

必要几何 / 资源检查：五种履带尺寸共 3,670 项闭合边、三角面朝向、材质标签与双侧射线检查通过；每条闭合网格 168 条共享边均连接两个三角面，负重轮中心保持开放。原 18 套蓝红装备资源与车体尺寸检查通过。用户仍通过联合演武场 Tab 选车亲自检查各方向画面。
