# 首关装备使用与进攻接续 · v2026.09.30.59

当前交付 **v2026.09.30.60** 进一步按用户反馈加入方向压制。固定 / 车载 / 随身机枪在已知方向约 ±23° 范围开始开火，不等待精确身体瞄准。固定/车载机枪每 1.2 秒循环中射击 0.9 秒；随身机枪约 0.85 秒点射 / 1.1–1.25 秒循环。枪管继续实际转动，不先跳到目标方向。固定 / 车载在原方向附近小幅扫射；射击条件保留实际弹药、装填、友军扇区和高度检查，不能朝完全无关方向或天空乱射。

目视记忆最多 1.8 秒；机枪可以用附近 12 m 队友不超过 1 秒的新鲜目视报告取得射击方向，转发保留原观察时间，单凭听觉不能取得盲射目标。失去观察和装填均停止火力支持，不把持续点射等同敌人已经被压制。新增机制不增加观察射线配额，仍用原有真实弹体、空间索引和效果批次；更长点射可能增加同时在飞弹数，满员实战性能需要用户验收。

入口是原 `res://proving_ground.tscn` 的第一关石墙果园，默认 T01；已有 Tab 面板仍可在开战前选 T02 / T03。继承 [v55 三维战术](campaign-ai-3d-runtime.md) 的材料穿透、姿态、补兵身份和实际破口机制。

## 计算边界

沿用原 1000 / 2000 μs 总决策预算和每帧最多两次 A*。车辆任务几何与寻路分开：每帧最多一个任务作业、两个车体姿态查询，约 350 μs 的协作时间片，原子查询可能越过时间片。每件装备招聘每 0.75 秒轮询，目标扫描约 0.48–0.60 秒；交通/步兵进展检查仍 0.2 秒缓存。不会为了战术额外增加相机、模型或 Draw Call。

任务几何使用真实碰撞查询，忽略暂时路过的人体作为永久路障；真正驾驶仍双向检查人物和所有实体。远处破坏不重启整条有效路线；出现新的实际阻挡仍由真实驾驶停止、倒车和有限释放处理。本批没有引入全局性能标准。
