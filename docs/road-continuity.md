# 道路连续性修复 · v2026.09.29.13

用户标注的断口位于首关 `farm-access-road` 的折线连接处。旧 `terrain_paths.gd` 对每段单独生成矩形条带，外弯缺少连接面；两个转角均可在物理路肩范围内找到没有路面三角形覆盖的位置。原地形高度为 0，此次无需改动地形、车道、寻路或碰撞。

`road_surface_mesh.gd` 先按整条采样路径生成带圆角和圆端点的连续轮廓，然后与真实地形网格逐三角形相交。地面起伏与显示仍共用 `terrain.height()`。多条道路一并烘焙：路面优先于路肩，交叉区域由一个面片拥有，不叠放共面矩形，也不会把另一条路的路肩画到路口中央。道路闭环的内部空地保留。

中心虚线按整条路径的累计长度切分，穿过采样节点时不重置相位；标线、路面、路肩通过同一面片分割实现，无需增加高差或深度偏移解决重叠。轮廓使用 [Godot Geometry2D 的折线偏移与多边形裁剪](https://docs.godotengine.org/en/stable/classes/class_geometry2d.html#class-geometry2d-method-offset-polyline)，以厘米输入控制圆弧精度。

所有结果仍写入原地面 ArrayMesh 和原材质。只在场景构建时烘焙，没有逐帧更新、额外材质或新增 Draw Call。实体路面高度保持原值，显示面保留原 1.3 cm 贴地余量。修复同样覆盖没有显式 `pathMode` 的旧折线路面。

检查：`qa/road_join_contract.gd` 在旧实现上复现 2 处断口，修复后 357 项检查通过。覆盖真实支路、直角 / 急弯、曲线、重复路径点、端帽、闭环内部、路口单层覆盖以及起伏地形。坡面内插误差小于 0.000001 m。首关道路网约 12,725 个三角形，烘焙约 1.1 秒（仅场景初始化）。检查未推进 AI、移动或开火；画面由用户在原首关验收。
