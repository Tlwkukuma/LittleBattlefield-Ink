# 第一关：石墙果园

2026-09-26。统一运行场景仍为 `res://proving_ground.tscn`，通过 `START_LEVEL_01.bat` 或演武场顶部“第一关”进入。启动脚本先打开装备说明并暂停战斗，按 Tab 或“继续战斗”开始，避免在用户开始操作前消耗兵力。

首关默认使用本地规则 AI，与 Laya 模型服务解耦：启动脚本不加载模型、不检查端口、不等待服务，游戏不创建 HTTP 指挥器或发送模型请求。直接打开项目、演武场内进入首关、F5 重开均默认本地模式，界面显示“本地规则 AI · Laya 已关闭”。本地小队指挥、士兵感知、寻路、射击、掩护和占点保留。

需要恢复模型时显式运行 `START_LEVEL_01.bat --laya`；只有这个可选入口才检查 / 启动原本地模型服务。直接运行 Godot 可在用户参数中加 `--laya`（服务需另行启动）；`--no-laya` 或 `LAYA_AI_DISABLED=1` 优先强制关闭。重开和切关沿用本次启动参数。模型文件和接入实现保留，详见 [资源占用与解耦记录](level01-performance.md#laya-资源占用与解耦)。

## 单局规则

- 初始蓝红各 30 人，蓝方包含玩家；每方总兵力 120，初始预备各 90。
- 补员使用有限队列，每 0.5 秒至多五人，并受人数上限与出生空间约束。
- B 点单人占领用时七秒，两名及以上倍率 1.18；双方在圈内争夺时进度向零回退。
- 蓝方占领 B 点，或场上红军及其储备全部耗尽时获胜。红方占点不会立即判蓝方失败。
- 玩家倒地后按原规则接管最近存活友军；如果没有可接管队友，判失败，即使仍有预备兵力。
- AI 默认由双方本地指挥器分配占点、守点、警戒、掩护和预备任务；单位按当前目视与有误差的近期枪声报告执行。破墙后分批更新真实通行网格，西丘、沟道和坡口沿用同一地形。Laya 为显式启用的可选高层指挥，界面区分主动关闭与模型离线；吉普与固定武器仍由玩家操作。

## 操作

WASD 移动，Shift 快跑，空格跳跃/翻越，C 蹲伏，Z 卧倒。左键射击，右键瞄准；手雷按住左键预瞄、松开投出，右键高/低抛。G 轮盘、数字键或滚轮统一切武器（步兵 1–3 自由武器、4 战术、5 医疗），R 装填，B 切射击模式，E 通用交互，F 就近操作车辆/固定武器；上车后同一套 G / 数字键 / 滚轮对应该车武器。

Tab 显示随身装备与战况，并暂停正式战斗；Esc 暂停/继续；F5 重开当前关卡。Tab 面板或结算面板可返回联合演武场。正式模式沿用实际配装和有限弹药，训练场的换枪、补给、无敌、传送和工坊功能从演武场使用。

接管队友保留其弹药、装备和职业；控制圈、相机、准心、圆镜同步当前玩家。稳定单位槽重生会清理上一生命的延迟抛壳/弹匣动作。
