# 原骨架动作连续性与方向步态（2026-10-09）

## 范围

修改当前使用的 `source_rig_motion.gd`；不替换人物、蒙皮、骨架或动画资产，不修改移动速度、跳跃物理、射击规则、伤害、碰撞半径或战役 AI。仍由真实骨骼生成命中胶囊，并从实际武器节点采集枪口。

源 GLB 与导入基线 SHA-256 相同：
`19db35838b6c1aea4c2ce0807c8c730e0ddc3e43ca9c796a755b3a73a4f4ffb6`。
41 根骨骼、20 段原动画和 4 段持枪副本均保留。

## 确认的问题与修改

1. **跳跃没有参与原有动作切换记录。** 旧实现先记录 idle/walk/run，再局部改成 jump；起跳与落地直接切换骨骼。现在 jump 参与同一个 0.14 秒过渡。原跳跃仍由实际竖直速度驱动：将 +6.4 至 -6.4 m/s 映射到原片段的 18% 至 80%，没有另加空中动画计时器。
2. **骨骼与根位移补偿必须同时过渡。** 每次记录未叠加武器 IK 的源姿态及可见骨盆；混合骨骼之后同时混合其已抵消源根位移的骨盆位置。空中高度补偿仍为原来的 0.73 m，只移到混合之前处理。翻越继续使用独立的进入/退出补偿，不把两套切换重复作用到翻越。
3. **走跑边界反复重播第一步。** 原 4.0 m/s 单门限改为进入跑步 >4.15 m/s、退出跑步 ≤3.75 m/s；只是动画选择，正常 3.4 m/s 走路、5.8 m/s 快跑等物理速度不变。走与跑之间传递归一化步态相位，不从零重来；换持枪/空手层也保留步态。
4. **后退仍播放前进脚步，瞄准横移时髋部没有跟随。** 有武器时，按实际速度与瞄准方向的点积反向采样原走跑片段，前后播放倍率在约 0.167 秒内连续反转，保留当前脚步相位。归一化前向分量低于 -0.20 才切后退、高于 +0.20 才切前进，侧移附近保持原选择。髋部沿移动方向有限转动（反向步态按反方向髋朝向），保留既有 ±0.80 rad / 约 46° 上下身偏角与 20 rad/s 转向上限。停止、卧倒、翻越与空手各自保持原朝向规则；上身扭转和武器解算继续瞄准真实选点。

这些是对已有原动画的选择、相位和衔接修正，不是新增动捕，不保证倒放步态等同于专门制作的后退/侧移动作。侧移仍受既有上下身偏角限制，未用程序重写站立走跑的腿脚关键帧。

## 验证方式

`qa/source_locomotion_check.gd` 只创建离线资源/姿态状态：不运行世界步进、AI、输入、射击、关卡或截图。

- 首轮旧代码 69 项中的 29 项失败；9 组起跳/落地状态样本中，同一时间瞬间切换的腿/骨盆采样点最大偏移分别约 **0.461 m / 0.619 m**
- 修正后相同样本分别小于 **0.00000049 m / 0.00000028 m**；这说明零时间切换连续，不代表真实每帧运动距离或视觉体验评分
- 扩展检查覆盖前进、后退、停止、左右与斜向移动、站立/蹲姿、源腿脚曲线、实际枪口与逐胶囊骨骼端点，以及速度和方向门限抖动
- 所有实际手感、观感和性能结论仍需在原联合演武场由用户验收；没有自动游玩或新预览场景

`qa/source_rig_preservation_check.gd` 从历史 `source_rig_walk.gd` 保留纯资源/数学部分，移除其旧截图阶段。脚、脚趾与 Blender 原样本最大误差约 0.00000631 m，持枪下身层误差为 0。

`qa/special_weapon_check.gd` 仅补上当前 `damage_unit` / `damage_object` 的两个可选参数以修复旧测试覆盖签名；断言与产品行为不变。该问题在原导入基线已经存在，属于测试维护，不算本次产品修复。

当前检查日志在 `qa/iteration_20261009/`；最终数量以其中各检查结尾为准。
