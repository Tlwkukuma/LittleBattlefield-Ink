# 后坐力、准心与方向受击

本轮只做资源读取、编译、相机投影数学及演武场启动检查，射击手感、放大瞄准和动作观感由用户在演武场测试。原模型、41 根骨骼、蒙皮、走跑动画及原武器伤害、射速、弹匣均保留。

## 后坐与散射

`scripts/weapon_handling.gd` 统一管理弹道、枪口朝向、准心与精确瞄准使用的参数。以原目录的后坐力、散射及枪型为基础，常见枪支分别配置每发上扬、横摆、首发倍率与回正速度；这些是本项目的游戏调校值，不是实枪测量数据。未单列的武器仍使用自身原始参数和武器 ID 对应的横摆序列。

- 连射时保留累积上扬，停火延迟后再回正；临界阻尼响应避免硬跳或回弹振荡。首发力度、后续缓慢横摆和小幅随机差异分开处理，下移鼠标可抵消上扬。
- 右键瞄准、蹲伏、卧倒更稳定；移动与腾空增加独立误差，避免狙击枪因基础散射极小而在腾空时仍过准。停步和开镜需要短暂稳定。
- 后坐同时作用于枪身、上半身及后续真实弹丸方向。首发先离开枪口，再产生这一发的后坐冲量。
- 普通弹使用有边界、中心更密集的二维高斯散布。霰弹每次扳机共享一次枪口误差，再围绕该方向分层分布弹丸；霰弹自身散布不因瞄准或卧倒而被不合理地收紧。

## 适合俯视角的瞄准

鼠标射线先拾取可见墙格、车辆、角色骨骼胶囊或地面的三维位置，再根据该点高度计算枪口方向。取消头 / 胸 / 腹的屏幕范围自动吸附；脚、腿、墙根都可直接瞄准，HUD 显示瞄准部位及世界高度。身体各部位胶囊随原骨骼更新，弹道使用同样的三维检测，保留掩体遮挡。墙体逐个存活格作三维射线检测，也能命中斜向弹道从上方进入的墙顶；破坏使用实际命中格，不以相邻已破坏格替代。

准心定位在实际枪口方向，瞄准时显示高度定位线和淡色散射边界；外框随真实散射、距离、连射及姿态变化。颜色区分普通瞄准、对准目标和射线被掩体截住。近身瞄准保留小范围死区，避免目标落在枪管内部时把枪口反算到背后。

| 武器 | 准心 |
| --- | --- |
| 手枪 | 紧凑三向刻线 |
| 冲锋枪 | 分段弧形 |
| 步枪 | 开放四向刻线 |
| 霰弹枪 | 散布圈与弹丸点 |
| 机枪 | 双层刻线 |
| 火箭筒 / 榴弹发射器 | 方形角标与纵向刻度 |
| 迫击炮 / 手雷 | 地面目标圈（手雷圈不预测碰撞后的弹跳） |
| 狙击 / 精确射手步枪 | 细线分划；右键按住或 V 切换同视角精确瞄准 |

精确瞄准始终使用主正交相机，俯角和朝向与普通战斗一致。用户最新选择为 **圆镜跟随鼠标、右键按住放大**：附加圆形 UI 遮罩，外围压暗；镜内仍是同一主视野，不旋转相机，不捕获相对鼠标。

狙击枪默认 2 倍、精确射手步枪默认 1.5 倍，滚轮选择 1.25 / 1.5 / 2 / 2.5 倍。普通步枪/霰弹枪/机枪右键放大 1.25 倍，手枪/冲锋枪 1.15 倍，发射器 1.18 倍；近战、投掷、迫击炮和载具保持原视野。动作近景保留最小视野 3.6，显示实际倍率。V 仍是可选开关；按住右键会接管 V 的锁定，之后松开即可退出。

进入和滚轮变倍时记录鼠标投影锚点，缩放期间保持该点的屏幕位置；角色移动正常跟随，鼠标移动只移动圆镜遮罩，不移动相机锚点。退出平滑恢复原有视野，普通缩放值不被覆盖。下移鼠标压枪的补偿按当前实际倍率换算。

镜内分划投影自原世界准心的实际枪口射线落点：跟随后坐、目标高度与掩体拦截；橙色表示掩体，红色表示目标。遮罩中心是鼠标请求的瞄准位置，实际准星可以偏离它。开镜时隐藏重叠的世界分划和高度辅助线，只保留一套准星。分划刻线是视觉辅助，不是真实密位/弹道补偿标尺。

装填、换枪、进入载具、翻越、武器库、编辑模式、暂停或死亡时取消圆镜。中断时仍按着右键，需要松开再按才会重新进入；从 UI 上按住右键拖回战场不会突然开镜。遮罩不拦截点击，常规 HUD 和面板保留在遮罩上方。只有主相机一次世界渲染，未将启动帧率当作交战性能测试。详细方案见 [圆镜瞄准](circular-scope.md)。

## 持枪稳定与辨识度

手臂目标和肘部解算共同限制在可达范围内，肘部采用随身体朝向的向外 / 向下约束。走跑切换只混合原动画姿态，不把上一帧已解算的手臂再次送回动画混合，避免反馈抖动。身体转向与过近枪口目标也增加连续转向和死区处理。

`scripts/weapon_identity.gd` 保留原武器轮廓，为不同枪支增加独立长度、黄褐 / 木色 / 灰金属配色与立体部件：枪管、护木、伸缩枪托、瞄准镜、提把、P90 顶置弹匣、Vector 机匣、机枪弹箱 / 弹链 / 折叠两脚架等。新增刚性细节合并为可缓存网格，枪口节点与双手握点跟随武器缩放。

上一轮数学与资源检查覆盖三维射线、脚部胶囊、散射范围、后坐累积 / 恢复及 84 把武器构建，共 184 项通过。新增 `qa/precision_camera_check.gd` 只检查相机的实际投影、缩放中变倍、移动跟随与退出恢复，不自动操作演武场或开火；动作、瞄准手感与枪械辨识度仍由用户实测。

## 原动作与受击方向

`assets/tripo_source/combat-clips.json` 是从现有 Blender 文件只读提取的原动作范围和骨骼位置；没有改写 Blender、GLB 或蒙皮。提取脚本为 `tools/inspect_source_combat.py`。

| 条件 | 原动作 |
| --- | --- |
| 头部命中 | `hit_to_head` |
| 左右侧命中 | `hit_to_side` + 实际冲击方向修正 |
| 腹部命中 | `hit_to_stomach` |
| 正面躯干命中 | `hit_to_body_01` |
| 背面躯干或爆炸冲击 | `hit_to_body_02` |
| 侧向或头部致命命中 | `fall` |
| 其余致命命中 | `defeat_03` |

方向依据弹丸飞行方向（爆炸则依据爆心到角色的方向）转换到人物朝向计算，不随机指定。受击保留原动作的上半身旋转变化，并按真实冲击方向补充倾斜；动作渐入渐出、不会替换正在播放的腿脚走跑。连发 / 霰弹在极短时间内合并反应，避免同一帧不停重启动作。

倒地从当前姿态衔接，使用所选原动作末端的倾倒方向对齐冲击方向，停在落地末帧。物理位移与原动画水平位移分开，避免重复滑移；尸体的滑动检查墙体阻挡。`defeat_02` 为约 8.5 秒、结束后恢复站立的失败情绪动作，仍保留在资产内，不作为死亡动画播放。

操作：Tab 换枪，左键开火，右键瞄准，C / Z 对比姿态稳定性，F1 查看动作近景。可绕到靶兵侧面或背后，分别瞄准头、胸、腹比较受击和倒地。

## 命中血液飞溅（2026-09-26）

用户认为命中反馈不足，明确要求增加血液飞溅。旧人体命中沿用墙体通用碎屑，死亡仅留一块淡色圆斑；现在人体伤害事件单独接入 `scripts/blood_effects.gd`，不再生成墙屑。保留原方向受击、死亡动作、爆头帽子击飞和武器掉落。

弹丸把真实接触点和含高度分量的飞行方向传给伤害反馈；墨迹从实际中弹部位出现，不统一从胸口生成。瞬间的暗红色飞溅约 0.16–0.23 秒，较小血滴受重力下落；颜色、深色边缘及不规则轮廓沿用墨线美术。强度随伤害调整，头部与致命命中更明显。近战和爆炸则用角色当前高度及冲击方向作为接触点的回退值，未修改伤害参数。

同一帧同一角色的多个霰弹命中合并为一次效果，合并时保留头部和致命信息；55 毫秒内普通重复命中不叠加新云团。血滴按生成时仍存活的墙体几何检查短弧线，遇墙停止，不在墙后留下地面痕迹；轨迹预计算后不追踪飞溅存续期间新增的移动障碍。落地痕迹保留约 10–14 秒，最后 2 秒淡出。没有断肢、屏幕血遮罩或覆盖整个人的大团红雾。

两组可复用 MultiMesh 分别绘制空中飞溅与地面痕迹，最多 192 个空中实例、96 个地面实例；每帧最多创建 6 次飞溅、执行 96 次轨迹射线查询，超出查询预算时保留短暂接触墨迹。血液实例独立于弹壳/弹匣额度，没有每滴血的独立节点、刚体或灯光。该上限是实现约束，尚未进行 50 vs 50 帧率测试。

`qa/blood_resources_check.gd` 的 110 项资源与数学检查通过：命中点/高度/方向、霰弹合并、致命强度、墙面截停、破口后的可达轨迹、粒子与查询预算、批次缓冲及超时清理。未自动开火、操控游戏或截图验收。

`START_HIT_FEEDBACK.bat` 打开同一联合演武场，装备 M416 并站到无遮挡靶兵前。由用户对比身体、头部、脚部，以及 Tab 换用霰弹/狙击后的飞溅反馈；F1 可看近景。
