# v2026.09.28.42：轻量表现后的尖峰处理

承接 [v41](frame-budget-v41.md)。用户在该版亲自试玩反馈 60 FPS，但原始日志 P99 仍常为 21–27 ms，出现 53 Draw Call，因此继续处理剩余开销。

## 变化

- 火箭、迫击炮弹、榴弹、手雷的显示部件合并，并使用已有武器几何图集批量绘制；预热全部相关资源。保留原三角形、弹体 / 尾翼位置、飞行缩放与真实弹道，只去掉手雷小拉柄额外线框。没有减少实际弹丸数量或碰撞。
- 枪声听觉每个画面帧最多新增 4 条遮挡射线；复用 4 m 声音区域的 0.30 秒估计，拓扑破坏使缓存失效，高度相差 1 m 时重新查询。超预算按衰减后的模糊声音处理，不提升为可见目标；真实视线 / 弹道 / 伤害不使用这份缓存。缓存最多 256 项。压力反馈仍每 AI 步更新，记忆置信度衰减约 5 Hz。
- 墙上每个弹痕的两个小盒体改为两个平面墨痕，破口断面的微小石粒改为三块平面纹理；保留破口、断面实体、实际 HP、坍落与碰撞。减少每次损伤更新的装饰几何。
- 4× MSAA 改为 2× MSAA，原分辨率和画面范围保留。这是明确的抗锯齿取舍，需用户确认边缘是否可接受。

## 验证

- `v42_resource_contract.gd`：6,314 项通过，包含全目录特殊弹体原三角形 / 尾翼位置、共享实例注册、听觉查询上限 / 缓存 / 破坏失效与“听到不等于看见”。
- `frame_budget_contract.gd`：8,658 项通过，包括 252 个墙格的损伤、剖面切换与原同步几何逻辑，武器图集无截断和保守裁剪。测试使用当前墙体表现，不把它解释为修改前后完全同画面。
- 实际 OpenGL 冻结资源检查包含全部特殊弹体、60 个枪口焰、尸体、掉盔、弹壳、弹匣、GPU 烟尘 / 血迹和载具特效。最高 **47 Draw Call**，全目录武器替换为 46；无脚本 / 着色器错误。最终结果在 `qa/performance/v42-gpu-final.log`。
- 首次特殊弹体检查发现手雷拉柄另有一层线框，导致“一个三角形表面”断言失败；已明确取消该微小线框、保留三角形本体并重测通过。失败日志保留，未作为通过证据。

没有自动操作或推进战斗，仿真时间和射击数均为 0。上述检查不能代替用户的移动交火验收，**15 ms 的实战目标尚未宣称达成**。本版实际启动身份写入 `qa/performance/latest-release-launch.json`。
