## 实际参考

本机 Duckov 2.3.30 的 `AimMarker` 绑定 `reloadProgressBar`，读取动作进度；`ActionProgressHUD` 读取 `IProgress.GetProgress` 并控制填充、淡入淡出和结束；`ReloadHUD` 用 `GetGunReloadable` 控制可操作状态。`ADSAimMarker` 接收 ADS 数值和实际散布。

资源层还核实 `AimMarker` 下的 `ActionProgress`、约 60×60 的 `FillBackground`，以及 `SimpleIndicatorEntry_Reload` / `SimpleIndicatorEntry_Focus` 的输入图标和标题。这些是序列化层级尺寸，不是游戏运行时的像素测量。本轮不宣称复制原作全部 UI 或已实玩逐帧对照。

可复查 [调用记录](duckov-combat-hud-observations.json)、[UI 层级](duckov-hud-prefabs.json)，对应工具 `tools/inspect_duckov_combat_hud.ps1`、`tools/inspect_duckov_hud_prefabs.py`。只读解析，未导出或导入原作图片、模型、字体、声音。

## 本项目实现

- 右下角为当前武器卡：原有枪械图标、弹匣 / 备用弹数、射击模式、R 换弹和鼠标右键聚焦。暖灰底、浅色文字、金色换弹、浅绿聚焦；无多余大幅动画。
- 换弹时准心外围出现细进度环，下方显示“换弹中”和剩余秒数，武器卡也显示同一实际进度。读取 `reload / reload_duration`，手动换弹、空仓自动装填、手持枪械和载具共用；不提前宣布完成，不另起视觉倒计时。
- 弹匣低于约 20% 提示换弹。满弹匣、无备用弹药、全部耗尽、翻越 / 梯子中分别显示原因，不错误提示可执行操作。近战没有虚假的弹量或换弹。
- 聚焦开始显示“聚焦中”；实际散布收敛后显示“聚焦就绪”，移动、腾空和射后回稳分别反映当前状态。细进度线由实际瞄准散布相对稳定下限计算，不能站着计时就无视移动与后坐。中断后仍按住右键时提示“松开后重按聚焦”。
- 狙击沿用先扩大范围、再出现圆镜；武器卡显示当前视野范围。圆镜和普通准心继续精确跟随鼠标。手雷右键仍显示高 / 低抛，近战与车载不虚构聚焦。
- E/F 的已有交互内容用同一轻量底板展示。旧左上角聚焦说明与底部重复弹量、装填秒数和瞄准高度移除；原顶部验收按钮、版本 / 启动标识、战况和性能面板保留。
- 面板、暂停、编辑器、倒地及非战斗阶段隐藏新提示；准心旁提示在鼠标悬停 UI 或攀爬时隐藏。所有新绘制都忽略鼠标输入；仅文字贴边换位置，不移动实际准心。

只是读取游戏状态的 HUD，没有修改射击、装填时间、后坐、散射、子弹或原动作资源。每帧复用一个绘制控件和三个样式资源，枪械图标只在切换时更新。
