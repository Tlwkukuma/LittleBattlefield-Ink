按用户要求扩展环境预制体。新增 19 个单体组件及对应单体预制体、6 个组合预制体；工坊目录现在共有 102 个组件、83 个预制体。原始导入的 63 个组件、52 个预制体及关卡 01 坐标没有替换或批量放大。

## 单体与组合

| 类型 | 本轮内容 | 实际形状差异 |
| --- | --- | --- |
| 阔叶树 | 老橡树、幼年橡树、白桦双干、高瘦白杨 | 粗细树干、根部、分枝、冠幅与高度不同；白桦双干带浅色树皮和细横纹，白杨为高而窄的树冠 |
| 针叶树 | 高山冷杉、厚雪冷杉 | 多层锥形枝冠和实体木枝；雪杉更矮更宽，额外生成立体积雪层 |
| 旱地树 | 枯树断枝、伞冠树、弯干棕榈 | 枯树没有叶冠；伞冠树低干分叉、横向扁冠；棕榈分段弯干、长叶分段向外下垂 |
| 林地杂物 | 倒木、树桩 | 水平树干和断枝、浅色断面；短树桩、外露根部 |
| 岩石 | 花岗岩巨石、低矮扁石、倾斜板岩、风蚀砂岩、砂岩拱、玄武岩柱、红土台岩、碎石簇 | 圆肩复合岩体、低平台、倾斜尖片、岩层凹凸、真实拱洞、六棱高低柱、阶梯状台面、独立碎石间隙 |

九种立树的标称高度约 3.7–8.2 m；倒木、树桩与低石提供低掩体，大石与柱岩提供高掩体。所有尺寸可在 F8 调整，不使用单纯颜色变化来区分这些种类。各树冠、枝干与岩体使用原创程序网格及项目既有墨线材质，没有拷贝参考游戏模型。

六套组合：混合林地、白桦疏林、积雪松林、沙漠旱谷、红土地岩脊、山地碎石带。组合由独立成员组成，破坏一棵树或一块石头不会把整套组合一并删除；雪林中的岩石会额外生成积雪顶盖。

组件 ID 与标题、基准尺寸、组合成员集中在 `scripts/nature_library.gd`。单体预制体 ID 为 `nature.single-` 加组件 ID（点替换为连字符），例如 `nature.single-tree-oak-mature`、`nature.single-rock-sandstone-arch`。组合 ID 分别为 `nature.oak-grove`、`nature.birch-line`、`nature.snow-stand`、`nature.desert-wadi`、`nature.red-ridge`、`nature.rubble-field`。

## 几何与战斗

`nature_forms.gd` 生成树干、枝条、叶团和岩体部件；`nature_geometry.gd` 使用这些相同的多面体表面进行渲染、射线、人物竖直身体切片、脚下承托和爆炸距离查询。碰撞先进行范围筛选，再测试真实几何，不把不规则岩石或带洞岩拱封成实心长方体。

- 树干、木枝、外露树根参与通行与挡弹；叶冠是可穿过的视觉植被，不能作为实心树墙或空中站台。橡树树冠下可通行，真实低枝仍会阻挡身体。
- 岩拱中心可以走人、过弹，上方横梁和两侧柱体仍挡弹；低扁石能实际承托人物，不依靠画面高度假装可站立。
- 爆炸到树木、岩石的距离按最近实体表面计算，避免高树的根部明明在爆区内，却因为树冠包围盒中心太高而不受损。
- 保留既有伤害、碎片、通行及寻路刷新。单体当前按整棵树 / 整块组合岩体损坏，不模拟逐枝折断、树干倒伏刚体或按受力应力开裂。组合预制体内成员可独立破坏。原有墙格枪伤、爆破洞口和墙体坍落未改变。
- 自然物件逐个落到实际地表高度；组合不会被强行安放在同一水平基础面。极陡坡仍建议手动调整位置或海拔，当前没有地面自动挖平或根系变形。

每个自然物件合并为一个三角面绘制表面，本轮最大单体网格 3,276 个展开顶点。造型随机量由物件 ID 决定，重载不会随机换样。高度、整体缩放、旋转和 JSON 保存 / 重载均沿用现有编辑流程；重选预制体时高度栏读取对应目录高度，避免被默认墙高 2.8 m 覆盖。

## 统一验收

仍使用 `res://proving_ground.tscn` 和默认联合演武场。19 个单体样本已摆在东南侧树木区和东侧岩石区，并有地面名称；不另建替代场景。入口：`START_NATURE.bat`，或 Tab →「树木预制体区 / 岩石预制体区」。F8 可搜索单体和组合名称、放置、旋转、调高度、保存与重载。

用户可先对比老橡树 / 幼树、白桦 / 白杨、冷杉 / 雪杉的体量和轮廓；再从砂岩拱中心走过并射击上梁、两侧石柱；最后用枪械和爆炸破坏树干、大石，确认物件消失后相应通路开放。叶冠不应挡住树下通行，附近仍存活的成员不应一起消失。雪地、沙漠的真实地形，以及住宅楼梯和墙体破坏继续在同场景验收。
