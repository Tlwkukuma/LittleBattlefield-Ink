# 简洁准心（2026-09-26）

用户反馈：原准心斜向拉长、信息过多，希望霰弹枪改成范围方框；随后明确所有枪的准心都跟随鼠标，不处理遮挡提示，大小与位置两方面都需要简化。

## 参考与取舍

[VALORANT 3.03 官方说明](https://playvalorant.com/en-us/news/game-updates/valorant-patch-notes-3-03/) 将普通、ADS、狙击镜中心点分别配置，并提供霰弹枪使用主准心的选择。本次参考这种分层表达；霰弹枪方框是按用户要求选择的形状，不声称所有 FPS 或《逃离鸭科夫》都采用方框。

沿用 [鸭科夫参考规范](duckov-reference.md) 的固定 2.5D 视角。上一版只对照了官方设置分类，未充分对照实际画面；仍将实际落点作为准心中心，造成截图中圆镜与准心分离。现在以用户最新要求为准：所有武器直接使用绝对鼠标坐标，圆镜与镜内分划共享同一个中心；形状不受三维投影压缩。

| 类型 | 显示 |
| --- | --- |
| 霰弹枪 | 完整细方框与小中心点；半边长 12～32 个逻辑像素，S1897 站立约 23 |
| 步枪、冲锋枪、机枪 | 四条短线与小中心点，间隙随散布变化 |
| 手枪 | 更短的十字线 |
| 狙击枪 | 细十字；圆镜内保留长一些的四条细线，取消多组测距刻度 |
| 火箭、榴弹发射器 | 四角括号与中心点 |
| 投掷物、迫击炮 | 简单圆圈与中心点，去掉抛物线和额外定位线 |
| 近战 | 小中心点 |

## 行为边界

- 准心中心直接使用鼠标屏幕坐标，步行、载具、开镜都相同；枪口摆动、实际后坐、墙面遮挡不会移动它。使用统一淡白色，取消悬停单位变红和掩体变橙；确认命中时短暂出现 X。实际子弹碰撞、后坐和三维目标高度的逻辑未被修改。
- 显示尺寸读取与弹丸相同的 `Handling.spread` 角度，包含移动、姿态、瞄准稳定和连射散布；霰弹固有散布不会因为 ADS 消失。取消距离和像素/米换算，方框不再随瞄准远近物体或镜头缩放忽大忽小。霰弹半边长为 `clamp(8 + spread × 120, 12, 32)`，表示精度强弱而非弹丸的世界落点边界。精度下降立即扩张，恢复时平滑收拢。
- 删除散弹内部点阵、中心菱形、地面高度辅助线、射锥虚线、第二目标横杠和多余测距线。淡色线加深色描边，以适应浅灰地面、草地和墙面。
- 保留圆镜跟随鼠标、按住右键放大、松开恢复。圆镜出现时普通准心隐藏，圆镜与分划使用同一帧鼠标样本，不再分离。
- UI 使用 `MOUSE_FILTER_IGNORE`，不拦截瞄准和点击；武器库、编辑、暂停、翻越、死亡及悬停交互 UI 时隐藏。场景重建会清理其 UI 节点。
- 准心不再逐帧重建三维网格，也不再查询预测落点和遮挡；不增加世界相机或后处理。弹道系统自身的碰撞检查保留。未测量整场性能变化。
