# 固定重机枪与野战炮

用户明确要求：这两件装备作为固定武器单独处理，显示人物操作，并通过人物摆动表现强后坐力。沿用用户提供的 41 骨骼角色、原蒙皮和原动作资源。

后续车辆风格统一时，本模块也接入 `vehicle_style.gd` 的淡蓝灰纸感、细墨线及柔和边缘。固定武器不随七类移动车辆放大，人物握持点、支撑位置、炮管行程与动作时间保持原尺寸。

弹壳也已拆分：固定重机枪使用重机枪长壳；野战炮在真实装填进度 22%、后膛打开后，向后排出单独的大炮壳，再进入送弹动作。详见 [弹壳规格与动作](mounted-cases.md)。

## 外观与动作

| 装备 | 模型结构 | 人物与动态 |
| --- | --- | --- |
| 固定重机枪 | 带脚铲和支撑杆的三脚架、锁紧柱、回转座、机匣、散热护套、瞄具、供弹盒／弹带、左右握柄 | 人物站在后方，略屈膝前倾，双手对准握柄；连射有短促肩部承力和轻微左右不对称摆动，停火回稳；装填时打开供弹盖、双手依次接触供弹与拉柄位置 |
| 野战炮 | 带轮毂和辐条的轮式炮架、分叉尾架／驻锄、分片炮盾和中间炮管开口、复进筒、滑动后膛、手轮与击发柄、制退器 | 人物站在侧后方，一手扶手轮、一手控制击发柄；开火后炮管最多后退约 0.29 m，随后复进，人物稍延迟屈膝、后仰、侧倾再回稳；驻锄处出现短促少量扬尘；装填时后膛打开、右手送弹再回握 |

两者的射击动作按真实开火时间计算。重机枪机构约 0.105 秒复位，野战炮约 0.68 秒复进，人物约 0.88 秒完成主要回稳。它们是本项目制作的表现参数，不是原作实测或现实武器数据。

炮架／三脚架留在地面。人物随水平瞄准变化小步换位，躯干承力时双脚目标留在地面；每帧从原动作采样后叠加骨盆、脊椎和四肢调整，避免姿态逐帧积累。双手 IK 读取模型上的握柄／手轮／装填接触点。离开操作位后恢复原步兵动作和手持武器。

## 与封闭载具的区别

- 固定武器不响应驾驶输入，沿用各自已有的转向范围和速度。
- 人物在操作位可见，位置和命中部位跟随实际姿势；关闭玩家无敌后，可以命中裸露操作员，炮盾和武器部件按自身几何提供遮挡。
- 操作员死亡或固定武器损毁时释放操作位。正常按 F 离开，优先保留人物当前站位。
- 固定武器使用独立的支架、炮盾、机匣碰撞形状，HUD 显示武器耐久和离开操作位提示。
- 车内隐藏人物的规则继续用于 7 类封闭载具。

实现位置：`emplacement_art.gd`、`emplacement_profile.gd`、`emplacement_motion.gd`，由联合演武场现有装备生成、枪口读取、角色更新与交互入口调用。

## 验收与检查范围

继续使用 `res://proving_ground.tscn`。Tab →「车辆 / 固定武器」选择「固定重机枪」或「野战炮」→「立即试驾 / 操作」。鼠标转向，左键开火，R 装填，F 离开，F1／滚轮观察近景。实际使用场景中由玩家接管时才出现操作员。

已做资源导入、演武场加载和关键姿势的骨骼／握点数学检查。在各自的待机、后坐及装填代表姿势中，双手和双脚目标误差按 0.1 mm 精度输出为零；这是节点位置检查，不能代替皮肤变形、穿插与动作观感的用户验收。未自动游玩或提供独立预览／验收截图。

## 固定机枪人物错位修复（v2026.09.28.43）

用户反馈接管机枪后，人物显示在机枪旁边的墙后。代码发现固定武器动作绕过了 `SoldierMotion.update()`，完成骨骼 / IK 更新后未递增 `render_pose_revision`；`crowd_batches.gd` 因版本号不变继续复用走跑时的骨骼调色板。原走跑动画含根位移，切换待机时模型的根位移补偿已改变，复用旧骨骼会使合批人物偏离物理操作位；实时骨架和遮挡剪影则可能与合批身体不一致。

- `EmplacementMotion.update_operator()` 在完成握持、脚步、后坐、命中形状与阴影计算后发布新姿态版本；沿用原有批次，不为操作员另造角色或每帧重建网格。重机枪和野战炮共用修复。
- 固定武器和操作员不再将显示高度写死为零。固定武器初始化高度来自地形，其枪口 / 弹壳节点随根节点，碰撞盒在原本地高度上加同一海拔，避免累积偏移。
- 接管及转向检查使用操作位真实地表高度；操作位和武器高差超过 0.35 m 时不允许继续转入，避免在沟边把人物拉到握柄够不到的位置。离开操作位也使用实际高度检查阻挡。
- 固定武器分支现在同步地面阴影与脚环高度，保持骨架、人物显示和交互位置一致。

必要编译 / 场景启动检查通过；未自动操作机枪或进行截图验收，接管、转向、连射、装填和离开后的观感由用户在原联合演武场试玩确认。
