# 职业形象与交互键（2026-09-26）

用户要求参考战地增加职业，先制作形象，并将 E 设为交互、F 设为进入载具。本轮完成五套可切换的原骨架职业装备和联合演武场展示；治疗、救起队友、维修、补给及侦察技能另行实现。换装不更改当前武器、伤害、弹药或阵营。

参考的是装备对应职责、在战场上能读懂身份的组织方式。[战地 V 官方医疗兵介绍](https://www.ea.com/en-gb/games/battlefield/news/battlefield-5-medic-class-and-combat-roles)保留独立医疗兵；[战地官方职业页](https://www.ea.com/en/games/battlefield/battlefield-6/features/classes)区分突击、工程、支援和侦察。本项目按用户要求将医疗单列为第五种，并自行设计适配墨线胖小兵的装备，没有导入原作模型或复制角色。

蓝/红阵营继续由原军服和头盔条带主导；职业点缀色只用于装备，不覆盖阵营颜色。五套装备都绑在原头盔与 Spine02 背包挂点上，骨骼、蒙皮和原走跑动作不改。倒地保留所选装备，头盔击飞时复制职业头盔配件；换装不会让已经丢失的帽子重新出现。

实现为 `scripts/soldier_classes.gd` 的可缓存刚性网格：头部和背部两组装备，圆角布包、扣带及墨线材质。实际装备资源最多约 7104 个三角形/角色，共用合并后的网格和材质，不为装备添加灯光或独立骨架。尚未据此进行 50 vs 50 性能测量。

## 在演武场查看

`START_CLASSES.bat` 打开原 `res://proving_ground.tscn`，默认玩家为医疗兵，前方依次陈列五种职业样兵和装备包。这些展示样兵用于看外观，不参与战斗。靶兵也配置不同职业的敌方配色，仍保留原战斗属性。

- 靠近装备包按 **E** 换装，只激活最近且未被实体墙遮挡的一项。
- **Tab → 职业形象**可以直接换装；“样兵转身 90°”用于查看正侧背面，“前往职业展区”回到展台附近。
- **F** 进入/离开载具，接管/离开固定武器；E 不再上下车。界面、提示及操作文档同步更新。
- 交互在死亡、腾空、翻越、车辆内部及菜单输入期间不执行；编辑模式保留原 Q/E 旋转操作。
- F1 和滚轮继续使用原 2.5D 视角。F5 重置场景保留当前职业选择。

`qa/class_resources_check.gd` 共 94 项资源与数学检查：职业与阵营变体、原网格/蒙皮/41 骨骼不变、绑定关系、换装节点复用与旧装备清理、落帽配件复制、装备规模，以及距离/遮挡/状态下的 E 选择规则。另完成原演武场编译与启动检查，不模拟按键、开火或截图；穿戴观感与动作中的装备穿插由用户试玩验收。
