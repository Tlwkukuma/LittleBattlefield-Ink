# v2026.09.28.44：墙体外观预烘焙

v42 用户实战中出现过一次 204 个墙格显示更新耗时 22.642 ms。v43 为另一会话的固定武器修复，本版在其基础上保留该修复。

## 实现与取舍

- `baked_wall_surface.gd` 在关卡载入时预烘焙每格完整、轻损、重损三种外观，以及完整高度 / 1.15 m 剖面两种视图。战斗中选择已经准备好的索引数据，不再生成顶点、逐顶点整理属性或重新上传整格顶点。未选中的外观没有有效三角形提交。
- 裂纹和受损颜色改为三个档位：损伤 ≤6% 使用完整外观，6–45% 使用 25% 损伤外观，≥45% 使用 65% 损伤外观。**仅表现分档，真实 HP、弹道、破坏、坍塌、通行和 AI 判定没有分档或延后。**
- 预留原本藏在相邻实心墙格内部的断面。邻格消失后，断面直接露出，避免再重建周围四格。门窗和死亡格不提交有效三角形。
- 原每格最多三处弹痕改用一个共享平面批次；保留位置、朝向和颜色，墙格消失或剖面低于弹痕时同步隐藏。首次着色器编译在载入阶段预热。它增加最多一个绘制批次。
- 两个常用剖面高度以外的编辑器高度仍使用原生精确墙体网格，作为正确性回退；首关正常行走只使用两个烘焙高度。新增实战日志区分剖面变化格、HP 变化格和回退次数。
- 沿用默认安全渲染线程；没有启用上一轮失败的 Separate 实验模式，没有降低人数、物理频率、分辨率或再次削减抗锯齿。

## 验证结果

`qa/baked_wall_contract.gd` 在同一进程交替比较旧版 / 新版的 216 个冻结墙格，使用真正 OpenGL 渲染驱动。只修改资源夹具，不发射武器、不调用战斗步骤、不注入输入。

| 资源更新 | 旧版中位耗时 | 本版中位耗时 | 本版最大值 |
| --- | ---: | ---: | ---: |
| 大面积受损外观 | 27.769 ms | 0.744 ms | 0.940 ms |
| 剖面切换 | 11.596 ms | 0.734 ms | 0.761 ms |
| 整组消失 / 恢复 | 20.474 ms | 0.732 ms | 0.777 ms |

同一组受损夹具累计上传从 37,663,488 字节降到 3,685,824 字节，减少约 90.2%。这些数字是资源更新专项结果，**不能当成整帧或稳定 60 FPS 证明**。

- 687,830 项检查通过：木墙、砖墙、石墙、沙袋，三档受损 / 两档剖面，连续缺口的原断面、真实 GPU 索引读回、弹痕随墙消失、非标准剖面回退，以及同外观档位不重复上传。记录：`qa/performance/v44-baked-wall-gpu.log`。
- 原 `frame_budget_contract.gd` 更新为验证三档外观的原露出三角形，而非要求旧的连续染色与内部面列表逐项相同；保留武器裁剪 / 变换检查。583,022 项通过，仿真时间与射击数均为 0。
- 全部战场特效冻结资源检查最高 **48 Draw Call**。同一初始化资源图元计数从 v42 的 1,200,584 降到本版 861,698；此计数包含退化和重复图元，不等同可见三角形。记录：`qa/performance/v44-gpu.log`。
- 多份外观在载入阶段占用资源；CPU 不再在每次受击时制作它们。烘焙总顶点为 1,747,008，每帧墙体索引为 394,056，不同时绘制六套外观。
