# 打击感设计方案（源码对照稿，2026-09-29）

状态：下文为设计依据；v2026.09.29.14 已实施打击感改动，准确范围及检查边界见 [实施记录](combat-feedback-runtime.md)。参考范围是本地旧 Pixi 小小战地 `G:/I00009/client/web/Pixi-Battlefield1-Blue/src`，当前落地目标为原生 Godot 联合演武场。

载具血量、方向防御、真实履带损伤与断履反馈另见 [载具装甲与行走机构耐久方案](vehicle-durability-design.md)，属于独立耐久提案；本轮根据用户所附打击感截图实施表现与性能改动。

## 1. 源码里值得沿用的设计

| 已核实位置（旧 Pixi） | 设计事实 | 本项目采用方式 |
| --- | --- | --- |

| `effects.js:253` | 肉体、混凝土、木、金属、玻璃、土分别使用碎片 / 火星 / 烟尘；命中方向参与喷散 | 按命中材质与实际命中点选择表现，不能每种表面都喷同样火花 |
| `effects.js:479` | 机关炮、轻 / 中 / 重炮分别配置爆闪、破片和烟团数量与寿命 | 接续现有爆炸批次，补 45 / 75 / 88 mm 的时间和冲击差别 |

| `game.js:3623`、`entities.js:235` | 伤害确认后触发方向受击；部分重武器致命命中进入独立击飞表现 | 用实际结果决定轻伤、重击、致命；延续原骨架与真实位移约束 |

旧版的二维像素位移、镜头振幅、飞尸速度不直接换算为当前三维世界数值。旧版 `combatSoundProfiles.js` 的声学事件用于 AI 感知，不能误当成扬声器声音参数。

## 2. 当前 Godot 基础与缺口

**已具备：** `weapon_handling.gd` 的枪型后坐 / 首发 / 连射 / 恢复，`combat_reaction.gd` 的方向及部位受击，`blood_effects.gd` 的命中点血迹与合并预算，分口径弹丸与实际速度，分弹种爆炸，以及车体 / 炮架后坐、击飞和残骸。方案复用这些系统。

**优先缺口：**

1. `proving_fx.gd:103–125` 当前运行声音主要由少数程序合成声构成；枪声路由主要为 shot / heavy，12 声道循环占用，没有按重要性挑选声音。颜色和口径已有差别，听觉身份仍弱。
2. `proving_fx.gd` 的 damage 主要进入血迹队列，impact 进入材质碎屑；未在这些分支接入独立的肉体、木、金属、砖石命中声音。
3. `combat_reaction.gd.register_hit()` 已有约 0.1 秒内保护较强反应的规则，但普通等强命中仍会重置动作；机枪和多颗霰弹需要按目标 / 射击合并，而非每颗完整重启。
4. `terrain_effects.gd.impact()` 主要按金属 / 非金属及地表色区分，尚未形成口径 × 材质 × 实际结果的反馈配置。
5. 当前命中准心主要是统一 .14 秒反馈。应统一来源过滤与结果分级；不增加飘字和堆叠提示。现有伤害 Label3D 隐藏后仍创建，实施时应移除无用分配。

## 3. 玩家应感受到什么

一次有效射击有四个明确阶段：**出膛有力 → 弹体可辨 → 接触有实感 → 目标结果可读**。时间由实际事件驱动，远距离命中反馈必须等弹丸真正到达。

### 3.1 出膛：短促发力，随后回稳

下表为待试玩调校的表现目标，不修改射速、伤害和既有散布设计。

| 武器 | 核心体感 | 回稳目标 |
| --- | --- | --- |
| 手枪 / 冲锋枪 | 清脆短音，手腕与枪身小幅快速冲量；连续射击保持节拍 | 80–130 ms |
| 步枪 / 7.62 机枪 | 枪托顶肩，肩部随后承力，停火有一次自然回稳 | 120–200 ms |
| 12.7 重机枪 | 低频更厚，机匣 / 炮架有重量；固定操作员肩背承力 | 160–240 ms；连射合成包络 |
| 20 / 25 mm 机关炮 | 每发明确机械撞击与短爆音，25 mm 更重；车身保持可控 | 180–280 ms；不逐发大幅摇车 |
| 霰弹 / 狙击 | 单次强冲量、明显呼吸式恢复；独头弹与散弹听感分开 | 200–350 ms |
| 45 / 75 / 88 mm 主炮 / 野战炮 | 炮管先缩回，炮座与车身滞后承力，再回正；重炮低频尾声更长 | 350–650 ms |
| 榴弹 / 火箭 / 迫击炮 | 榴弹低沉出膛，火箭喷气与后喷，迫击炮短闷声；与目标爆炸分开 | 按现有动作与射速协调 |

这些是视觉与音频包络，不是输入锁定时间。全自动枪的后坐状态连续叠加并封顶，不能为表现而改变扳机响应。保留原角色骨架和固定武器操作员双手接触。

### 3.2 命中：先看接触，再看反应

建议以接触后 0–40 ms 的局部亮点 / 碎屑起始、40–140 ms 的受力峰值、120–350 ms 的恢复构成反馈。死亡动画按实际片段完成，不塞进统一时长。避免全身大面积白闪，强化真实接触位置和身体承力方向。

| 材质 / 结果 | 视觉 | 声音及反应 |
| --- | --- | --- |
| 人体轻伤 | 小范围墨色血花、局部肩胸偏移 | 短而清楚的命中音；不每枪移动整个根节点 |
| 头部 / 重击 | 更集中接触，按部位带动头颈 / 躯干 | 更明确瞬态；头盔脱落沿用实际事件，非致命不能播放击杀反馈 |
| 致命 | 中止受击叠加，衔接方向倒地；遗留血迹与背包 | 一次短结果确认；步枪以倒地为主，重击可短距离击退 |
| 金属 / 装甲 | 沿接触法线少量火星、细屑和暗痕 | 清脆金属声；无有效伤害不能表现成穿甲成功 |
| 木材 | 定向细长木屑、较少烟尘 | 干脆碎裂；实际结构断裂才播放更重一层 |
| 砖石 / 混凝土 | 短灰尘、较钝碎块 | 硬脆撞击和低闷余声；不凭视觉效果生成假破口 |
| 沙土 / 雪地 | 土屑 / 雪粉，弱火光 | 柔软闷击；按原地表颜色与高度 |
| 玻璃 | 少量亮薄碎片 | 脆裂；只在实际材质和破坏状态支持时触发 |

同一目标约 60–90 ms 内的连续命中合成一次受击包络，保留最强部位 / 冲量；同发霰弹对同一目标只发一次主体反应。伤害仍逐颗结算，合并只影响表现。致命结果优先替换普通受击，不在倒地途中重播活体受击。

### 3.3 爆炸：按口径与命中位置表达重量

- 沿用当前爆闪、火团、烟尘、碎片分层；45 / 75 / 88 mm 除尺寸外，再区分冲击峰值、扩张速度和烟尘持续时间。
- 机关炮命中保持短促，连续打击能辨认落点；榴弹紧凑扬土；迫击炮竖向土柱；火箭保留方向；重炮扩大近地冲击并延长低频尾声。
- 贴地、击墙、击中车体、空爆读取实际点 / 法线 / 材质。墙边尘屑向外喷，不能所有情况都是地面圆圈。
- 高抛、强水平击飞留给近距离爆炸和高速车辆撞击；强度由实际冲量、距离及遮蔽决定。人物不能穿墙或在封闭驾驶舱里凭空飞出。
- 装甲命中和载具毁坏分开；击中装甲不是每发都殉爆。保持原残骸批次、损毁动作和真实破坏系统。

### 3.4 镜头与界面：稳定优先，重击有节制

- 普通机枪默认以枪身 / 操作员表现冲量，镜头偏移目标 0–0.5 px；本地主炮或近距离强爆炸允许短促 1–2 px 峰值，约 100–180 ms 内衰减。数值是起调目标，提供关闭 / 低 / 标准选项。
- 不加入每发缩放冲击或全局慢动作 / hit-stop，不把全场炮火叠成持续抖动。保持已经修正的载具跟随插值。
- 准心固定在鼠标，实际瞄准使用未受装饰偏移影响的相机逻辑变换；狙击圆镜与准心同心。效果偏移不能进入下一帧的瞄准计算。
- 复用当前命中标记，轻伤 / 致命只调一次线条强度与短音，不新增飘字、计数或文字提示。标记仅由本地玩家的实际有效伤害触发，不能把队友命中当成玩家命中。
- 对不可见目标的结果确认遵守现有信息规则，不额外透视人物 / 暴露血量。受伤提示只在玩家确实受伤时出现，附近响枪不会伪装为受伤。

## 4. 声音优先实施

第一阶段先补枪声身份、材质命中与混音，收益预计高于继续增加粒子。旧 Pixi 的音频表证明已有分类和采样引用；实施前盘点实际可用文件及来源，再决定复用或补素材，不能把路径引用当成文件已可用。

建议固定 24 个声音槽：8 个本地开火 / 命中 / 受伤，12 个附近世界声，4 个爆炸余声 / 远景声；先完成这个上限下的听感，再决定是否增加。按重要性、距离、剩余响度抢占，不能由弹壳声打断本地主炮或击杀确认。

开火音与接触音分别位于真实枪口 / 命中点。远处降低高频和音量；遮蔽先复用现有事件与场景信息，必须新增查询时采用低频缓存、每帧最多两次装饰查询。AI 听觉事件保持原逻辑，不因扬声器静音或声音池满而被取消。

## 5. 实现组织与预算

沿用真实事件链：`shot → impact / damage → death / fracture / vehicle_destroyed`。

拟增加小型 `combat_feedback_profile.gd` 配置表和 `combat_feedback.gd` 调度器：读取弹种身份、命中材质、部位、实际伤害、致命、来源与可见性，向现有动画 / FX / 声音系统分发。原伤害系统仍是唯一裁决来源。必要时在原事件附上接触法线、武器槽和射击编号，避免为特效重复射线或同发霰弹重复播反馈。

配置分为武器基础 → 弹种 / 口径覆盖 → 材质反馈 → 本地 / 远景缩减；缓存以实际武器身份和 mounted_fire_key 为键。声音 / 动画 / 粒子各有预算，不由一个质量开关同时删掉全部反馈。

**优先级：** 本地真实接触与致命确认 > 近处目标受力 > 材质瞬态 > 次要烟尘 / 碎片 / 远景余声。爆炸批次继续 480 实例、普通弹丸 2048 显示项、血迹 192 动态 + 96 留痕、尸体 18 个，不因本方案增加这些容量。

目标为新增反馈调度与音频选择 CPU P95 ≤ 0.5 ms（目标机、代表负载下待测），现有爆炸维护计时不能冒充整体成本。无逐碎片刚体、逐弹灯光、全场单位扫描或新增世界相机。启动预热音频与 shader；不在首发命中时加载文件。

## 6. 分三轮实施和验收

1. **先补接触实感：** 枪族声音、材质命中音、受击合并、来源正确的命中确认。对照 M416 / AKM / 12.7 重机枪，分别击打人物、木、金属和石墙。
2. **再做重量层次：** 20 / 25 mm 机关炮、45 / 75 / 88 mm 主炮的炮架承力、低频、接触 / 爆炸差异；RPG、40 mm 榴弹和迫击炮补命中位置 / 地貌区分。精调致命倒地、爆炸抛飞与车体反应。
3. **最后调混战：** 视野中多处交火与爆炸的混音优先级、装饰削减、镜头选项和缓存维护。用户实际试玩并观察 P95 / P99、音频抢占与遮挡，不用启动帧率代替压力结论。

验收入口始终为 `res://proving_ground.tscn`。用原 Tab / 轮盘选择武器与载具；不另建预览。核心验收问题：能否凭声音分出轻重；能否立刻分清打中人 / 墙 / 装甲；持续扫射时角色是否自然承力；主炮重击是否明确且准心稳定；密集爆炸是否仍能辨认目标和操作。
