# 医疗交互与动作 · v2026.09.28.27

原实现只有计时回血和很小的手臂摆动，未绘制医疗物品；演武场初始满血使按键直接被拒绝。本次接入实际物品、动作与图形反馈，原骨架、蒙皮及走跑下身保持不变。医疗动作是本项目的程序上身层，不是用户提供的医疗动画或其他游戏的原版资源。

- 按 5 使用当前医疗物品；G 轮盘医疗区滚轮选绷带 / 急救包，松开确认。原 Tab 配装面板有直接使用按钮，附近背包的随身医疗物品也可点“使用”。
- 按 5 再次取消、Esc 取消；切武器、收枪、受击、死亡、上车、翻越、攀梯或离地中断。取消不回血、不消耗；医疗动作期间原开火 / 冲刺限制保留，不泄漏按住的扳机。
- 绷带 1.8 秒回复 40；急救包 3 秒回复 100，完成时各扣一件，最多回满生命。无库存和满血不消耗，以短暂的斜杠 / 勾及血条反馈，不显示状态文字或倒计时。
- `medical_motion.gd` 提供取出、缠绕 / 开包取敷料按压、收回动作。道具跟随实际手骨，急救包盖独立开合。手腕目标先平滑再做原骨架双关节求解，按身体坐标限制单步移动，避免混合已求解骨骼导致肘部甩动。站、蹲、卧分别调整操作高度，取消后恢复原动作。
- HUD 显示角色附近医疗图标细环、真实生命及预计回复量；右下原武器卡临时显示医疗品名、现有库存与血量。仍复用现有 UI 几何 / 字形批次，不添加另一套计时、说明浮框或输入面板。
- 网格和材质共享，道具仅首次治疗时懒创建（一个容器、四个网格节点），取消 / 完成 / 死亡 / 上固定武器后隐藏；无逐帧网格生成、刚体或灯光。

在同一联合演武场按 Tab → 医疗演练，会由用户主动把生命设为 35%、补充 3 绷带 / 2 急救包，并选择急救包；随后按 5 治疗。演练按钮不自动触发动作，不改变无敌开关，不在战役生效。正常启动仍满血。

验证：`qa/medical_action_check.gd` 覆盖满血 / 空库存反馈、各中断、一次消费、站蹲卧手部连续性、道具开合 / 隐藏、原下身骨骼与共享资源；另运行原快捷装备、收枪、掉落背包和 HUD 检查。只做状态 / 数学 / 资源与启动检查，画面及手感由用户在 `res://proving_ground.tscn` 验收。
