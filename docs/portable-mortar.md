# 便携迫击炮部署 · v2026.09.29.24

用户要求：使用后部署在原地；靠近按 F 后才能瞄准 / 发射，并且只能蹲姿操作。

## 操作

1. 原 Tab 武器库或已有战术装备槽选中便携迫击炮。
2. 左键在身前约 0.85 m 放置。不发射炮弹、不自动接管；炮留在地面，人物可以离开。
3. 靠近至 2.2 m 内按 F，检查高度与到操作位的通路，通过后自动蹲下。鼠标瞄准、左键单发、R 装填；保留空膛自动装填。
4. 操作时不能走跑、跳跃、站起或卧倒；再按 F 离开，保留蹲姿，由玩家之后按 C 起身。炮与余弹不跟随人物、不消失。
5. 离开会暂停尚未完成的装填，回来后继续；未接管不能发射。

## 实现

- `portable_mortar.gd` 将随身装备转为 `portableMortar` 固定武器。现有弹膛 / 备弹转入炮的唯一状态，从随身战术列表移除该门炮；同一角色不能从武器库重复生成已部署炮。死亡背包也跳过这门已落地的炮。
- 炮沿用原 portable-mortar 武器伤害、弹药、射速、弹道、音效和爆炸；原射程 5.5–23.75 m，必须在炮口转向范围内发射。车载 81 mm 迫击炮保留车辆操作。
- 复用现有 vehicles 数组及 emplacement 接口、碰撞 / 命中 / 损毁、F 交互与装备 HUD；动态生成时仅追加一个视图，不重建演武场。部署炮不放入 Tab 立即试驾列表，玩家通过 F 接管。
- 保留原迫击炮几何与原人物骨架；独立地面炮体、蹲姿腿部支撑、双手接触、炮口送弹和轻微受力。骨架命中及合批姿态修订照常发布。
- 放置检查底板 / 支腿地面高度、1.05 m 上方空间、操作位及身体通路；F 再检查距离、层高、墙体和蹲姿通行。室内读取真实楼板支撑，不能隔墙 / 隔层接管。
- 每场景最多 16 门部署炮，每名角色当前最多部署一门，复用网格缓存与已有刚体网格合批，不新增逐炮物理刚体或逐帧放置扫描。新增耐久为 280，为本项目固定武器设置。

## 检查与验收

Godot 4.6.3 必要资源导入和场景编译通过，未自动部署或开火。统一 `res://proving_ground.tscn` 联合演武场，启动可直接选中便携迫击炮；实际操作及装填动作由用户试玩。F5 重建演武场后清除部署炮；本轮没有增加回收搬运交互。
