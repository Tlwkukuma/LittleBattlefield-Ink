## 必须明确的限制

1. **GAP-01：原版运行时资料不完整**：上传内容没有原Pixi第二至十章最终AI与逐兵配装。当前复用已核对的首关武器池、保留有限迫击炮数量，并采用公开说明的补员/战术适配。不能称作完整原版AI复刻。
2. **LIMIT-01：本次云端可视化约1实际FPS**：正常渲染下的连续实战操作评价有限。固定节拍测试只让模拟可比较；无法据此预测用户Windows机器帧率。旧版本RTX3060性能表不是本版成绩。
3. **LIMIT-02：缺少Windows实机及双机LAN验收**：当前LAN仍是独立第一关果园，不解锁离线十章；未证明十章多人协作或跨机器兼容全部通过。
4. **SCOPE-01：章节存档不是战中存档**：保存完成章节、当前选择与战术，不保存当前战斗位置、弹药、伤亡和破坏状态。
5. **SCOPE-02：历史五关只是设计**：佩加索斯桥、台儿庄、巴斯托涅、卡西诺、阿拉曼均有任务/地图/AI/资产/验收提案与来源；年代装备及扩展规则仍待制作。

## 怎么开始

Windows便携包完整解压后运行 `LittleBattlefield.exe`，保留旁边的同名PCK。操作顺序：

1. 首页“战役”→十章列表→第一章或其他已解锁章→简报/配装/战术→**Tab开战**
2. **WASD移动，鼠标瞄准，左键射击**；Tab打开装备面板并暂停，F5重开当前章
3. 胜利后可进入下一章；失败可重试。重开从本章初始状态开始，第十章胜利结束战役
4. 章节完成、选择与战术会保存在本机；退出后可继续已解锁进度，但不会恢复退出前的战斗现场

源码用Godot4.6.3 stable导入 `project.godot`。普通离线游玩不需要运行LAN防火墙辅助脚本。

项目版本、引擎版本与散列分别见 `VERSION.txt`、`ENGINE_VERSION.txt`、`SHA256SUMS.txt` 和ZIP旁置 `.sha256`。最终源码包保留有用的人工/自动QA脚本，并提供仅覆盖实际交付项目文件的清单。运行包中的 `SOURCE_MANIFEST.json` 是**导出时集成项目快照**，用于追溯构建；最终源码包自己的清单是**打包后源码库存**，会排除原始轨迹并纳入后续说明文档，因此两份清单范围不同，不能互换校验。工具链、消融副本和大体积原始诊断轨迹不混入交付。
