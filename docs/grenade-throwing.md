# 手雷投掷：PUBG 方向与 2.5D 适配

## 2026-09-29：修正弧线与飞行速度

用户明确本次主要问题是“弧线和飞行速度不像真实抛掷”。旧求解先指定 `1.1 + 距离 × 0.085` 的弧顶增高，再倒算速度：即使只丢 2 米，也强行上升 1.27 米，造成近距离吊高、滞空偏长。本轮取消该弧顶公式，使用出手角度、有限初速度及恒定重力计算。

参考事实：[PUBG 官方投掷说明](https://support.pubg.com/hc/ko/articles/360004496594)说明按住左键后用右键改变远投 / 近投姿态；[官方 Console Update 3–5](https://pubg.com/en/news/1728)说明轨迹指引保持至投掷物离手。两份文档没有公开出手速度和物理系数，以下均为本项目的 2.5D 调校，不能宣称 PUBG 原参数、动捕或完整操作复刻。

- 正常上抛基准 28°，近距离低抛基准 12°；普通站姿速度上限分别为 18 和 8.5 m/s，蹲 / 卧按原力度差异降低，并按目录射程小幅缩放。鼠标仍指定距离与目标表面高度，避免为第一人称仰角操作而改动本项目相机。
- 近处轻投，远处增加初速度，出手后只受原重力、碰撞和反弹影响。高处目标允许提高仰角，但有角度 / 初速度上限；超出能力时预览显示实际弹道，不增加虚构的向上推力或直接移到目标。下坡可能比平地飞得更远，限的是出手能力，不在空中硬截距离。
- 在出手高度 1.30 m、平地、站姿上抛的数学夹具中：2 米投掷从约 1.02 s / 上升 1.27 m 改为 0.57 s / 上升 0.12 m；6 米从约 1.11 s / 1.61 m 改为 0.79 s / 0.58 m；12 米为 1.04 s / 1.34 m。实际场景由手掌位置、地形和碰撞决定。
- 原骨骼动作保留。预览改为只读预测**完成摆臂后的手掌位置**，与真实出手共用偏移与手臂可达限制，避免用准备姿态的后方持物点来画另一条弧线。预览和飞行共用 `grenade_ballistics.gd`，躯干到手掌的防穿墙检查继续保留。
- 按住左键预瞄、松开投出；右键上抛 / 低抛；原 G、数字、滚轮选武器保持。引信与取消规则未改，未加入捏雷。原卡片的模式文字显示“上抛 / 低抛”，删除常驻教学句和力度数字浮框；保留细轨迹及首次接触小圆，取消把首次接触冒充爆炸点的大范围圈。
- 原爆炸伤害、可破坏场景、楼层 / 负海拔支撑、弹体显示插值、反弹、滚动与有限库存继续保留。预览仍为 15 Hz、最多 80 段、单动态网格；没有新建第二相机或逐段物体。

验证：`qa/grenade_math_check.gd` 6267 / 6267；`qa/grenade_release_check.gd` 73 / 73，覆盖站 / 蹲 / 卧、上 / 低抛及四向原骨架的预计与实际出手位置、只读预览与初速度一致；快捷装备状态检查 50 / 50。仅数学、状态、资源和启动检查，不自动操控游戏。实际手感由用户在同一联合演武场验收。

## 2026-09-26 初版记录（参数和界面以本页上方修正为准）

入口仍为 `res://proving_ground.tscn`，`START_GRENADES.bat` 携带 HE 手雷进入联合演武场；Tab 武器库可切烟雾弹。以下保留初版参考来源和历史行为。

## 参考中核实的部分

主要参考本机《逃离鸭科夫》2.3.30。对 `TeamSoda.Duckov.Core.dll` 进行只读方法体检查，没有运行原游戏、修改原文件或导入原素材。可复查的符号与调用关系保存在 [观察记录](duckov-throw-observations.json)，提取脚本为 `tools/inspect_duckov_throw.ps1`。

- `Skill_Grenade.OnRelease` 读取出手位置、瞄准位置与 `canControlCastDistance`。允许控制距离时，水平初速度由目标距离决定，而非所有目标使用同一发射速度。
- `CalculateVelocity` 使用重力、配置的竖直初速度与目标高度计算飞行时间，再求水平速度。瞄准位置包含高度，不仅是地面上的平面方向。
- `SkillProjectileLineHUD.UpdateLine` 使用对应的抛物线计算；`CheckObsticle` 通过球扫检测障碍物。`SkillHud3D` 控制轨迹和效果范围提示。
- `Grenade.Launch` 把速度交给刚体并赋予旋转，短暂忽略投掷者碰撞。
- 以上不能确定每种原作手雷预制体的数值、默认键位、高低抛操作或引信规则。本轮没有实测原游戏手感，不能将本项目下列参数说成鸭科夫原值。

PUBG 作为辅助参考：官方 [Console Update 3–5](https://pubg.com/en/news/1728) 说明投掷轨迹提示保持到手雷离手，并修复倒地后的残留轨迹。采用出手前预览、离手后消失这一信息组织方式；没有使用 PUBG 动捕或模型资源。

## 本项目的操作与效果

| 操作 | 行为 |
| --- | --- |
| 移动鼠标 | 决定方向、目标高度与距离；近处轻抛、远处用力。距离超过上限时显示“最远”。 |
| 按住左键 | 抬手预瞄，显示抛物线、力度百分比和首次接触位置。按住时间不增加力度。 |
| 松开左键 | 锁定这次目标，摆臂约 0.16 秒后从原骨架实际手掌位置出手。 |
| 右键 | 切换高抛 / 低抛。高抛适合越过矮掩体；低抛更平、更快，适合近距离或窗口。 |
| Esc | 取消尚未离手的投掷，不扣数量。 |
| 蹲伏 / 卧倒 | 缩短最大投掷距离；卧倒使用低抛。 |
| Tab、切武器、翻越、爬梯、上车、失焦、死亡 | 取消尚未出手的投掷，重新按下左键才能准备。 |

维持原 2.5D 镜头和固定鼠标准心。轨迹是独立的世界空间提示。小圆标记**首次接触**，不是保证最终爆炸位置：撞墙、撞地后仍会反弹、滚动并逐渐停下；软地面减弱反弹和声音。爆炸和场景破坏保留原系统。支撑面被炸掉后，已停下的手雷会继续下落。

预览和飞行共用 `grenade_ballistics.gd` 的重力、解析曲线及碰撞查询，支持地形三角网格、负海拔、可破坏墙单元、车辆和住宅部件。出手前检查躯干到手掌的通路，避免手穿过墙后把手雷直接生成在墙另一面。

HE 球形橄榄色弹体与烟雾弹的灰绿罐体分开；旋转速度随碰撞衰减，声音有并发/频次限制。烟雾在实际起爆高度展开。未增加普通子弹拖尾。

## 本项目参数与验证边界

参数均为本项目初版调校：重力 14 m/s²；碰撞半径 0.085 m；HE 站姿高抛范围沿用目录的 19.5 m，低抛为 58%，蹲伏为 82%，卧倒再缩短。HE 离手后 2.8 秒、烟雾弹离手后 2.2 秒触发；预瞄不会把手雷捏爆。投出后沿用空仓自动装填来补下一颗。

轨迹仅在准备投掷时以 15 Hz 更新，每次最多 80 段；复用一份动态网格，不逐段创建场景节点。每枚飞行手雷使用 1/60 秒子步及最多 12 次迭代，静止后每 0.18 秒检查支撑。以上是开销控制，不是 50 vs 50 性能测试结果。

`qa/grenade_math_check.gd` 检查目标距离 / 高度解析解、30 / 60 / 120 Hz 飞行、首次接触预览、墙面反弹、窗口、移除地面后的继续下落、旋转住宅部件法线，以及长按 / 松开 / 中断的状态机。仅运行数学与状态夹具，不自动操控游戏。

实际摆臂观感、门窗边缘容错、远近力度和爆炸节奏由用户试玩验收。当前不计算人物躯干对手雷的反弹，也不预测多次反弹后的最终停留位置；烟雾沿用现有特效，不模拟室内气体扩散。
