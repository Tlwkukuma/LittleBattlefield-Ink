# v2026.09.28.40：以实际帧间隔 15 ms 为目标

本轮验收目标是用户性能面板中的 **P95 / P99 帧间隔均不超过 15 ms**，持续移动、交火时维持至少 60 FPS，战斗 Draw Call 小于 50。不是仅将物理或主循环中的某一个计时压到 15 ms。本文记录实现和证据，不新增全局制作规范。

**交付时尚没有 v40 的用户实战样本，不能宣称上述目标已经达成。** 原项目限制由用户测试操作和画面，本轮只进行了编译、数学、资源及启动检查，没有自动推进战斗、调用 world.step 或注入操作。

## v39 实战问题

数据源：`qa/performance-v2026.09.28.39-20260928-171622-491.log`，用户窗口启动 17:16:27，PID 15168。

- 拥挤交火窗口实际约 32.8 FPS，帧间隔 P95 约 43.7 ms。不能把后续较轻窗口的 50–58 FPS 当作持续表现。
- 一个最差窗口的 164 个画面帧中，115 帧补算了两次物理更新。最差一帧约 46 ms，仅两次物理累计就约 25 ms。过长画面帧触发物理追赶，进一步放大 CPU 压力。
- AI、移动、真实弹道、角色表现、特效和批次提交累加超预算。该窗口墙体更新已不再是最大开销；继续只压 Draw Call 或重复优化墙体不足以解决问题。
- 战斗日志仍出现超过 50 的 Draw Call；单张截图的 42 不能证明整个过程合格。

## 当前修改

1. **血滴和血迹共用一个 GPU 批次。** CPU 保留生成时的真实接触查询和有界生命周期；GPU 从固定槽位数据计算原有抛物线、朝向、大小和淡出。数据只在生成 / 回收时上传，免去逐滴逐帧变换和颜色提交。使用 32 位浮点出生时间，避免长时间运行后半精度时钟失真。
2. **明确的装饰性取舍：** 每个画面帧喷血轨迹查询上限从 96 收紧为 24，优先附近和致命命中，超预算沿用短促接触飞溅。血滴 / 血迹数量上限保留。实际子弹、伤害、墙体破坏查询不受该预算限制。
3. **持续维护单位空间格。** 单位射线和移动邻居索引复用原格表，只在跨格、死亡或列表变化时更新，保持原候选顺序。物理命中仍使用当前状态。
4. **射线便宜排除。** 场景索引记录保守世界包围体，短射线先排除完全不相交的实体，再进行原精确局部空间 / 墙格检测。重建场景索引同步重建包围体。
5. **移除重复渲染工作。** 人物已通过 GPU 骨骼调色板绘制，取消不可见源模型的额外原生蒙皮注册；原 Skin、骨架、动作和挂点保留，主角遮挡副本显式连接实际骨架。武器屏幕裁剪使用缓存包围球及相机空间边界，并跳过未改变的实例数据上传。
6. **物理追赶共享 AI 决策预算。** 同一画面帧的多个物理更新不再分别补发感知 / 寻路预算；运动、射击、冷却和实际命中继续按原物理更新执行。
7. **B 点文字合批。** 保留原 Label3D 的文本、字体、颜色、世界位置和标记逻辑，文字与墨线描边复用 HUD 字体图集，只在状态变化时重建网格。
8. **正确记录目标。** 原 60 FPS 上限本身对应 16.67 ms，改为 75 FPS（13.33 ms 理论间隔），物理仍为 60 Hz；该设置不是性能达标证据。面板 P95 / P99 任一超过 15 ms 标红。日志新增实际活动帧区间、超过 15 ms 的帧数、渲染 CPU / GPU 计时，保留原始全帧间隔数据。

人数保持 30 对 30，原角色与头盔、真实地形、可破坏墙体、分辨率和画质设置保留，Laya 关闭。

- 实际 OpenGL 资源检查：`v40-gpu-merged.log`。原入口保持禁止处理，仿真时间 / 射击数始终为 0；仅放置已有表现资源，检查枪口焰、尸体、头盔、弹壳、弹匣、血迹、载具烟火、伤害数字、遮挡副本和武器目录替换。288 个血液 GPU 槽位实际回读通过。基本冻结场景 27 Draw Call，特效组合 43，扩大视野最高 **49**；武器目录替换 48。无脚本或着色器错误。这是有限资源组合，不能代替长时间战斗上界。
- 初次 GPU 检查错误包含装备菜单：165–191 次绘制；明确关闭菜单的显示后重测，场景仍禁止处理。后续宽视野检查先为 51、血液合批后 50、B 点文字合批后 49。原始失败日志保留，没有修改计数器。
- Headless 的 Dummy 渲染器不支持 MultiMesh 数据回读，最初新增的回读断言在该后端返回零而失败；回读检查移至实际 OpenGL 后验证通过，数学检查继续在 Headless 执行。

同一进程交替执行旧 / 新冻结微基准（`v40-cpu.json`，下列为整批 CPU 中位耗时，并非帧时间）：

| 固定工作量 | v39 源码 | v40 |
| --- | ---: | ---: |
| 2,400 次射线 | 79.494 ms | 70.559 ms |
| 120 次单位射线索引刷新 | 22.138 ms | 7.786 ms |
| 192 血滴 + 96 血迹，120 次表现更新 | 37.351 ms | 0.110 ms |

这些结果说明指定工作减少，不证明整帧 P99 小于 15 ms。仍需用户在新 Release 窗口按 Tab 开始，到 B 点持续移动、交火和进出建筑，由实际日志判断目标是否达到；GPU 计时若引擎返回零，应视为未提供有效测量，不能解释为没有 GPU 开销。
