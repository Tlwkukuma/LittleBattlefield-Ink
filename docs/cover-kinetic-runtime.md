# 墙体枪弹伤害与金属围栏 · v2026.09.28.21

用户发现 M4 能打碎标为混凝土的测试墙，并指出金属围栏看起来像实心金属墙。原因分别是运行命中仍调用人物伤害 × `kind` 倍率、围栏共用整格金属墙网格且整件 `blocksProjectiles=false`。

## 本批已生效

- `advance_round` 和近战实际命中把武器绑定传入结构结算。墙格读独立枪弹响应数组；M416 / AKM 对混凝土、砌石和钢筋混凝土等表中零值材料不扣耐久，不会累计到最后突然挖穿。混凝土地板、台阶及路障也执行材料禁破。
- 墙格正值伤害与人物伤害脱钩，按单元面积、实体厚度、实例耐久倍率、实际命中法线、结构距离衰减和弹粒份额结算。标准参考格 M416 木板 3 发、砖墙 48 发、混凝土禁止；AWM 混凝土 96 发。0.28 m 砖格为 56 发，60° 入射的标准砖格为 96 发。实际散布和击中多个小格不等于一直命中同一参考格。
- 兼容迁移只有一份实际 HP：初始化将 `D_ref` 预换算到旧 HP 存储单位，换算因子为 `旧 max_hp / [100 × 格面积 / 0.25 × 厚度 / 参考厚度 × health_scale]`。因此旧 `kind` 的 max_hp 在墙格动能发数里抵消，实例的 `health_scale` 仍作为显式耐久倍率保留；旧爆炸与坍塌继续扣同一份 HP。没有暗中叠加第二条耐久。
- 原破坏靶的位置保留，木 / 砖 / 混凝土的实际厚度改为 6 / 24 / 20 cm，沙袋为 50 cm。前三组长度 3 m、高度 1.5 m，每格正面 0.5×0.5 m。沙袋仍使用较矮袋体格，按面积换算，不能把其中半块称作完整参考格。此前所有样品都是 80 cm 厚，不能冒充标准板。中文标识保留。
- 零结构伤害仍产生原弹着反馈；每格最多保留三处不同弹痕，相近重复命中不再请求网格更新。零伤害不改拓扑、导航或支撑。

## 金属围栏

`metal_fence.gd` 创建有端柱、中柱、上下横杆和细焊接网格的围栏。没有背板；所有杆件按原墙格裁分并缓存，`terrain_art.gd` 合为一个网格 / 一个表面，不为每根丝创建节点。沿用纸感色调，柱框偏深灰蓝、网丝偏浅金属色。

同一杆件数据进入子弹、人物、车辆、承托和手雷碰撞：网眼能过弹，立柱和丝杆可被实际命中；网眼小于人物通行体，完整围栏拦人。爆炸或重火力清空格子后，显示、弹道、车辆 / 人物通行和承托都忽略对应杆件。按钢构件材料规则处理，不能把围栏整件设为“所有子弹都穿过”。

杆件范围只在初始化生成。射线先用原空间索引和包围盒，再限定到实际经过的墙格。只有带武器的命中查询需要新入射法线；AI / 相机查询不增加此计算。测试的 2 m 样段为 1032 三角形、单表面、每格最多 8 段杆件。

## 尚未迁移

- RPG 等爆炸仍使用原有破坏和支撑结算，混凝土保持可炸毁；表中新的接触爆炸发数尚未生效。
- 历史 v2026.09.28.21 普通弹到墙后停止。v2026.09.30.55 已接入按实际实体厚度、入射方向、剩余预算与伤害衰减的有限多层材料穿透，最多 4 层；见 [当前三维战术/穿透实施记录](campaign-ai-3d-runtime.md)。网眼或已有破口仍不消耗实体穿透预算。
- 树干、家具、容器等整体道具对允许攻击的正值耐久仍沿用原系统，避免用实心包围盒体积当成空心容器壁厚；材料表的禁止破坏已生效。混合部件的独立材料 / 局部耐久与动态土体侵蚀留给后续批次。
- 车撞、坍塌及爆炸属于各自的机械/爆炸来源，不伪装成普通步枪子弹；坦克自身装甲伤害不套墙格表。

- `cover_damage_contract.gd` 269 项：标准材料×武器发数、厚度、斜射实际法线、远端衰减、霰弹份额、人物伤害独立、近战禁止及所有住宅混凝土件。
- 1000 次独立 M4 → 混凝土接触：耐久无损、子弹停止、拓扑变化 0、网格通知 1；本机一次总耗时 42.477 ms。这是固定夹具总耗时，不是每帧耗时，也不是 50 vs 50 性能验收。
