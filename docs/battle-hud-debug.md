# 战斗 HUD 与 Debug 抽屉

项目版本：v2026.09.29.11。用户要求沿用小小战地 UI，测试与性能信息默认不显示、不渲染。

## 常规界面

布局参考旧 Pixi 项目 `src/ui.js` 的 `HUD`、`layoutForceStatus()`、`drawForceBars()`：顶部居中红蓝兵力条，左下生命，右下原枪械、弹药与快捷装备。首关兵力为存活在场人数加预备兵力，比例分母读取各队部署总兵力；据点显示归属、占领比例及方向距离。乘车时生命上方增加载具耐久。暂停 / 倒地才显示相应简短提示。

`battle_status_hud.gd` 把图形与文字追加到原 `combat_hud.gd` 的共享批次，不增加 HUD 绘制通道或世界相机。兵力与据点摘要最多 10 Hz 更新；生命与武器仍反映真实状态。原 G 轮盘、Tab 拾取 / 配装、医疗、换弹环、准心和 E/F 交互继续保留。

## Debug 入口

右上角仅一个 Debug 按钮，点击打开同一抽屉，Esc 或再次点击关闭。分页包括性能 / 状态、测试工具、场景工坊。原顶部场景按钮、动作近景、画风对比、重置、房顶控制，以及原 Tab 内展区传送、医疗演练、补给、无敌和靶兵开关全部归入这里。Tab 的正常武器 / 车辆选择继续保留。

F1 / F2 / F3 / F5 / F8 仅在 Debug 已打开时作为工具快捷键；F4 不再单独弹出性能面板。关闭抽屉会退出工坊并恢复战斗视角。打开时清除旧扳机、跳跃、开镜与轮盘状态，屏蔽玩家战斗输入；世界仍可运行以观察 AI 的性能，普通暂停状态不会被 Debug 改写。

窗口标题始终保留项目版本、启动时间和 PID；游戏内相同标识显示在 Debug 副标题与提示中，重置和场景切换保留本次启动身份。

## 关闭时的执行边界

- `performance_overlay.gd` 关闭 `_process`；切出性能页也停止采样，并清空旧帧间隔 / P95 / P99 历史，重开重新采样。
- 详细 CPU / GPU 日志需在性能页显式勾选。关闭或切页会释放记录器、关闭 viewport 渲染计时和 `world.profile_ai`。启动器不再默认带 `--performance-log`；旧启动参数只预选勾选框，不能绕过抽屉可见性启动采样。
- 原每帧底部字符串、FPS 计数及详细战况只在可见性能页刷新。常规战斗只保留必要摘要。
- Debug 整棵子树标记 `hud_native`，不被 `hud_batches.gd` 收集，因此不会把不可见的调试文字 / 几何留在战斗批次。原生控件随抽屉隐藏停止绘制。

## 检查

`qa/debug_hud_contract.gd` 使用冻结的原入口，覆盖默认隐藏、采样启停、分页启停、隐藏字符串不更新、调试子树不入批次、输入锁、1280×720 / 1440×900 布局、Tab 载具入口、工坊退出、跨场景版本身份。没有推进 `world.step`、AI 或开火。另复用原资源与 GPU 冻结渲染契约；实战观感和性能由用户试玩确认。
